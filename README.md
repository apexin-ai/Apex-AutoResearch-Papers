# 超衍智能 · AI 自主科研系统

**让 AI 自主推进从研究问题到可复核成果的完整过程。**

超衍智能（Apex Intelligence）构建了一套 AI 自主科研系统，探索在尽量少的人工干预下，如何让系统贯通文献调研、方法设计、代码实现、实验分析、论文写作与迭代检查。本仓库展示系统产出的 **36 项研究成果**，并把论文与可用的过程材料放在一起，供研究者阅读、检验和讨论。

**36 项研究成果** · **AI 研究与机器人具身智能** · **7 类项目材料**

[按标题检索全部成果](CONTENTS.md) · [查看项目与论文](#项目与论文) · [参与讨论](https://github.com/Zxy-MLlab/Release_examples/issues)

## 从研究成果回看研究过程

我们希望展示的不只是最终稿件，还有研究如何逐步形成：

> 研究任务与文献 → 方法与实现 → 实验与分析 → 稿件与图表 → 检查与迭代

这些项目覆盖模型评测、信息抽取、因果推断、智能体、LLM 安全、模型机制与效率，以及机器人和视觉-语言-动作模型。下图概览了本次成果的研究方向分布。

## 每项成果包含什么

打开任一[项目页面](paper-assets/)可以从论文进入代码、实验和研究过程。项目采用统一的七类目录；某类材料是否存在以及覆盖程度，以各项目的说明和索引为准。

| 目录 | 可查看的材料 |
|---|---|
| `01-manuscript/` | 论文 PDF、LaTeX 源文件、图表与版本材料 |
| `02-code/` | 研究代码、脚本、配置与依赖记录 |
| `03-experiments/` | 实验配置、数据、运行结果与分析产物 |
| `04-generation-trace/` | 可读生成记录和结构化会话；缺失时提供说明 |
| `05-validation/` | 已归档的内部审查、审计与验证记录 |
| `06-maintenance/` | 研究计划、修订、维护与项目文档 |
| `07-index/` | 文件清单、原始路径、校验值与排除记录 |

我们欢迎研究者运行代码、核查实验、检查方法与结论，并通过 [Issues](https://github.com/Zxy-MLlab/Release_examples/issues) 提出问题或修订建议。独立复核与批评同样是这些成果继续完善的一部分。

### 阅读前说明

这里展示的是研究项目及其归档材料，不代表论文已被会议接收或经过外部同行评审。发布时未对所有代码和实验进行独立复跑；部分项目没有完整生成轨迹。请以各项目的清单与说明判断材料覆盖范围。
