# ApexTune benchmark code and experiment records

Versioned benchmark code, baseline runs, optimization histories, state records, and measured results. The collection includes code-v1-v4 through code-v7 and AIDE baseline records; it contains no standalone manuscript PDF.

Included: **3,886 source objects**. [Browse files](source/) · [Source and exclusion manifest](source-manifest.csv).

These are archived code, experiment records, or revision materials. They are not automatically counted as separate generated papers. English guides accompany original-language evidence. Credential fields are redacted; dependency caches, Git internals, and account files are excluded. Nested archives are exposed as sanitized extracted files rather than unchecked binary bundles.
