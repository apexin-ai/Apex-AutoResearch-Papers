| 项 | 值 |
|---|---|

| 冠军 test cls_acc | **0.6231**(< 容差地板 0.6251) |

根因链:val 只有 475 行,准确率读数采样 σ≈2.2pp → 冠军在 val 上 +0.7pp 的
边际纯属噪声量级 → test 读数落到容差之下 → 整轮归零。**argmax_val 从不检查
准确率边际**,而 robustify 配方(公平换准确率)天然把候选推向地板——两者相加,
贴地板冠军在 test 上是掷硬币。这正是 Phase C 已量化过的"准确率地板是真约束"
在实战里的兑现。

## 修复(提交 `4989e3f42`)

`final_accuracy_margin`(默认 0.0 = 与 QD-v5 逐位一致):终选改为
"在 val cls_acc ≥ 地板 + margin 的候选中取 metric 最优",空池回退 argmax。
**在本轮 89 个有效候选上回测**:

| margin | 改选结果 |
|---|---|
| +0.00 | val 0.00027 @ acc 0.6421(本轮实际提交,翻车) |
| +0.01 ~ +0.03 | **val 0.00214 @ acc 0.6884**(仍是 robustify 候选,+5.3pp 边际) |

近零指标代价换 2σ 级存活边际。性质上这是**存活约束**(排除"可能无效"的候选),
不是 v6.1 那类"预测公平性"的启发式——不与已证伪方向冲突。
