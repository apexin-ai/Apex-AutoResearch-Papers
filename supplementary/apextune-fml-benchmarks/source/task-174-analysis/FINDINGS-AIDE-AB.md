## 三个定案级结论

### 1. "我们用 5.6 打不过人家 5.4"这个担忧,被证伪了

模型轴对齐后差距消失:AIDE@5.6-sol(0.2273)甚至**低于** AIDE 官方@5.4
(0.2310)。原先的 0.005 "落后"主要是**跨模型跨口径比较的伪影**,不是架构
差距。同模型同口径下,ApexTune 与 AIDE 完全同档(v5 均值差 −0.0014,
中位数还占优;逐轮 2:1)。

### 2. AIDE 的性格:稳定,但够不到深处

AIDE 三轮全部停在 val 0.03094 吸引子——**它从未到达过我们常规到达的深度**
(我们的 val 最优 0.0003–0.0017)。但因为 val<0.02 以下是噪声地板,它的
"浅而稳"在 test 上并不吃亏(0.0126,好于我们 14 轮的中位)。两种搜索性格:
AIDE = 低方差低上限;ApexTune = 高方差高上限(史上最佳 0.2337 与最差有效轮
0.2116 都是我们的)。均值几乎一样。

### 3. 这个 bench 对两家一视同仁地饱和了

同模型下三方(AIDE / v5 / v7)挤在 0.223–0.227 的带内,带宽 ≈ 轮间噪声。
与标定结论完全闭环:剩余差异由 val→test 小样本量测噪声主导,任何一方的
架构改进都无法在 n=3 下显形。**aif360 的架构信号已经被榨干。**
