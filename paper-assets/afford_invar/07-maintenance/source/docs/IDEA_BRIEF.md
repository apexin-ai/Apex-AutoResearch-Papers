## Seed Topic

## Seed 4: Open-Vocabulary Affordance Zero-Shot VLA

Objective: CoRL 2026 submission.

Direction: Traditional affordance methods and VLAs rely on fixed category annotations and struggle with open-world unknown objects and free-form interaction instructions. CoA-VLA (arXiv 2412.20451, December 2024) integrates affordance chain-of-reasoning into VLA, but uses 4 predefined structured affordance types (object, grasp, spatial, motion) — not truly open-vocabulary — and cannot handle free-form interaction descriptions like "use this thing to wipe off the dust over there." GeneralVLA (arXiv 2602.04315, February 2026) achieves zero-shot affordance perception and manipulation trajectory generation through VLM+SAM, but is a modular three-stage pipeline (affordance perception → trajectory planning → low-level control), not a unified end-to-end VLA — with information loss between modules and inability to jointly optimize. OVAL-Prompt (ICRA 2024 VLMNM Workshop, arXiv 2404.11000) achieves truly open-vocabulary affordance localization, but only performs detection/localization without generating actions. AffordDP (CVPR 2025, arXiv 2412.03142) achieves affordance cross-category transfer through 3D contact points and trajectories, but completely lacks language conditioning. Core gap: No work unifies open-vocabulary affordance reasoning into an end-to-end VLA for zero-shot manipulation — existing work either has fixed affordance types (CoA-VLA), or is a modular pipeline (GeneralVLA), or only does detection without actions (OVAL-Prompt), or lacks language (AffordDP).

Seed Papers:
- "OpenVLA: An Open-Source Vision-Language-Action Model" (Kim et al., CoRL 2024, arXiv 2406.09246)
  — 7B parameter open-source VLA, trained on 970K real robot demonstrations, establishing the VLA open-source paradigm. The base architecture for this work — integrating open-vocabulary affordance reasoning on top.
- "CoA-VLA: Improving Vision-Language-Action Models via Visual-Textual Chain-of-Affordance" (Li et al., arXiv 2412.20451, December 2024)
  — Integrates affordance chain-of-reasoning into VLA: model sequentially reasons about object affordance, grasp affordance, spatial affordance, and motion affordance before predicting actions. Uses visual-language collaborative injection module. Surpasses OpenVLA and Octo. Key limitation: 4 affordance types are predefined/structured, not open-vocabulary — cannot handle arbitrary natural language descriptions of novel interactions.
- "GeneralVLA: Generalizable Vision-Language-Action Models with Knowledge-Guided Trajectory Planning" (Ma et al., arXiv 2602.04315, February 2026)
  — Hierarchical three-module pipeline: (1) VLM+SAM affordance perception for keypoint detection, (2) mid-level planning agent for trajectory generation, (3) low-level control policy. Achieves zero-shot manipulation across 14 tasks without real-world data. Key limitation: Modular pipeline, not end-to-end — affordance module, trajectory planner, and controller are separated, with information bottlenecks between modules.
- "OVAL-Prompt: Open-Vocabulary Affordance Localization for Robot Manipulation through LLM Affordance-Grounding" (Tong et al., ICRA 2024 VLMNM Workshop, arXiv 2404.11000)
  — Prompt-based method combining VLM for object part segmentation and LLM for part-affordance grounding mapping, achieving open-vocabulary affordance localization without prior training. Competitive with supervised methods on localization benchmarks. Key limitation: Only performs affordance detection/localization, does not generate robot actions — a perception module, not a complete manipulation system.
- "AffordDP: Generalizable Diffusion Policy with Transferable Affordance" (Wu et al., CVPR 2025, arXiv 2412.03142)
  — Models manipulation priors through 3D contact points and post-contact trajectories, achieving affordance cross-category transfer using visual models + point cloud registration. Affordance-guided diffusion policy generates actions. Key limitation: No language conditioning — affordances are geometric/contact-based, not language-driven, cannot handle open-vocabulary instructions.

Exploration Directions: (1) End-to-end activation of VLM internal affordance features: Rather than adding an external affordance detection module to VLA, activate interaction-relevant visual features within VLA's VLM backbone network directly through language instructions. Key insight: Large-scale VLMs (e.g., PaliGemma, SigLIP) have already learned extensive shape-function associations during pre-training ("knives can cut," "bowls can hold"), only requiring suitable activation mechanisms to release this implicit knowledge. (2) Affordance as intermediate reasoning tokens: Rather than explicitly outputting affordance heatmaps, have VLA generate a set of "affordance reasoning tokens" before generating action token sequences (similar to CoA-VLA's chain reasoning but open-vocabulary). These tokens encode interaction possibilities of objects in the current scene, then condition subsequent action generation. Differs from CoA-VLA: not limited to 4 predefined types; reasoning content is dynamically determined by language instructions. (3) Contrastive learning for universal shape-function-interaction mapping: Add contrastive objective during VLA training to pull together different-shaped objects with similar functions (various "tools that can scoop things") in affordance feature space, and push apart similar-shaped objects with different functions (decorative bowl vs. functional bowl). More flexible than CoA-VLA's structured types — any natural language-described interaction can participate in contrasting. (4) Knowledge distillation for zero-shot affordance reasoning: Use large VLMs' (e.g., GPT-4V level) zero-shot affordance reasoning capability ("how can this object be interacted with?") as teacher signals, distilling into small VLA. Large models have rich commonsense knowledge and can generate affordance descriptions for virtually any object, but are too large to deploy directly on robots. (5) Affordance consistency self-supervision: The same object under different language descriptions should have consistent affordance responses ("grab the handle" vs. "pick it up by the stick part" describe the same interaction). Use this consistency as self-supervision signals, reducing dependency on fine-grained affordance annotations.

## Core Problem

Can we learn explicit spatial affordance representations within an end-to-end Vision-Language-Action model without any affordance annotations or external supervision signals, by jointly exploiting (1) instruction paraphrase invariance — semantically equivalent instructions must activate identical spatial affordance regions — and (2) cross-object affordance transfer — objects with similar functional parts must exhibit similar affordance patterns for the same interaction type — producing interpretable intermediate representations that improve paraphrase robustness and zero-shot generalization to novel objects beyond what action-level invariance methods (RSS, LangForce), supervised spatial affordance approaches (PALM, CoA-VLA), spatial grounding with web-scale data (ST4VLA), 3D teacher-based alignment (Spatial Forcing), foundation-model affordance distillation (UAD), or standalone affordance modules (INTRA, AffordanceSAM) can achieve — all without the annotation pipelines, web-scale grounding data, simulator labels, foundation model teachers, or distillation sources that existing spatial methods require?

## Opportunity / Why Now

Recent work has firmly established that spatial representations within VLAs improve manipulation — ST4VLA (ICLR 2026) uses point/box/trajectory spatial priors from web-scale grounding data achieving 95.9% on LIBERO, Spatial Forcing (ICLR 2026) aligns intermediate VLA visual embeddings with a 3D foundation model (VGGT) achieving 98.5% LIBERO average (Spatial 99.4%, Object 99.6%, Goal 98.8%, Long 96.0%), PALM (CVPR 2026) integrates 4 supervised affordance types achieving 91.8% on LIBERO-Long, and SG-VLA (March 2026) co-trains affordance decoders with simulator-extracted labels. Meanwhile, UAD (Stanford, June 2025) demonstrates annotation-free affordance distillation from foundation models but as a standalone module disconnected from end-to-end VLA training. However, all VLA-integrated spatial methods require external supervision: ST4VLA needs web-scale grounding data (RefCOCO, LLaVA-OneVision); PALM requires a semi-automated annotation pipeline (GroundingDINO + SAM + SpatialVLM + RoboPoint + CoTracker); SG-VLA depends on simulator ground-truth labels; Spatial Forcing requires a pretrained 3D foundation model as teacher; and even UAD, while annotation-free, still requires pretrained large vision models and VLMs as distillation sources. This supervision dependence creates a critical scaling bottleneck — deploying to new environments, tasks, or real-world settings without simulators or web-scale data requires re-annotation or re-collection. Critically, standard LIBERO is approaching saturation (97–99% with recent methods including simple flow-matching VLAs), reducing its discriminative power for comparing spatial approaches. The real differentiator has shifted to out-of-distribution robustness: LIBERO-Para (arXiv 2603.28301, March 2026) reveals that VLAs suffer 22–52 percentage point drops under simple paraphrasing with 80–96% of failures at the planning level — and none of the above spatial VLA methods (ST4VLA, PALM, SG-VLA, Spatial Forcing) have been evaluated on LIBERO-Para, leaving paraphrase robustness as an untested dimension for spatial VLA methods. Separately, Shin (arXiv 2603.16044, March 2026) shows that LLM-generated instruction augmentation with LoRA improves linguistic robustness, but without learning any spatial representations — demonstrating that paraphrase diversity helps but leaving spatial affordance learning unexploited. The context-dependent affordance study (arXiv 2603.04419) confirms that stable latent affordance factors persist despite >90% lexical drift across contexts, suggesting spatial affordance structure is exploitable as a free self-supervision signal from paraphrases alone. OpenVLA-OFT achieves 97.1% on LIBERO with LoRA fine-tuning in ~10–15 hours on a single A100, providing a compute-efficient backbone.

## Landscape (SOTA & Limitations)

**Spatial representations in VLAs (supervised/teacher-based)**: ST4VLA (ICLR 2026, arXiv 2602.10109) uses spatial priors (point, box, trajectory) from web-scale grounding pre-training (RefCOCO, LLaVA-OneVision) followed by spatially guided action post-training, achieving 95.9% LIBERO average (92.6% Long) and emergent paraphrase robustness in real-world (52% on novel instructions by attribute) — the closest spatial VLA, but requires web-scale grounding data not available in new domains and does not explicitly learn affordance maps. Spatial Forcing (ICLR 2026, arXiv 2510.12276) aligns intermediate VLA visual embeddings with 3D representations from VGGT, achieving 98.5% LIBERO average (Spatial 99.4%, Object 99.6%, Goal 98.8%, Long 96.0%) with 3.8x training speedup — a plug-and-play approach demonstrating that intermediate spatial alignment improves VLAs, but requires a pretrained 3D foundation model as teacher with no learned affordance structure. PALM (CVPR 2026, arXiv 2601.07060) integrates 4 complementary affordance types (global object masks via GroundingDINO+SAM, local contact heatmaps, spatial placements via SpatialVLM+RoboPoint, motion dynamics via CoTracker) end-to-end with progress-aware policy learning, achieving 91.8% on LIBERO-Long — the most directly comparable affordance-in-VLA work, but requires a multi-model semi-automated annotation pipeline. SG-VLA (arXiv 2603.22760, March 2026) co-trains auxiliary decoders for grasp affordances, segmentation masks, robot pose, and joint configurations from shared VLA features, with ground truth extracted from ManiSkill-HAB simulator state — demonstrates that auxiliary affordance decoders improve VLA performance, but is limited to simulation environments with accessible ground-truth state. SpatialVLA (arXiv 2501.15830) uses Ego3D Position Encoding and Adaptive Action Grids pre-trained on 1.1M real-world episodes — focuses on 3D spatial encoding rather than affordance learning per se. **Annotation-free/unsupervised affordance (standalone)**: UAD (arXiv 2506.09284, Stanford, June 2025) distills affordance knowledge from large vision models and vision-language models into a task-conditioned decoder without manual annotations, training on rendered simulation objects and generalizing to real-world scenes — the closest work on annotation-free affordance for robot manipulation. However, UAD is a standalone module (not end-to-end VLA), still relies on foundation model distillation as its supervision source (requiring pretrained LVMs/VLMs), and its affordance predictions are not jointly optimized with action prediction. Our method differs fundamentally: end-to-end VLA integration with affordance jointly trained alongside action prediction, using paraphrase invariance rather than foundation model distillation, with no external models required beyond an LLM for offline paraphrase generation. **Affordance-augmented VLA inference**: AFI (arXiv 2512.07472, December 2025) uses 3D Spatial Affordance Fields as an on-demand inference-time plugin to help VLAs escape 'memory traps' — complementary to our approach but operates at inference time rather than training time, requires 3D reconstruction, and does not learn affordance representations end-to-end. **Action-level robustness methods**: RSS (arXiv 2601.04052, January 2026) uses Monte Carlo Syntactic Integration and Residual Affordance Steering at the action logit level, achieving 82.2% on pi0 (vs 52.4% baseline) and 90.0% on LIBERO-Plus — strong but explicitly operates at the action output level with no learned spatial affordance maps. LangForce/BayesianVLA (arXiv 2601.15197, January 2026) uses Bayesian decomposition into vision-only prior and language-conditioned posterior achieving 11.3% OOD improvement on SimplerEnv. RobustVLA (ICLR 2026) enforces action-level consistency under 17 perturbation types. **Instruction augmentation without spatial learning**: Shin (arXiv 2603.16044, March 2026) fine-tunes OpenVLA with LLM-generated synthetic instruction paraphrases via LoRA, improving linguistic robustness — demonstrates that paraphrase diversity helps VLA robustness, but learns no spatial representations and operates purely at the action/language level. Our method uses the same paraphrase generation insight but channels it into spatial affordance learning rather than direct action-level augmentation. **Standalone affordance modules**: INTRA (ECCV 2024, arXiv 2409.06210) uses ChatGPT-4-generated synonyms with interaction-relationship-guided contrastive learning for text-conditioned affordance maps, SOTA on AGD20K/UMD — directly anticipates our paraphrase-invariance idea for affordance but is disconnected from VLA action prediction. AffordanceSAM (April 2025, arXiv 2504.15650) extends SAM for affordance grounding, current SOTA on AGD20K — supervised, standalone. WSAG-PLSP (ICLR 2025) uses part-level semantic priors for weakly supervised affordance grounding — standalone, requires pseudo-label generation. RoboMAP (arXiv 2510.10912) generates adaptive affordance heatmaps for language-guided manipulation — standalone grounding module, not integrated into end-to-end VLA training. **Supervised affordance in VLAs**: CoA-VLA (ICCV 2025) integrates chain-of-affordance reasoning with supervised labels. GeneralVLA (arXiv 2602.04315) proposes a hierarchical VLA with externally supervised Affordance Segmentation Module. RT-Affordance (ICRA 2025) uses affordances as intermediate representations with supervised learning achieving 69% vs 15% baseline. **Diagnostic benchmarks**: LIBERO-Para (arXiv 2603.28301, March 2026) reveals 22–52pp VLA drops under paraphrasing — confirms the problem but proposes no solution and, to our knowledge, has not been used to evaluate any spatial VLA method (ST4VLA, PALM, SG-VLA, Spatial Forcing). **The critical gap**: No work learns spatial affordance maps within a VLA via pure self-supervision from demonstrations alone. ST4VLA uses web-scale grounding data; PALM uses multi-model annotation pipelines; SG-VLA uses simulator ground truth; Spatial Forcing uses 3D foundation model teachers; UAD uses foundation model distillation as a standalone module. Our method requires only robot demonstrations + LLM-generated paraphrases, integrates affordance learning end-to-end with action prediction, and explicitly optimizes for instruction invariance at the spatial representation level.

## Proposed Approach

We propose AffordInvar, which augments OpenVLA-OFT with a lightweight spatial affordance decoder trained jointly with the VLA via LoRA using two complementary self-supervised signals — requiring no affordance annotations, web-scale grounding data, simulator labels, or foundation model teachers. **Phase 0 — Paraphrase Quality Diagnostic (pre-experiment, ~2 hours compute)**: Before committing to full training, we operationalize a signal-strength diagnostic to validate that Qwen-3 paraphrases of LIBERO's templated instructions create sufficient diversity for meaningful self-supervised learning. Protocol: (1) Generate K=5 paraphrases per LIBERO task instruction (130 tasks × 5 = 650 paraphrases) using Qwen 3 with diversity-promoting prompting (requiring structural rephrasing, functional re-descriptions, and spatial re-framings — not just synonym substitutions). (2) Compute three diversity metrics: (a) lexical divergence via 1−BLEU between original and each paraphrase (higher = more diverse), (b) embedding divergence via 1−cosine similarity of instruction embeddings in the pretrained OpenVLA text encoder (higher = more distinct in model's representation space), (c) semantic preservation via NLI entailment score between original and paraphrase using an off-the-shelf NLI model (must remain high). (3) Categorize paraphrases into three tiers: Tier-1 trivial (BLEU > 0.7, embedding sim > 0.95 — pure synonym swaps), Tier-2 moderate (embedding sim 0.80–0.95 — structural rephrasing), Tier-3 deep (embedding sim < 0.80 — functional/spatial re-descriptions). (4) Estimate gradient signal strength: process a random subset of 20 tasks through the untrained VLA, extract layer-18 intermediate features for original vs. paraphrase pairs, and measure the KL divergence of resulting attention patterns — this directly estimates the magnitude of L_consist gradients at initialization. (5) Go/no-go decision: If >40% of paraphrases are Tier-2 or Tier-3 AND initial KL divergence is >0.1 nats → strong signal, proceed as planned. If 20–40% Tier-2+ OR KL 0.05–0.1 → moderate signal, proceed with augmented diversity prompting (re-generate weak paraphrases with stronger diversity constraints) and increased entropy regularization (lambda_H × 2). If <20% Tier-2+ AND KL < 0.05 → weak signal, activate contingency: supplement L_consist with trajectory contact heatmaps as lightweight supervision extracted from gripper state in demonstrations (contact points are detectable from gripper force/position data without manual annotation, adding ~0 annotation cost). This diagnostic costs ~2 hours of LLM inference + a few hundred VLA forward passes and could save 50+ GPU-hours if the signal proves insufficient. **Architecture**: The affordance decoder takes intermediate features from the VLA's 18th transformer layer (out of 32), which retain spatial structure before the final action-prediction layers. The decoder consists of 3 transposed convolution blocks (each: ConvTranspose2d 4×4 stride 2, GroupNorm, GELU) upsampling from 16×16 to 128×128 resolution, with text conditioning via the instruction embedding projected through a linear layer and channel-wise multiplied at each block (~8M parameters total, <0.12% of VLA backbone). Output is a sigmoid-activated 128×128 affordance heatmap. **Self-supervised signal 1 — Paraphrase invariance (L_consist)**: For each training episode, Qwen 3 generates K=3 semantically equivalent instruction paraphrases offline (selected from the Phase-0-validated pool, prioritizing Tier-2 and Tier-3 paraphrases for maximum gradient signal). During training, each paraphrase-image pair is processed through the VLA, and a symmetric KL divergence loss enforces identical affordance heatmaps across all K+1 instruction variants: L_consist = (1/C(K+1,2)) sum_{i<j} KL(h_i || h_j), extending SelfEQ's visual grounding consistency (CVPR 2024) from general VLM grounding to the VLA affordance domain. Unlike RSS which applies paraphrase averaging at the action logit level, we enforce consistency at the intermediate spatial representation level, providing richer structured learning signal. Unlike Shin (arXiv 2603.16044) who uses paraphrase augmentation for direct action-level robustness without spatial learning, we channel the paraphrase signal into explicit spatial affordance representations. Unlike ST4VLA's emergent robustness from web-scale spatial pre-training, we explicitly optimize for instruction invariance. **Self-supervised signal 2 — Cross-object affordance transfer (L_transfer)**: Episodes with semantically similar instructions (cosine similarity > 0.85 on instruction embeddings) but different target objects are mined as positive pairs; episodes with the same object but different interaction types serve as negatives. A contrastive InfoNCE loss on spatially-normalized affordance features encourages interaction-specific (not object-specific) affordance representations, enabling zero-shot transfer to novel objects — inspired by INTRA's interaction-relationship contrastive learning but operating on VLA-internal features with free-form instructions rather than predefined interaction labels. Unlike UAD which transfers affordance via foundation model distillation on rendered objects, our transfer emerges from contrastive learning on real demonstration data within the VLA itself. **Affordance-action integration**: The affordance heatmap is bilinearly downsampled to the action feature resolution and applied as an element-wise gate: action_features = action_features * sigma(W_g * affordance_features + b_g), where W_g is a learned linear projection (~0.5M parameters). This is architecturally similar to SG-VLA's auxiliary decoder approach but with a key difference: our decoder is trained entirely self-supervised while SG-VLA requires simulator ground truth for each auxiliary task. **Entropy regularization**: H_entropy = -lambda_H sum h_i log(h_i), preventing degenerate uniform or collapsed heatmaps. **Total loss**: L = L_action + alpha*L_consist + beta*L_transfer + lambda_H*H_entropy, where L_action is OpenVLA-OFT's continuous L1 action regression loss. **Evaluation**: (1) Manipulation success on LIBERO-Long (10 tasks, standard) and LIBERO-Para (paraphrase robustness, measuring PRIDE score) — to our knowledge, this would be the first evaluation of a spatial affordance VLA method on LIBERO-Para, though concurrent work may independently pursue this evaluation given LIBERO-Para's March 2026 release; (2) Zero-shot generalization to held-out object categories within LIBERO; (3) Held-out interaction type generalization: train without all 'opening' tasks and test on them, plus creative rephrasings via Qwen 3 using novel interaction vocabulary (e.g., 'unfasten the container' instead of 'open the drawer') to test whether affordance representations generalize to unseen interaction semantics; (4) Affordance transfer evaluation with fine-tuning protocol: (a) zero-shot application of the VLA-learned affordance decoder on AGD20K/UMD as an exploratory experiment assessing cross-domain affordance quality, and (b) fine-tuning only the affordance decoder on AGD20K while freezing the VLA backbone, testing whether VLA-learned representations provide useful initialization vs. training from scratch — this addresses the large sim-to-real domain gap; (5) Qualitative affordance map visualization and contact-point prediction accuracy on held-out LIBERO episodes. **Baselines**: (a) OpenVLA-OFT (vanilla, no affordance) — 97.1% LIBERO standard; (b) OpenVLA-OFT + RSS-style action-level paraphrase invariance (our reimplementation); (c) OpenVLA-OFT + Spatial Forcing (intermediate 3D alignment with VGGT teacher) — 98.5% LIBERO average (verified: Spatial 99.4%, Object 99.6%, Goal 98.8%, Long 96.0%); (d) PALM (semi-automated affordance annotation) — 91.8% LIBERO-Long; (e) ST4VLA (web-scale spatial grounding) — 95.9% LIBERO average; (f) INTRA affordance maps + OpenVLA-OFT policy (two-stage); (g) CoA-VLA (supervised affordance); (h) OpenVLA-OFT + synthetic instruction augmentation (Shin, arXiv 2603.16044 — paraphrase augmentation without spatial learning). Key comparison axes: (i) LIBERO-Para PRIDE scores — explicit spatial invariance training (ours) vs. emergent robustness (ST4VLA) vs. action-level invariance (RSS) vs. instruction augmentation without spatial learning (Shin); (ii) zero-shot novel object/interaction generalization where annotation-free affordance transfer should outperform annotation-dependent methods in out-of-distribution settings; (iii) annotation efficiency — competitive performance without any affordance labels, web-scale data, foundation model distillation, or 3D teachers. **Key hypotheses**: (a) Explicit paraphrase invariance at the spatial affordance level provides better PRIDE scores on LIBERO-Para than ST4VLA's emergent robustness from spatial grounding, RSS's action-level invariance, and Shin's instruction augmentation without spatial learning; (b) Self-supervised cross-object affordance transfer enables superior zero-shot generalization to novel objects compared to methods that learn object-specific supervised affordance features (PALM, SG-VLA) or distill from foundation models on rendered objects (UAD); (c) AffordInvar maintains OpenVLA-OFT's baseline performance on standard LIBERO (no degradation from the added affordance decoder and auxiliary losses), with primary gains concentrated on LIBERO-Para PRIDE and OOD generalization conditions — this is the appropriate hypothesis given standard LIBERO's saturation at 97–99% where marginal gains are noise; (d) VLA-learned affordance representations provide useful initialization for downstream affordance benchmarks, demonstrated by faster convergence when fine-tuning the decoder on AGD20K vs. training from scratch.
