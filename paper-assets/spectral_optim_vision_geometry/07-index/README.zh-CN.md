# 来源与文件索引

原始归档路径、发布文件、校验和、排除项和论文版本。

[返回项目说明](../README.zh-CN.md)

- [文件清单（CSV）](asset-manifest.csv)：原始路径、发布路径、文件大小和校验和。
- [快照摘要（JSON）](asset-manifest.json)：来源对象、数量、论文标题和资料范围。
- [排除项清单](excluded-files.csv)：未包含的归档条目。
- [版本索引](version-index.csv)：归档中的候选 PDF 及其来源路径。
- [来源对象覆盖范围](source-objects.json)：列出的备份对象及缺失项。

通过[完整文件清单](../07-index/asset-manifest.csv)查看发布文件及其原始归档路径。
