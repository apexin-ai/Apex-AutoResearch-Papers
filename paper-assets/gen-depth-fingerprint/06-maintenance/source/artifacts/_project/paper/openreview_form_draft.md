## Abstract (plain text, no LaTeX)

Text generated by large language models (LLMs) increasingly re-enters the web and seeds subsequent generation, producing recursive chains that progressively diverge from human-written text. As such text contaminates training corpora, distinguishing generation depth from binary authorship becomes important for data provenance. We study this phenomenon in base (pretrained) models and ask whether the drift is structured enough to classify how many generation steps a text has undergone, framing this as generation depth classification (gen-0/gen-1/gen-2+ rather than binary real-vs-synthetic). Across eight base models from five families (0.6B-8B parameters), we identify a differential depth response (DDR): features partition into drifting, intermediate, and near-stationary groups, consistent with recursive generation shifting the negative log-likelihood (NLL) location under a reference model while distributional shape remains stable. A 7-feature ensemble achieves leak-free binary F1 = 0.694 under leave-one-generator-out evaluation, generalizing across model families. The depth signal degrades substantially under instruction tuning, restricting current applicability to base models.
