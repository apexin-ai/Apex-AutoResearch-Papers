# Abstract — Draft v1 (A-source: plan-012-full, 11 tasks / 245 episodes)

\begin{abstract}
LLM agents in rule-governed interactive environments hallucinate state transitions---predicting outcomes of actions never executed---leading to catastrophic failures such as agent death. Deterministic external computation eliminates these hallucinations, but understanding \emph{what} drives the routing signal between internal reasoning and deterministic strategies remains unexplored. Standard per-step oracle labeling degenerates under sparse rewards: on ScienceWorld, 98.2\% of steps produce identical scores regardless of modality. We introduce \emph{episode-level counterfactual analysis}, comparing complete episode outcomes across strategies to generate routing labels. Across 11 task types (245 episodes) with Qwen2.5-7B-Instruct, deterministic computation outperforms internal reasoning by $\Delta_{\text{full}} = +29.60$ points. Excluding episodes where either strategy causes death, this gap collapses to $\Delta_{\text{no\_death}} = +2.84$---a Death Avoidance Factor of 90.41\%. The per-task correlation between death rate differential and performance gap is $r = 0.9698$ ($p = 8.12 \times 10^{-7}$). Oracle routing selects the deterministic strategy in 96.2\% of decisions. These results demonstrate that the value of deterministic computation concentrates overwhelmingly in failure prevention rather than positive task guidance.
\end{abstract}
