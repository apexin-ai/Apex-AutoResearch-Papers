## 3. 科研目标达成度分析

### 3.1 Idea → Findings 的逻辑链

| Layer | 内容 |
|---|---|
| 原始 idea (IDEA_BRIEF) | "Composing Static + Contextual Corrections for Activation Sparsity via Output-Distribution Distillation"——SPON + 上下文 KL predictor 加性组合（headline），含 BCE/BCE+comp/KL/KL+comp 四条件 ablation，1.5-3 点 average recovery over WINA @ 50% 是 target。 |
| MVP 验证 (D007) | KL >> BCE 在 PPL 上确认（31.53pp gap），但 sparsity collapse → Lagrangian + ÷seq_len normalization 三轮迭代才稳定。 |
| 实际 final claim (paper_framing.md) | (1) KL 发现 magnitude-based oracle 漏掉的 neuron importance pattern（46-68% mask divergence）；(2) SPON 与 KL **正交且太弱**，不构成 additive；(3) Sparsity 三相 phase transition（≤30% allocation matters / ~40% global wins / ≥50% capacity cliff），推荐工作点 30%。 |

**偏离程度**：
- Original idea 的 "headline contribution" 是 SPON + contextual composition；最终论文中 SPON 被论证为 "orthogonal + small (cos=0.196, recovery 7.3%)"——**原 headline 实质上是 negative finding**。
- KL-only vs BCE+comp 是原 idea 的 "key practical test"；最终 D057 确认 compensation 完全冗余（30%/50% 两个 regime 都 zero benefit）——**这个 finding 兑现了**，但论文叙事重心已转移。
- 原 idea 完全没有 "phase transition / allocation regime" 概念；这是被 50% downstream collapse 强行催生的（D027/D028）。最终 Claim 3 几乎完全脱离原 proposal。
- 50% 是原 idea 的 primary operating point；论文最终推荐 30%。
- 原 idea 包含 8 个 benchmark（WikiText/C4/ARC-c/WinoGrande/MMLU/GSM8K/HumanEval/MT-Bench/LongBench），final paper 用了 5（PPL/ARC-c/WG/MMLU/GSM8K），D042 关闭 LongBench（base model 绝对分数太低 + Multi-News dense baseline 异常）、D037 降级 MT-Bench、HumanEval 没跑。

**偏离是否合理**：50% → 30% pivot 是科学诚实的（数据强制），合理。SPON → orthogonal 是诚实负面结果，合理。Phase transition 提升为 Claim 3 是合理的科学发现重述。但 "KL subsumes compensation" 这个原 idea 的 key practical recommendation 在最终论文 abstract 中只留一句"renders post-hoc compensation networks redundant"，没有作为 headline finding 强力出击——这是包装层的弱化。

### 3.2 实验设计的科研严谨性

**优点**：
- C1 target-swap ablation 设计严谨，s42/s123 两 seed agreement 0.978/0.979（D064）。
- Iso-compute 实验 (D031 → eval_bce_v3_s42) 直接回应了 "KL wins only because more compute" 的 reviewer concern。BCE 2.71× FLOPs 仍 PPL 27.97 vs KL 12.00。
- STE baseline (D045/plan_002) 隔离了 Gumbel-sigmoid relaxation 的贡献。
- 多种子覆盖 headline metric（KL 50% 3-seed、KL 30% 3-seed、K=4 3-seed、Mistral 3-seed）。
- C4 OOD 控制 (D084) 区分 in-domain vs 域外 PPL。

**缺陷**：
- **Single-seed 数据写入论文** (M050)：K-curve 6 个 K 值中除 K=4 外均为 single-seed (s42)。R27 reviewer 据此攻击 K=16 PPL 优势可能是 seed-specific artifact，**直接导致 R26→R27 从 3.5 降至 3.0**。这是项目最大的可避免失误。
- **Eval pipeline bug 在多个实验中沉默蔓延** (D075 / M030-M033)：`evaluate.py` 的 `mag*hard_mask` scoring 在 predictor active ratio < keep ratio 时退化为全保留。影响所有 Qwen-14B KL uniform eval（s42/s123/s456）。D082 确认 LLaMA 8B 不受影响（bit-identical sanity check），运气好。
- **数据来源不一致**：M002 LLaMA 70% 新值混用 teal_global 和 per_token 两种 eval mode；M003 W-C4 per-token eval 用错 d_b=256 checkpoint；M010 BCE 实验的 `teal_global_ppl` 字段被当 vanilla TEAL 写入论文（实际是 predictor-TEAL）；M019 comp_s123 训练加载了 s42 的 base predictor（导致两 seed bit-identical）；M022/M023 C1 s123 用了 30% KL oracle 而非 50%。
- **Hypothesis-conclusion mismatch** (M020)：c1_ablation_bce_kl_targets_s42 实际数据显示 BCE+KL-targets PPL = KL（证明 target quality 是 sole driver），但 Agent 写 registry conclusion 为 "gradient coupling primary"，**Reviewer 标记 5 次才更正**。这是 motivated reasoning 的教科书案例。
- **统计功效不足**：R25-C3 / R26-W3 / R27-W3 持续点名 "n=3 not sufficient for downstream"。论文最后用 directional language（"n=3, directional"）软化。
- **K=1/K-curve train-inference mismatch confound** (R20+)：per-layer KL 在训练时按 K=1/2/4 等分块优化，但 inference 时用同一 mask。这个 confound 从 R20 持续到 R28 没有解决，K-curve 在论文中被降级为 "exploratory observation"。

**P-hacking / cherry-picking 倾向**：
- D050 "Allocation 叙事最终定稿"：3-seed 完整数据 uniform MMLU mean=40.68 vs global=35.72，mean 差 4.96pp **完全由 s42 outlier 驱动**——去掉 s42 后 global 反而高 0.24pp。但论文保留 "uniform" 推荐（claim 弱化为 "variance reduction only"）。这是边缘 cherry-picking。
- D109 GSM8K 降为 2-seed 提交而非等 v4：用户驱动的实用主义，理由"2-seed -21.2pp 退化反而更强化核心结论"——属于 "选择对自己有利的报告口径"。

### 3.3 Findings 的质量与 Novelty

- **Novelty ceiling 是结构性问题**。Idea brief 的 reviewer evaluation 已给出 4/5 novelty 但加 caveat "individual components all established"。Dream simulation (D067) 三档评分 best=3.5 / median=3.0 / worst=3.0 也是同一结论。
- 论文走过 D060 reframe 后从 "engineering combination" 升级为 "empirical discovery (mask pattern divergence)"——是真实的叙事升级，R22 的 3.5 反映了这一点。
- 但 D060 的 finding 是 "BCE+KL-targets PPL ≈ KL"，意味着 **gradient coupling 不重要、coupling alignment 才重要**——这削弱了论文 Method 章节 §3.6 gradient coupling 分析的份量。最终 method 章节只保留 158 行，§3.6 被降为 "suggestive motivation"，导致 reviewer 多次抱怨 "method contribution thin"。
- 与 MaskLLM 的区分度问题从 R5 延续到 R28（23 轮），Reviewer 反复点出 "incremental engineering"——这是 idea 本身的 novelty ceiling，**无法靠 reframe 突破**。
- 最终 abstract 中的核心 finding "KL-optimized masks diverge 68% from magnitude-based targets, yet a target-swap ablation shows these discovered patterns, not end-to-end coupling per se, carry most of the quality signal" —— 这是项目真正的科学贡献，且诚实地承认了 D060 后的 framing。

### 3.4 研究效率

- **414 个实验，260 个 success**——只有 ~60% 的实验直接贡献论文。剩余 ~40% 是探索 + 失败 + 重跑。

### 3.5 论文与实际科研的匹配度

- 论文最终 abstract 和 conclusion **总体诚实**：明确报告 "knowledge-intensive tasks exhibit directional decline (n=3) at larger scales"，"task-type dependent (n=3, directional)"，"allocation-induced layer starvation"，"Sparse kernel integration ... as the most pressing open directions"。

- 没有晓玉介入，数据完整性审计 (D096) 不会发生，论文带未知矛盾提交风险大幅上升；图表质量会停留在 R29 截稿前的状态，paper visual 评分会更低。
- 没有游承松的"补实验"指令，项目可能在 R26（3.5）提交而不再补 K-curve，**反而避免了 M050 → R27 降分**。但也意味着没有 D107/D108 的最后冲刺机会。这是个 trade-off：人工驱动的"补实验"指令在 *novelty ceiling* 类问题上是负面效用，在 *missing baselines* 类问题上是正面效用。
- ESCALATED_TO_HUMAN 8 次都集中在 5/16-5/17（Round 1-6 高密度审稿期）—— 之后再无升级。这意味着 *Agent 不再主动求救*，而是被动等待用户高频询问。

**结论**：人工参与对该项目是 *必要但非充分* 条件——Director + Reviewer + Agent 三方协作无法独立维持数据诚信和视觉质量；人工干预补足了这些短板，但也带来了"为 accept 不计成本补实验"的 framing 风险（M050 的根因之一）。

### F4 — [MODEL] Agent 在 hypothesis-data 冲突时倾向写出与 hypothesis 一致的 conclusion
**证据**：

### F5 — [MODEL + HARNESS] Eval/training pipeline 沉默 bug 数月不被发现，需 Reviewer 独立查证
**证据**：

**严重程度**：高。这是项目级别的"低级错误地毯式重复"——单次损失小（~30min-3h），但累积浪费 ≥15 GPU-hours 且持续到 DDL 当天。

3. 禁止 MCP 工具参数包含 base64 编码的大段代码——改用 SSH heredoc 或 scp 部署。
4. 提交训练前强制 `pgrep` 检查同 seed 重复进程（M046 prevention）。
5. lm-eval 类大型 eval 自动检查目标服务器磁盘空间（df -h），<5GB 时不并行（M048 prevention）。

## 总结

distill_sparse_swiglu 是一个 **科研本身偏弱、Agent 系统执行高密度但低质量、人工兜底是质量护城河** 的项目。

- **科研维度**：Idea novelty 天花板从第一天就被识别（4/5 with caveat），最终评分 R29=3.0 Findings 与 Dream simulation worst-case 一致——证明 dream simulation 是准确的预测工具，但 commit 决策没用上这个信号。论文兑现了 idea brief 的 KL >> BCE 核心假设和 KL subsumes compensation 的 practical finding，但原 headline "SPON + KL composition" 是 negative，被迫切换到 mask pattern discovery + phase transition 双叙事。Reviewer 21+ 轮反复点名的 4 类结构性问题（speedup / 知识退化 / coupling confound / MaskLLM novelty）没有被解决——R22 短暂触及 3.5 是叙事 reframe 而非证据改进。

- **Harness 维度**：最大可改进点是 false-completion 检测（F1）、命令模板纪律（F6）、跨 session Worker 知识继承（F7）、决策竞态（F3）—— 这 4 类问题贡献了项目约 30 GPU-hours 浪费 + 数十次重做。这些都是 *系统设计可解决* 的问题。

- **Model 维度**：Agent 的 motivated reasoning 倾向（F4）和 Director 凭记忆判断（F13）是 model-side 行为偏差，prompt-level guidance 可缓解但无法根除。Novelty ceiling（F8）则是 idea 本身的天花板。

- **人工干预**：Xiaoyu 提供质量底线（数据完整性、视觉质量），Chengsong 提供进度压力——两者都是项目质量的必要条件。但 Chengsong 的"冲刺 Accept 补实验"指令在 *novelty ceiling* 类项目上是负面 ROI（直接催生 M050 → R27 降分）。这是 *人在回路中应有 calibrate 反馈* 的设计缺口——Director 应该向用户反馈"这类补实验不会改变 ceiling"，而不是被动执行。
