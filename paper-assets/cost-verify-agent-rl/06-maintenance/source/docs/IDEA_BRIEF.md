## Core Problem

Recent work has established that RL can learn to selectively allocate test-time computation — reducing unnecessary reasoning (Leash, AdaCoT, SelfBudgeter), learning when to plan in agent environments (Learning When to Plan, arXiv 2509.03581), learning when to think via GRPO (TON, NeurIPS 2025; Thinkless, NeurIPS 2025), and managing tool-call budgets heuristically (BATS). AVA (TMLR 2026) dynamically allocates compute across search, sampling, and selective verification cascades using uncertainty-based heuristics at inference time. However, self-verification in interactive agents presents a distinct and unsolved challenge: (1) verification is a short, diagnostic action (~30-50 tokens) yielding a categorical assessment (positive/neutral/negative), unlike generative planning (100+ tokens, open-ended) or continuous reasoning (variable length); (2) the Self-Verification Dilemma (arXiv 2602.03485) demonstrates that most self-verification is confirmatory rather than corrective, yet no prior work trains agents to distinguish behaviorally-corrective from confirmatory verifications; (3) verification carries a built-in behavioral signal — whether the agent's subsequent action actually changes — enabling a novel training objective not applicable to planning or reasoning. Self-Guide (arXiv 2604.03098) proves that always-on self-guidance — a forward-looking verbal assessment that steers the next action — substantially improves agent RL (Qwen3-1.7B: +13.7 on WebShop, +8.6pp on ALFWorld), but applies this guidance at every step indiscriminately. RISE (arXiv 2505.13445, NeurIPS 2025) simultaneously trains problem-solving and self-verification via RL with verifiable rewards, but operates in single-turn reasoning, not interactive multi-step agents with irreversible actions. CoVe (arXiv 2603.01940) trains interactive tool-use agents via constraint-guided verification on τ²-bench, but uses external deterministic verifiers rather than learned self-verification selectivity. TON (arXiv 2505.16854, NeurIPS 2025) and Thinkless (arXiv 2505.13379, NeurIPS 2025) use GRPO for binary think/not-think decisions in VLMs and LLMs respectively, achieving up to 90% token reduction — but optimize single-turn reasoning with task-accuracy rewards only, without the behavioral-grounding signal unique to interactive verification. Practitioners deploying agent systems lack principled guidance on when self-verification is cost-optimal, and no framework exists to train agents that concentrate verification at steps where it behaviorally corrects their actions.

## Opportunity / Why Now

Self-Guide achieves strong agent performance with always-on self-guidance, with gains strongly dependent on model capacity: Qwen3-1.7B gains +13.7 on WebShop (63.0→76.7) and +8.6pp on ALFWorld (72.7→81.3), while the larger Qwen3-4B gains only +2.7 and +4.7pp respectively. This capacity-dependent headroom reveals that the guidance signal's value is highest for smaller, resource-constrained models — precisely the deployment scenario where verification cost also matters most. The Self-Verification Dilemma confirms that most verifications are confirmatory and wasteful but proposes only test-time retrieval heuristics, not learning-based solutions. Meanwhile, Learning When to Plan demonstrates that RL (PPO with fixed cost penalty) can learn when to allocate test-time compute for planning in Crafter environments, and AdaCoT achieves 69% token reduction via Pareto-optimal selective CoT triggering. TON and Thinkless demonstrate that GRPO can learn binary think/not-think decisions, achieving 50-90% token reduction in single-turn reasoning and basic agentic navigation (AITZ). AVA shows that uncertainty-based heuristic allocation can improve cost-reliability tradeoffs at inference time with API models. BATS shows budget-aware heuristics improve agent cost-performance Pareto frontiers. Yet NONE of these exploit the unique property of self-guidance/verification in interactive agents: the signal produces a behavioral consequence — whether the agent's subsequent action actually changes — that directly indicates whether the signal was decision-critical. This creates an opportunity for the Behaviorally-Grounded Informativeness-Aware Verification Reward (B-IAVR), which rewards guidance-verification episodes that lead to actual action changes rather than merely producing self-assessment labels. This behavioral grounding eliminates the gaming risk present in category-based rewards (where agents could produce false negative labels for bonuses) and is inapplicable to single-turn reasoning or heuristic allocation (where no comparable binary behavioral-change signal exists). The GRPO-based selective compute family (TON, Thinkless, AdaCoT) provides methodological precedent for the <VERIFY> triggering mechanism, but B-IAVR's behavioral grounding is a fundamentally different reward signal suited specifically to interactive environments with observable action consequences. Using Qwen3-1.7B as the primary model with verl-agent's GRPO infrastructure provides ample headroom (13.7-point WebShop gap, 8.6pp ALFWorld gap) for meaningful Pareto frontier analysis, with Qwen3-4B serving as a scaling analysis on ALFWorld (4.7pp gap) and as a ceiling test on WebShop (2.7pp gap — where the expected finding is that B-IAVR correctly learns to almost-never-verify when verification adds minimal value).

## Landscape (SOTA & Limitations)

Self-Guide (arXiv 2604.03098, April 2026) co-evolves policy and self-generated internal reward via GRPO on ALFWorld/WebShop/ScienceWorld — achieves strong gains that are capacity-dependent: Qwen3-1.7B gains +13.7/+8.6pp (WebShop/ALFWorld), Qwen3-4B gains +2.7/+4.7pp, Qwen2.5-7B-Instruct gains +11.8/+8.6pp. Importantly, Self-Guide's SG mechanism is forward-looking self-guidance — a verbal assessment that steers the next action — rather than backward-looking error verification. Always-on with no selectivity or cost modeling; our starting point and always-on baseline. Notably, Self-Guide reports no error bars, seed counts, or confidence intervals, making training variance unquantified. We reproduce Self-Guide's exact SG protocol in Component 1, then test whether selective deployment of this guidance signal (regardless of its forward- vs. backward-looking nature) improves cost-efficiency in Component 2. Learning When to Plan (arXiv 2509.03581, Sep 2025) is the closest methodological precedent for selective compute in agents: SFT+RL (PPO) with fixed cost penalty for binary plan/no-plan decisions in Crafter, demonstrating task-dependent 'Goldilocks' planning frequency. Key differences: (a) planning is generative and open-ended, while verification is diagnostic and brief with behavioral output; (b) fixed cost penalty vs. our Lagrangian adaptive cost + behaviorally-grounded informativeness; (c) no informativeness analysis. TON: Think or Not (arXiv 2505.16854, NeurIPS 2025) uses GRPO for binary think/not-think decisions via two-stage training (SFT with thought dropout → GRPO exploration) in VLMs. Achieves up to 90% token reduction on reasoning benchmarks and is also evaluated on the AITZ agentic navigation task (3.6K→0.9K tokens). Key differences: (a) primarily single-turn VLM reasoning and basic agentic navigation, not multi-turn interactive agents with irreversible environmental actions and sparse rewards; (b) task-accuracy reward only, no behavioral grounding or informativeness signal; (c) thought dropout SFT warm-start vs. our always-on verification capability warm-start from Self-Guide. The two-stage GRPO approach is methodological precedent for our Component 1→2 transition. Thinkless (arXiv 2505.13379, NeurIPS 2025) introduces DeGRPO (Decoupled GRPO) for binary <short>/<think> control tokens in LLMs. Achieves 50-90% reduction in long-chain thinking on math reasoning. Complementary to TON; differs from our work in the same ways (single-turn, no behavioral grounding). AVA: Anytime Verified Agents (OpenReview JMDCMf7mlF, TMLR 2026) dynamically allocates compute across search, sampling, and selective verification cascades under budget constraints using calibrated uncertainty estimation and value-of-information-guided search expansion with early exits. Evaluated on GSM8K, MATH, HotpotQA, HumanEval with API models (GPT-5, GPT-4o). Key differences: (a) inference-time uncertainty-based heuristic allocation, not RL-trained verification selectivity; (b) operates on single-turn reasoning tasks, not interactive multi-step agents; (c) relies on calibrated uncertainty rather than behavioral-change signals; (d) uses API models without fine-tuning. AVA addresses 'when to verify under budget constraints' at inference time; we train the selectivity into the model via RL with behavioral grounding. AdaCoT (arXiv 2505.11896, May 2025) frames when-to-reason as Pareto optimization via PPO with adaptive penalty, achieving 69% token reduction. Key differences: (a) single-turn reasoning, not interactive agents with irreversible actions; (b) CoT is continuous-length, verification is discrete binary with behavioral signal; (c) no informativeness reward. BATS (arXiv 2511.17006, Nov 2025) provides systematic study on budget-constrained agents using heuristic strategy adaptation. Key differences: (a) plug-in heuristic, not RL-trained; (b) tool-call budget, not step-level self-verification; (c) no verification quality analysis. RISE (arXiv 2505.13445, NeurIPS 2025) simultaneously trains problem-solving and self-verification via RL with verifiable rewards, showing self-verification behaviors emerge during reasoning. Key differences: (a) single-turn mathematical reasoning, not multi-turn interactive agents with irreversible environmental actions; (b) verification integrated into reasoning chain, not a discrete binary decision per step; (c) no selectivity mechanism or cost-quality tradeoff analysis. Uno-Orchestra (arXiv 2605.05007, May 2026) jointly optimizes task decomposition and worker selection via RL on multi-agent orchestration, achieving 77.0% macro pass@1 across 13 benchmarks at 10× lower cost. Key differences: (a) routing/delegation across models, not intra-agent self-verification; (b) optimizes worker selection, not verification timing; (c) no self-check informativeness signal. CoVe (arXiv 2603.01940, March 2026) trains interactive tool-use agents via constraint-guided verification on τ²-bench, achieving 43-59% pass@1 competitive with 17× larger models. Key differences: (a) uses external deterministic constraint verifiers, not learned self-verification; (b) verification quality defined by constraint satisfaction, not behavioral correction; (c) does not learn WHEN to verify — constraints are always applied during training. ReVeal (arXiv 2506.11442) introduces TAPO (Turn-Aware Policy Optimization) for code agents, preventing reward gaming via turn-level credit assignment. Relevant methodology: our B-IAVR's behavioral grounding similarly prevents gaming by tying rewards to action changes rather than self-check labels. iStar (arXiv 2509.19199) combines implicit step rewards with episode-level advantages for agent RL credit assignment on WebShop, achieving efficient exploration. Relevant to our step-vs-episode reward design. GiGPO (arXiv 2505.10978, NeurIPS 2025) introduces two-level grouping (episode + step) for fine-grained credit assignment in verl-agent, achieving >12% gains on ALFWorld and >9% on WebShop over GRPO. Complementary to our approach — we use GRPO for consistency with Self-Guide baselines, but GiGPO integration is natural future work. Leash (arXiv 2512.21540, Dec 2025) uses Lagrangian primal-dual adaptive penalty to reduce reasoning length by 60%; we adopt this for verification budget control. SelfBudgeter (arXiv 2505.11274) trains two-phase GRPO for token budget estimation; latest arXiv revision (v6, April 2026) remains under review. AutoThink (arXiv 2505.10832, NeurIPS 2025) learns reasoning mode switching via multi-stage RL. Self-Verification Dilemma (arXiv 2602.03485, Feb 2026) identifies confirmatory over-verification; our B-IAVR operationalizes this insight via behavioral grounding. Agentic Critical Training (arXiv 2603.08706, March 2026) trains self-reflection via RL without cost modeling. LLMs Gaming Verifiers (arXiv 2604.15149, April 2026) demonstrates that RLVR-trained models can exploit verification signals for reward hacking, validating our concern about category-based IAVR and motivating the behavioral grounding in B-IAVR. KEY POSITIONING: The GRPO-based selective compute family (TON, Thinkless, AdaCoT) provides strong methodological precedent for learning binary compute-allocation decisions, but operates in single-turn settings without behavioral grounding. AVA provides the closest 'when to verify under budget' framing but uses inference-time heuristics rather than RL-trained selectivity. Unlike all prior work on selective compute allocation and concurrent work on agent verification, B-IAVR introduces a behaviorally-grounded training objective that rewards verification only when it changes the agent's action — exploiting the unique causal structure of self-guidance in interactive environments where actions have observable consequences.

## Proposed Approach

Three-component framework introducing the Behaviorally-Grounded Informativeness-Aware Verification Reward (B-IAVR) for training agents that verify selectively at decision-critical steps. Primary model: Qwen3-1.7B (large headroom: +13.7 WebShop, +8.6pp ALFWorld). Secondary model: Qwen3-4B (scaling analysis on ALFWorld with 4.7pp headroom; ceiling test on WebShop with 2.7pp headroom).

**Terminological note on forward guidance vs. backward verification:** Self-Guide's SG mechanism is forward-looking self-guidance (steering the next action) rather than backward-looking verification of previous actions. We reproduce this exact mechanism in Component 1. B-IAVR is agnostic to this distinction: the behavioral grounding — whether the agent's action changes post-assessment — applies equally to forward guidance ('should I do X?') and backward verification ('was my plan correct?'). We retain the <VERIFY> token and verification framing because (a) the mechanism functionally verifies the agent's default action choice before committing to it, and (b) this connects to the broader literature on selective verification (AVA, RISE, CoVe). The framework and all results apply to any self-assessment mechanism that influences subsequent actions, regardless of whether it is framed as forward guidance or backward verification.

**Compute scope:** Full 7-baseline comparison is conducted for Qwen3-1.7B only. Qwen3-4B scaling analysis compares B-IAVR sweep points (from Component 2) against the always-on SG baseline (from Component 1) and Self-Guide's reported no-SG performance as reference lower bound, requiring no additional baseline compute beyond Component 1 and Component 2 sweeps. This makes the total compute budget unambiguous and keeps all experiments within the 200h H100 ceiling.

**Seed protocol:** Each (model, β, α) configuration is trained with 1 training seed and evaluated across 3 evaluation seeds with fixed episode sets. For the final best-performing B-IAVR configuration (Qwen3-1.7B, both environments), 3 independent training seeds are run as a robustness check, each evaluated across 3 evaluation seeds, reporting mean ± std across training seeds with 95% stratified bootstrap CIs using the rliable framework (Agarwal et al., NeurIPS 2021). Training seed variance is acknowledged as a limitation of the sweep configurations (1 training seed each); all checkpoints are released for full reproducibility. We note that Self-Guide reports no error bars, seed counts, or confidence intervals, making our protocol strictly more rigorous and our statistical claims more defensible (cf. Henderson et al., AAAI 2018 on the importance of multiple training seeds in deep RL).

**Component 1 — Self-Guidance Capability Acquisition (warm-start):** Train Qwen3-1.7B (primary) and Qwen3-4B (secondary) with GRPO on WebShop and ALFWorld with always-on self-guidance at every step, following Self-Guide's SG protocol. Both environments are directly supported by verl-agent. Self-guidance format: pre-action assessment (~30-50 tokens) categorized as positive/neutral/negative with reasoning and action recommendation. Duration: 50 GRPO training steps per environment per model. After Component 1, checkpoints serve as always-on self-guidance baselines. Expected targets: Qwen3-1.7B ~76.7 on WebShop, ~81.3% on ALFWorld; Qwen3-4B ~87.0 on WebShop, ~91.4% on ALFWorld (reproducing Self-Guide's GRPO w/ SG). Methodological note: like TON's two-stage approach (SFT thought dropout → GRPO), our Component 1→2 transition first establishes the capability, then trains selective deployment — but our warm-start is via always-on GRPO (reproducing Self-Guide) rather than SFT with dropout, because the guidance capability requires RL-trained quality, not just format familiarity.

**Component 2 — Behaviorally-Grounded Selective Self-Guidance (primary methodological contribution):** Convert always-on self-guidance to optional <VERIFY> action. When the agent generates <VERIFY> as the first token, the self-guidance subroutine is triggered; otherwise no self-guidance occurs. Two mechanisms:

(a) *Lagrangian Verification Budget Control* (adapted from Leash): maximize task reward subject to verification budget E[n_verify / n_steps] ≤ β. Dual variable adapts: λ_{t+1} = max(0, λ_t + η · (mean_verify_rate - β)).

(b) *Behaviorally-Grounded IAVR (B-IAVR)* — primary innovation: verification reward is conditioned on whether the self-guidance actually changes the agent's action, not merely on the self-assessment's categorical label. Before the self-guidance step, save the agent's top-1 action from the policy (the action it would take without guidance). After guidance, compare with the action actually taken. Formally: r_step(t) = -λ · 1[verify_t] + α · 1[verify_t ∧ action_changed_t], where action_changed_t = 1 iff the post-guidance action differs from the pre-guidance greedy action.

**Semantic action deduplication:** action_changed is computed over canonicalized action representations rather than raw token sequences. In WebShop, actions are canonicalized by normalizing whitespace and casing in click[element] and search[query] arguments. In ALFWorld, actions are canonicalized by mapping to (verb, object, receptacle) tuples, collapsing syntactic variants of the same semantic action (e.g., 'put apple in/on fridge' → (put, apple, fridge)). This prevents gaming via superficial token-level variations of semantically identical actions.

**Equivalent-action robustness:** In environments where multiple actions are equally optimal at a given step (e.g., ALFWorld tasks with redundant valid object placements), the diagnostic perturbation analysis yields E[Δ_t] ≈ 0, indicating that action changes at those steps carry no task reward cost. However, gaming at such steps remains unprofitable: the agent collects the α bonus but pays the -λ verification cost, and the Lagrangian mechanism ensures λ adjusts upward when the verification budget is exceeded. The agent can only profit from gaming at steps where both (a) verification is triggered AND (b) the action change has zero cost — a scenario where the verification was arguably informative, since it revealed genuine action ambiguity that the agent's default policy did not resolve deterministically. We empirically validate this by measuring the fraction of steps with unique vs. multiple optimal actions in both environments during the anti-gaming diagnostic phase: WebShop's narrow action space (search[query], click[element]) has limited equivalence (search reformulations are the primary source); ALFWorld has moderate action redundancy at navigation and placement steps, consistent with findings from the DPEPO literature on action repetition in text-game environments.

This behavioral grounding provides three advantages over category-based IAVR: (i) Gaming-resistant by construction — the agent cannot collect the α bonus without actually changing its behavior, and changing to a worse action decreases task reward, creating automatic counterbalance. At equivalent-action steps, the verification cost λ still applies, preventing exploitation. (ii) More accurate informativeness measure — a negative self-assessment that doesn't change the action was informationally redundant; a positive self-assessment that unexpectedly changes the action captured genuine uncertainty. (iii) Environment-grounded — tied to observable behavioral consequences rather than potentially unreliable self-assessment labels (cf. LLMs Gaming Verifiers, arXiv 2604.15149).

**Anti-gaming formal analysis:** Gaming requires collecting α bonus via unnecessary action changes. An unnecessary change at step t means switching from the correct action to an incorrect one, incurring expected task reward loss Δ_t. Gaming is unprofitable when α < min_t E[Δ_t]. We estimate E[Δ_t] empirically via a diagnostic phase: randomly perturb 10% of actions in trained trajectories and measure mean task reward degradation per perturbation. This yields a principled upper bound for α. For steps where E[Δ_t] ≈ 0 (equivalent optimal actions), the Lagrangian cost -λ ensures that gratuitous verification is penalized even when action changes are free. We additionally conduct an α sensitivity sweep: α/E[r_task] ∈ {0.01, 0.05, 0.1, 0.2} (4 values; the 0.5 endpoint is dropped as it likely falls in the gaming regime and exceeds the empirical α threshold) to map the gaming-resistance frontier and identify the optimal α.

Budget target sweep: β ∈ {0.1, 0.2, 0.3, 0.5} (4 values; β=0.7 dropped to accommodate 3-training-seed robustness check within the 200h compute ceiling), each trained for 50 GRPO steps from Component 1 checkpoint, across both models, to map Pareto frontiers.

**Component 3 — Multi-Scale Pareto Analysis and Verification Characterization:** For each (model, β) pair, measure: (a) task performance; (b) mean verification rate and total verification tokens; (c) verification informativeness — fraction of verifications that are behaviorally corrective (action_changed). Plot Pareto frontiers for both models. Key analyses: (i) Compare verification informativeness under B-IAVR vs. Lagrangian-only vs. always-on — if B-IAVR produces substantially higher per-verification informativeness, this demonstrates learned verification quality improvement. (ii) Cross-model scaling analysis on ALFWorld (primary, 4.7pp headroom for 4B): how does optimal β shift from 1.7B to 4B? Hypothesis: larger models need less verification (lower optimal β), consistent with capacity-dependent headroom from Self-Guide. (iii) WebShop ceiling test for 4B (2.7pp headroom): report whether B-IAVR correctly learns to almost-never-verify when verification adds minimal value — this reframing (showing that the learned policy recognizes when verification is unnecessary) strengthens the paper's narrative about principled allocation rather than weakening it. With only 2.7pp gap, the expected finding is that selective verification converges to very low β, validating B-IAVR's behavior
