# Control B (Label Permutation) 实验分析报告

## 实验设计

将 temporal distance 标签随机打乱后训练 probe。若 probe 学到真实信号，打乱标签后 ρ 应≈0。

- 500 trajectories, 33 layers, dim=4096
- Split: 400 train / 100 val
- Pairs: 200K train / 50K val

### ρ 下降幅度

| 模型 | 真实→打乱 ρ 下降 |
|------|------------------|
| Trained OpenVLA | 0.955 → 0.013 (−98.6%) |
| Untrained OpenVLA | 0.933 → 0.009 (−99.0%) |
| DINOv2 | 0.554 → 0.039 (−93.0%) |

## 结论

**Control B 验证通过。** 两个 VLA probing 实验的 label permutation 控制组 ρ 均≈0（最大 |ρ|=0.013），R² 均为负值（≈chance level），MAE 无改善（≈0.2475，与随机猜测一致）。

这确认了：
1. **Trained OpenVLA probe（ρ=0.955）学到的是真实的 temporal distance 信号**，不是过拟合数据特征
2. **Untrained OpenVLA probe（ρ=0.933）同理**，probe 捕获的是 features 中的真实结构
3. VLA 的 control B 结果（ρ≈0.01）甚至比 DINOv2 的 control B（ρ=0.039）更干净，进一步说明 VLA probe 的有效性
