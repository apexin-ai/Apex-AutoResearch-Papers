Full-width academic pipeline figure for an EMNLP 2026 paper (figsize 14x4.2 inches, 300 DPI).
This is the "hero figure" (Figure 1) — it must look like it belongs in a best-paper at a top NLP venue.

NARRATIVE: A Python function and its test input are executed to produce a raw execution trace (hundreds of lines). Different "trace conditions" extract varying amounts of diagnostic information from this raw trace — from nothing (no_trace: code only) to everything (full_trace: complete line-by-line log). Each representation is paired with source code and fed to an SFT language model to predict the test verdict (pass/fail). The key finding: compact exception summaries achieve 99%+ accuracy, while verbose complete traces degrade performance to 72-82%.

LAYOUT: Horizontal left-to-right flow. Four logical stages. The center "Trace Conditions" stage is the visual focal point (~45% of width), fanning out vertically into 4 parallel paths.
