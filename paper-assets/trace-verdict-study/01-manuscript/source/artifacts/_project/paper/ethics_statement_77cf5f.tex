\section*{Ethics Statement}

This work uses publicly available datasets (HumanEval, MBPP, and DebugBench) consisting of programming problems and their test suites. No human subjects are involved in our experiments. All execution traces are generated by running code against automated test cases in sandboxed environments, posing no privacy or safety risks.

Our fine-tuned models predict test verdicts (pass/fail) from execution traces and do not generate executable code. The models are trained on synthetic data derived from deterministic program executions, with no personally identifiable information.

We acknowledge that automated verdict prediction could be misused to bypass testing workflows. However, our approach is designed to \emph{augment} developer feedback loops by providing faster diagnostic signals, not to replace rigorous software testing practices.

All experiments were conducted on two RTX PRO 6000 Blackwell GPUs, with each experiment using a single GPU. We report complete hyperparameters, random seeds, and statistical significance tests to ensure reproducibility.
