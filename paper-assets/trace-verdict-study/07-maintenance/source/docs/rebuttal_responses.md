### Response to "Finding is predictable from Information Bottleneck theory"

We appreciate this connection to information-theoretic foundations. While IB theory directionally predicts that compressed representations can improve task performance, our contribution lies in the *quantitative decomposition* that IB alone cannot predict. Specifically, our gradient masking experiment (§5.3) isolates content quality as responsible for 97% of the full_trace performance degradation, with gradient dilution accounting for only 3% — a ratio that has no IB-theoretic prior. Furthermore, our budget curve analysis (Figure 3) reveals a sharp phase transition at 384–512 tail tokens, where accuracy jumps 13–22 percentage points across all four model architectures. This positional criticality — diagnostic signal being concentrated in a narrow token window near exception events — is an empirical finding about execution trace structure that IB theory does not address. Additionally, our exception subcomponent decomposition (Table 4) reveals a novel loss-accuracy decoupling: `exc_message_only` exhibits 60× higher token-level eval loss than `exc_type_only` (0.58 vs. 0.01), yet verdict accuracy drops by only 0.33pp (99.50% vs. 100%). This dissociation between representation uncertainty and classification performance is not predicted by IB's rate-distortion framework.

### Response to "Task too easy — regex baseline achieves 99.33%"

We thank the reviewer for raising this point, which our paper directly addresses through systematic controls. The regex baseline's 99.33% accuracy relies entirely on format markers (e.g., `[PASS]`/`[FAIL]` tags). Our marker removal ablation (Table 2) demonstrates that removing these markers causes regex accuracy to collapse to 28.49% (−71pp), while SFT accuracy decreases by only 2.18pp to 97.65% in-distribution and 95.46% cross-dataset (HE→MBPP). This 67pp gap between regex and SFT under marker removal definitively shows that SFT learns semantic code reasoning rather than surface pattern matching. Furthermore, calibration analysis (§5.4) reveals that SFT achieves ECE = 0.0027 vs.\ 0.171 for no\_trace — a 63× gap — indicating well-calibrated predictions incompatible with shortcut exploitation. Finally, SFT demonstrates cross-dataset generalization (exception_only: HE→MBPP = 99.41%, MBPP→HE = 100%, Table 3), a capability that regex fundamentally lacks. The regex baseline serves as an essential tautological control that validates the non-trivial nature of SFT's learned representations.

### Response to "Narrow scope — only Python, HumanEval, MBPP"

We acknowledge the language and benchmark scope, which is explicitly discussed in our Limitations section. Within this scope, we provide extensive validation across multiple axes of generalization. First, our cross-dataset experiments (Table 3) demonstrate strong transfer: exception_only achieves 99.41% on HE→MBPP and 100% on MBPP→HE, despite substantial differences in coding style between algorithmic (HumanEval) and practical (MBPP) problems. The minimal accuracy drop (0.4pp for HE→MBPP) indicates that the model learns transferable code reasoning rather than dataset-specific patterns. Second, we validate across four model architectures spanning an order of magnitude in parameters: Qwen2.5-Coder-7B, Qwen2.5-Coder-1.5B, DeepSeek-Coder-6.7B, and CodeLlama-13B. The diagnostic tier hierarchy (exception > full_trace > no_trace) holds consistently across all architectures (§5.1). Third, supplementary validation on DebugBench (Appendix) extends coverage to diverse bug types. The Python focus is a deliberate design choice: execution trace formats are language-specific, and our trace collection infrastructure targets Python's traceback system. Extending to other languages requires redesigning the trace instrumentation — meaningful future work that is beyond the scope of this controlled study.

### Response to "Gradient masking only validated on one model"

We appreciate this observation and have conducted cross-architecture validation since submission. The primary result on Qwen2.5-Coder-7B-Instruct (3 seeds: 99.22% ± 0.20% under 99.8% mask; dilution ≤4% of the 18.07pp gap) is robust, with near-zero seed variance demonstrating that content quality — not gradient dilution — accounts for ≥96% of the full-trace degradation. Cross-architecture validation on two additional families provides directional support: DeepSeek-Coder-6.7B-Instruct achieves 99.33% (single seed) and CodeLlama-13B-Instruct achieves 100% (single seed) under 99.8% masking, both well above the full-trace range (77–82%). We note that DeepSeek shows higher seed variance under aggressive masking (preliminary seed123: 93.95%), suggesting architecture-dependent sensitivity to gradient signal sparsity; even this lower bound remains 14.8pp above full-trace, consistent with content quality being the dominant factor. The Qwen-7B result (3 seeds, std=0.20pp) provides the most reliable quantitative decomposition, while the cross-architecture results confirm the qualitative finding that masking most gradient updates preserves high accuracy across model families.

### Response to "Why not larger models (30B+)?"

We thank the reviewer for this suggestion. Our study covers models spanning an order of magnitude in parameters (1.5B to 13B), and we observe consistent trends across this range: the diagnostic tier hierarchy and phase transition patterns hold for all four architectures (§5.1, Figure 3). Our core research question concerns the *information-theoretic properties of execution traces* — specifically, which trace components carry diagnostic signal, where this signal is located, and how much is sufficient. These are properties of the input signal rather than model capacity. Indeed, our results suggest that larger models primarily strengthen the implicit pathway: the no_trace condition shows increasing lift over the majority baseline as model size grows (Qwen-1.5B < DeepSeek-6.7B < Qwen-7B < CodeLlama-13B), while the explicit pathway saturates near 100% regardless of scale. Scaling to 30B+ models would require multi-GPU setups with quantization (QLoRA), introducing confounding variables (quantization error, communication overhead) that would complicate the controlled analysis of trace information value. This limitation is discussed in our Limitations section.

### Response to "Single-seed baselines — results may not be robust"

We appreciate the reviewer's emphasis on reproducibility. We conducted 3-seed validation (seeds 42, 123, 456) for three key conditions. For the explicit pathway (exception_only with gradient masking, §5.3), accuracy is 98.99%, 99.33%, and 99.33% (mean = 99.22% ± 0.20%), demonstrating exceptional stability. For the full_trace condition (Table 1), accuracy is 81.76%, 79.58%, and 80.50% (mean = 80.61% ± 1.09%), confirming reproducible intermediate performance. For the implicit pathway (no_trace), accuracy is 75.13%, 79.08%, and 75.04% (mean = 76.42% ± 2.31%), showing higher but expected variance under weaker learning signals. Notably, we observe a monotonic relationship between diagnostic signal strength and seed variance: exception_only (std = 0.20%) < full_trace (std = 1.09%) < no_trace (std = 2.31%). This pattern is itself informative — stronger diagnostic signals lead to more deterministic learning outcomes. All pairwise gaps between conditions remain statistically significant across seed combinations. Additionally, our Holm-Bonferroni correction (80 pairwise comparisons, 67/80 significant) and bootstrap analysis accounting for problem-level clustering (effective n = 119 unique problems) provide further statistical robustness beyond seed variation. We note that the rebuttal full_trace data (80.61% ± 1.09%) reflects a corrected truncation implementation (v5, chat-template-aware) that eliminates a subtle misalignment in chat template handling; the submitted Table 1 reports the original series (81.44% ± 1.11%). The 0.83pp difference is consistent within seed variance and directionally strengthens the reported degradation pattern.

### Response to "Tautological learning — model memorizes exception format markers"

This concern motivates our meta-finding MF-2 and its supporting experiments, which we designed specifically to address the near-tautological learning hypothesis. We provide five independent lines of evidence against pure marker memorization. (1) **Marker removal** (Table 2): removing format markers reduces SFT accuracy by only 2.18pp (99.83% → 97.65%), whereas regex collapses by 71pp (99.33% → 28.49%), demonstrating that SFT's performance is grounded in semantic understanding rather than surface patterns. (2) **Cross-dataset marker removal**: in the more challenging HE→MBPP transfer setting, nomarker SFT still achieves 95.46%, ruling out dataset-specific marker memorization. (3) **Exception subcomponent ablation** (Table 4): each individual subcomponent — exception type (100%), stacktrace (99.83%), and error message (99.50%) — independently achieves near-perfect accuracy, showing the model processes exception *semantics* at multiple granularities. (4) **Calibration analysis** (§5.4): SFT achieves ECE = 0.0027 vs.\ 0.171 for no\_trace (63× gap), demonstrating probabilistically calibrated predictions incompatible with shallow pattern matching. (5) **Cross-dataset transfer** (Table 3): HE→MBPP = 99.41% and MBPP→HE = 100% with entirely different code distributions but identical marker formats — if the model relied solely on markers, cross-dataset accuracy should be ~100% regardless; the slight drop with marker removal confirms genuine code-level reasoning.
