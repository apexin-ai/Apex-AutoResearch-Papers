## 3. Dataset Split Details

### Main dataset (HumanEval + MBPP-sanitized)
- **Problems**: 591 unique (164 HumanEval + 427 MBPP-sanitized)
- **Candidate solutions**: Generated by Qwen-2.5-Coder-7B-Instruct (10 per problem)
- **Total samples**: 5,910 (591 × 10)
- **Train/test split**: 80/20 → 4,720 train / 1,190 test
- **Class distribution**: ~71.51% pass / ~28.49% fail (majority baseline = 71.51%)
- **Deduplication**: Applied to training set (exact-match on normalized code)

### DebugBench dataset
- **Source**: DebugBench (Tian et al., 2024) — synthetically injected bugs in LeetCode solutions
- **Bug types**: logic errors, reference errors, syntax errors
- **Train/test split**: 1,622 train / 426 test
- **Class distribution**: ~51.41% pass / ~48.59% fail (near balanced)

## 4. Random Seed Strategy

- **Primary seed**: 42 (all conditions)
- **Robustness seeds**: 123, 456 (selected conditions)
- **Seed-tested conditions**:
  - exception_only (Qwen): seeds 42/123/456 → 99.83% ± 0.00 (perfectly robust, 2/1190 identical errors across all seeds)
  - exception_only (DeepSeek): seeds 42/123/456 → 99.33%/91.09%/99.33% (seed 123 outlier, LoRA initialization sensitivity)
  - VOTA (Qwen): seeds 42/456 → 99.41%/99.08%
  - ae_only (Qwen): seed 42 → 99.92%; seeds 123/456 in progress
  - label_only: seed 42 only (seeds 123/456 planned)
- **Other conditions**: single seed (42)

## 5. Evaluation Metrics Definitions

| Metric | Definition |
|--------|-----------|
| **Accuracy** | Fraction of correctly classified samples (pass/fail) |
| **Pass/Fail Precision** | TP/(TP+FP) for each class |
| **Pass/Fail Recall** | TP/(TP+FN) for each class |
| **Pass/Fail F1** | Harmonic mean of precision and recall per class |
| **95% CI** | Wilson score interval for accuracy |
| **ECE** | Expected Calibration Error — weighted average of |accuracy − confidence| across 10 equal-width bins |
| **MCE** | Maximum Calibration Error — max |accuracy − confidence| across bins |
| **Brier Score** | Mean squared error between predicted probability and true label |
| **McNemar's Test** | Paired test for significance of accuracy difference between two models on same test set (with continuity correction) |
| **Paired Bootstrap** | 10,000 bootstrap resamples, percentile CI, paired on sample IDs |
