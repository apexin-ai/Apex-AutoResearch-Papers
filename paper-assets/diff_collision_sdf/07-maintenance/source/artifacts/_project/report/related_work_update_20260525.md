# Related Work Literature Update (2026-05-25)

## Direction 1: Collision-aware manipulation
1. **CoFreeVLA** (Zhai et al., 2026) — External risk estimator post-hoc filtering vs ColliForce training-time SDF (internal vs external)
2. **APEX** (Dastider et al., IROS 2024) — Latent diffusion + classifier-guidance collision avoidance (test-time vs train-time)
3. **Safe Learning Survey** (Zhang et al., 2025) — Positioning framework: constrained RL / CBF / MPC shields → ColliForce = "training-time geometric supervision"

## Direction 2: SDF in robotics
1. **Configuration Space Distance Fields** (Li et al., RSS 2024) — C-space SDF, addresses EE-only limitation directly
2. **SDF-SC** (Liu et al., 2024) — Full-body SDF + SVM self-collision, engineering feasibility for future work
3. **Neural NMPC-SDF** (Jacquet et al., IJRR 2025) — SDF in control vs policy loss, complementary integration paths
