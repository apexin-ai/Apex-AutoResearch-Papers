\begin{abstract}
Vision-Language-Action (VLA) models generate manipulation trajectories from visual observations and language instructions, but frequently collide with non-target objects in cluttered workspaces. Existing collision-safe approaches either apply post-hoc corrections to already-generated trajectories or rely on reinforcement learning without geometric reasoning, leaving the VLA's internal representations collision-ignorant. We propose ColliForce-VLA, which integrates a differentiable workspace Signed Distance Field (SDF) into the VLA forward pass for collision-aware action generation. Two lightweight modules, an SDF Decoder (${\sim}$395K parameters) and an End-Effector Extractor (${\sim}$263K parameters), are attached to the action expert of $\pi_0$, a 3.5B-parameter flow-matching VLA. During training, for near-collision samples, we compute the SDF gradient in feature space and perform gradient ascent to produce collision-corrected action targets; a refinement loss trains the LoRA parameters (${\sim}$33.5M) to reproduce these targets directly. At inference, the default path requires only the base model with trained LoRA adapters, adding no extra modules or computation.
