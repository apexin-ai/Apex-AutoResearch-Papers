- **PALADIN 的 confound**：其 +57pp 中 ~30pp 来自 inference-time retrieval，不是纯 SFT。paper 中必须讨论这个 confound
- 所有 pairwise comparison 修正后均不显著——paper 措辞必须是 "directional but not statistically significant"
