\section*{Limitations}

We evaluate on a single environment (ALFWorld, 47 tasks) with one base model. Three seeds provide limited statistical power; the 10\% dose-response uses a single seed (25\%/50\% confirmed across 3 seeds). TaxEI/Random use $2.1\times$ more training data than Vanilla; the fixed-size ablation controls for this. Per-operator analysis ($N{=}11$--$12$) is exploratory. ALFWorld provides immediate binary feedback (``Nothing happens'') but not diagnostic feedback indicating error type or correction direction, partially resembling tool-use error observability. Vision-based embodied tasks with continuous state spaces may exhibit different error injection dynamics. We compare only error injection variants; other augmentation strategies (e.g., paraphrasing, trajectory diversification) were not tested, leaving open whether the negative result generalizes to all off-distribution augmentation at this data scale.
