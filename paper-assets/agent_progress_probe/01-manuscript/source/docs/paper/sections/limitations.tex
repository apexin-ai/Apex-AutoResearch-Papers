\label{sec:limitations}

\paragraph{Scope.}
We evaluate two software engineering coding agents (SWE-Agent and OpenHands) on SWE-bench.
Cross-coding-agent transfer is demonstrated between these two agents.
A pilot on ALFWorld (Appendix~\ref{sec:app_nonse}) suggests 23/30 features transfer to non-SE domains, but full evaluation with domain-specific gold labels remains future work.

\paragraph{Third-agent transfer.}
Extending the pipeline to a third coding agent (ACR; Appendix~\ref{sec:app_acr}) reveals that LF portability---not model architecture---is the transfer bottleneck: 2 of 4 adapted LFs achieve zero coverage, and adapted LFs yield inconsistent gains across classifiers (RF $+$10.4\,pp, GB $-$3.6\,pp).
Each new agent likely requires agent-specific LF design.

\paragraph{Silver labels.}
Silver-label evaluation dominates this study; while a 505-window gold set provides partial non-circular validation (\S\ref{sec:gold_set}), the primary metrics in Tables~1--5 remain silver-evaluated, and the structural RF's 0.995 macro-F1 reflects LF-reconstructibility rather than ground-truth detection accuracy.
Moderate inter-annotator agreement (Fleiss' $\kappa{=}0.39$) reflects the inherent subjectivity of stagnation boundaries.

\paragraph{Labeling function count.}
Three LFs produce insufficient inter-LF conflict (95.1\% agreement at conf${\geq}$2) for any label model---temporal or generative---to demonstrate value; scaling to ${>}$10 LFs with higher disagreement is needed.

\paragraph{No online evaluation.}
All results are offline; no intervention or real-time deployment evaluation has been conducted.

\paragraph{Label version sensitivity.}
Cross-coding-agent transfer results are sensitive to label quality: a single embedding version mismatch shifted the OH stagnation rate from 6.56\% to 21.4\% and improved 5\% fine-tuning F1 from 0.570 to 0.850.
This sensitivity suggests that deploying the pipeline on new agents requires careful label auditing before conclusions about transfer difficulty can be drawn.

\paragraph{Outcome dependence.}
The outcome backpropagation labeling function ($\lambda_3$) requires task outcome, which is unavailable during inference.

\paragraph{Code and data.}
Code, data, and trained models are anonymous during review and will be released upon acceptance.
