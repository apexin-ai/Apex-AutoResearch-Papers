## 1. Paper Summary

The paper studies progress stagnation detection in LLM coding agents (SWE-Agent, OpenHands) via weak supervision. Three labeling functions (command repetition, file diff frequency, outcome backpropagation) generate noisy window-level labels aggregated by majority vote. Four detection paradigms are compared: structural feature classifiers (30 handcrafted features, RF/GB), neural embedding probes (Qwen-0.6B, BGE-m3, E5-large-v2), LLM-as-judge (Claude Sonnet zero-shot), and a hybrid ensemble (probability averaging). A 650-window human-annotated gold set validates all methods. Five contributions are claimed: structural baseline discovery (0.84 gold F1), hybrid complementarity (0.86), circularity gradient analysis, LF temporal dynamics, and a TLM negative finding.

## 2. Roundtable: Step 1 — Independent Assessments

### R1 (Methods + Experiments): 4/6 Borderline Accept

**Strengths:**
- Unusually honest treatment of circular evaluation; proactively identifies and quantifies inflation per method (structural 15.5pp, probe 11.5pp, LLM −4.8pp)
- Gold set construction is well-designed: stratified sampling (50 conf=3, 300 conf=2, 300 conf=1), dual annotation + adjudication, κ=0.73
- Comprehensive multi-paradigm comparison across multiple axes (in-domain, cross-agent, encoder ablation, window size, data scaling, multi-seed)
- Cross-agent cmd_rep role reversal is a genuinely useful finding for practitioners
- TLM negative finding well-documented with three implementations and clear diagnosis
- Statistical validation of temporal dynamics (Kruskal-Wallis + Bonferroni)
- Strong practical relevance (<5ms inference, no GPU needed)

**Weaknesses:**
- **No confidence intervals or significance tests on gold results.** The core comparative claims (structural 0.84 vs probe 0.81; hybrid 0.86 vs structural 0.84) lack bootstrap CIs or McNemar's test. On N=650, the 2–3pp gaps may or may not be significant.
- **No independent OpenHands gold set.** Cross-agent "0.82 estimated gold" is extrapolated from SWE-Agent inflation patterns — unjustified given demonstrated agent-specific differences (cmd_rep reversal, stagnation ratio 28.5% vs 6.6%).
- **Gold set annotation quality is borderline.** κ=0.73 is "substantial" but not "almost perfect." Adjudication process underspecified. Per-class kappa not reported.
- **Only 3 LFs** make the weak supervision analysis regime-limited (95.1% conf≥2 agreement → MV near-trivially optimal → TLM negative finding somewhat expected).
- **Outcome backpropagation uses privileged information** (task outcome unavailable at inference time). Impact on comparison fairness insufficiently discussed.
- **Hybrid ensemble underspecified.** No comparison to stacking, learned weights, or selective routing. No robustness analysis across seeds/splits.
- **Missing ablation:** No structural feature subset removing LF-overlapping features to isolate non-circular structural contributions.

### R2 (Novelty + Related Work): 3/6 Weak Reject

**Strengths:**
- Well-identified, practically relevant problem with timely motivation
- Honest circularity treatment rare in empirical ML papers
- Thorough ablation ecosystem (encoder, window size, data scaling, cmd_rep removal, OB holdout)
- Cross-agent cmd_rep reversal is genuinely interesting
- TLM negative finding informative for weak supervision community

**Weaknesses:**
- **Limited novelty in individual components.** MV over LFs is vanilla data programming; probe is standard GRU+attention; structural features are straightforward. The core message ("simple features work well") echoes many applied ML domains.
- **Structural baseline finding partially tautological.** Structural features near-perfectly predict labels generated by structural heuristics. Gold validation narrows but doesn't eliminate this concern (gap shrinks from ~9pp to 3–5pp).
- **Circularity gradient is not a novel concept.** Feature-label leakage in weak supervision is well-known (Ratner et al. 2016). Calling it a "gradient" adds terminology but limited conceptual novelty. Only 3 data points (structural, probe, LLM) support the claimed monotonic relationship.
- **Contribution count inflation.** Five claimed contributions compress to ~3 genuine ones. "Hybrid complementarity" is a standard ensemble result (2pp, likely not significant). "LF temporal dynamics" is descriptive analysis that doesn't yield a method improvement.
- **Missing related work:** Snorkel MeTaL (hierarchical label aggregation), SPEAR/NPLM (post-2021 programmatic WS), active learning as alternative to WS, DivideMix (noisy label learning), broader "simple features beat deep learning" literature.
- **Broken references [??]** for cycle detectors — unacceptable quality issue.
- **Narrow scope:** Two coding agents on SWE-bench. "Stagnation is structural" may be domain-specific.
- **Better suited for applications/industry track** (EMNLP Industry, NeurIPS D&B, ICSE) than main research track.

## 3. Roundtable: Step 2 — Cross-Sharing

### R1 responds to R2's concerns:

**On novelty:** R1 agrees that individual components are not new, but argues the paper's value is as an empirical analysis paper, not a methods paper. The combination of gold-validated comparison, circularity quantification, and TLM negative finding provides a complete empirical picture that the community lacks. The "structural features beat neural" finding is NOT obvious a priori — most NLP intuition would expect embedding-based methods to capture semantic stagnation better.

**On tautology:** R1 partially concurs but notes the gold set breaks the tautology to a meaningful degree. The gap on gold (3–5pp) is real even if inflated on silver. The more important finding is the absolute gold F1 (0.84) — structural features achieve practically useful detection, not just LF reconstruction.

**On contribution inflation:** R1 agrees that 5 → 3 is more honest. Hybrid complementarity is a supporting analysis, not a standalone contribution. LF temporal dynamics are descriptive but still informative.

**On broken references:** R1 agrees this is a quality issue that must be fixed before submission.

### R2 responds to R1's assessment:

**On gold set quality:** R2 agrees κ=0.73 is adequate for an empirical study but emphasizes that missing per-class kappa and underspecified adjudication weaken the gold set's credibility. The paper's entire argument rests on gold validation — it needs to be bulletproof.

**On missing CIs:** R2 strongly agrees this is a critical omission. The hybrid's 2pp improvement is the lynchpin of contribution #2. Without significance testing, it cannot be claimed.

**On practical value:** R2 concedes the engineering contribution is clear and useful. The disagreement is about venue fit, not paper quality. This is a solid empirical study that would be well-received at an applications track.

## 5. Roundtable: Step 4 — Consolidated Assessment

### Overall Score: 3.5/6 (Weak Reject / Borderline)

### Verdict
A competent, thorough empirical study with an unusually honest treatment of evaluation circularity. The gold-validated finding that structural features provide a strong, efficient baseline for agent stagnation detection is practically useful. However, the paper faces a novelty gap for a top venue main track: individual components are standard, the structural dominance finding is partially tautological, and the five claimed contributions inflate what are genuinely three moderate findings. Missing statistical significance tests on the key gold comparisons (structural vs probe, hybrid vs structural) leave the quantitative claims underspecified.

### Strengths Summary
1. **Methodological honesty:** Proactive circularity quantification with the "circularity gradient" analysis is rare and sets a good example for weak supervision research.
2. **Gold set validation:** 650-window stratified gold set with dual annotation directly addresses the central evaluation threat. Method hierarchy preserved on gold.
3. **Comprehensive comparison:** Four paradigms × multiple axes (in-domain, cross-agent, encoder ablation, window size, data scaling, multi-seed) provides a complete empirical picture.
4. **Cross-agent cmd_rep reversal:** Leading on SWE-Agent (−1.87 steps), lagging on OpenHands (+3.32 steps), with removal improving OH F1 by 17.6pp — genuinely useful finding.
5. **Well-documented negative finding:** Three TLM implementations tested, failure traced to low-conflict regime, downstream impact quantified (TWV −21.7pp cross-agent).
6. **Practical deployment message:** Structural monitoring at <5ms inference, no GPU, effectively free vs $11.66 LLM-judge cost.

### Weaknesses Summary
1. **[Critical] No significance tests on gold comparisons.** The 3pp structural-probe gap and 2pp hybrid-structural gap on N=650 may not be significant. Bootstrap CIs and McNemar's test are computationally trivial and must be included.
2. **[Major] Limited novelty.** No new methods; core finding ("simple features beat neural on structured task") is a known pattern. Circularity gradient is a well-known WS concern repackaged with new terminology.
3. **[Major] Contribution inflation.** Five claimed contributions → three genuine ones. Hybrid complementarity (2pp, unvalidated) and LF temporal dynamics (descriptive, no method improvement) are supporting analyses, not standalone contributions.
4. **[Major] No independent OpenHands gold set.** Cross-agent "0.82 estimated gold" extrapolated from SWE-Agent inflation patterns — unjustified given agent-specific differences in LF firing patterns and stagnation rates.
5. **[Moderate] Missing feature overlap ablation.** Removing LF-overlapping features from the 30-dim structural vector would isolate non-circular structural contributions and directly address the tautology concern.
6. **[Moderate] Missing related work.** Snorkel MeTaL, SPEAR/NPLM, active learning alternatives, DivideMix. Broken [??] references unacceptable.
7. **[Moderate] Hybrid ensemble underspecified.** Only probability averaging tested; no comparison to stacking, learned weights, or confidence-based routing.
8. **[Minor] Gold set κ=0.73 adequate but borderline.** Per-class kappa and adjudication protocol details should be reported.
9. **[Minor] Narrow scope.** Two coding agents on SWE-bench. "Fundamentally structural" claim needs domain hedging.

### Required Revisions for Acceptance
1. Add bootstrap 95% CIs and McNemar's tests for all gold F1 comparisons.
2. Reduce contribution count from 5 to 3 (structural baseline + circularity analysis + TLM negative finding); frame hybrid and temporal dynamics as supporting analyses.
3. Add LF-overlapping feature removal ablation.
4. Fix broken [??] references.
5. Hedge cross-agent claims — present 0.82 as "rough estimate" with explicit caveats, not as a validated finding.
6. Add missing related work (Snorkel MeTaL, SPEAR, active learning discussion).

### Recommended Venue Fit
- **Top venue main track (NeurIPS/ICML/EMNLP main):** Below the bar without significance tests and with current novelty level.
- **EMNLP Findings:** Good fit if required revisions 1–4 are addressed.
- **Applications/Industry track:** Strong fit as-is.
- **NeurIPS Datasets & Benchmarks:** Could work if gold set + LF framework are released as a benchmark.

### Experiment Coverage Assessment
The paper covers both imagined experiments from the review context:
- **Gold Set Human Validation (gold-set):** Fully covered. All expected deliverables present (LF-human agreement Table 4, gold method evaluation Table 1, circular inflation Tables 2–3, hybrid result, error analysis in Section 3.4).
- **F1_stag Per-Class Breakdown (f1-stag-analysis):** Fully covered. Tables 5–8 present stagnation F1 by class, trajectory position, LF confidence, and probe advantage regions.

No experiments from the imagined list are missing from the paper.

### Questions for Authors
1. What are bootstrap 95% CIs for structural (0.84), probe-BGE (0.81), hybrid (0.86), and LLM judge (0.71) gold F1? Is structural > probe significant by McNemar's test?
2. If you remove repetition-related and file-operation features from the 30-dim structural vector (i.e., features that directly overlap with cmd_rep and file_diff LF inputs), what is the residual structural F1 on gold?
3. The LLM-as-judge uses zero-shot Claude Sonnet. Have you tried few-shot or chain-of-thought variants? The 0.71 gold F1 seems low and may reflect prompt quality rather than an inherent limitation.
4. FlyingSquid appears completed in the experiment registry but is not reported. Why? If it also fails to beat MV, it strengthens the TLM negative finding.
5. Do you plan an independent OpenHands gold set? Given cmd_rep role reversal and stagnation rate differences (28.5% vs 6.6%), the transferability of SWE-Agent inflation patterns is questionable.
