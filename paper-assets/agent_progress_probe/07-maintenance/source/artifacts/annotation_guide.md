# Agent 行为窗口标注指南

## 任务定义

判断给定的 agent 行为窗口中，agent 是否在**取得有效进展（progress）**还是**陷入停滞（stagnation）**。

每个标注样本包含一个 agent 在连续若干步中的行为摘要（Thought → Command → Output），请根据这些信息做出判断。

## 标注选项

在 `annotator_label` 列填写：
- **progress** — agent 在此窗口内取得了有效进展
- **stagnation** — agent 在此窗口内未取得有效进展

## 判定标准

### Progress（进展）

agent 在窗口内执行了有效的问题解决行为，包括但不限于：
- 修改了相关代码文件
- 定位到新的错误位置或相关代码
- 采用了新的解决策略
- 产生了有意义的文件变更
- 运行测试获取了新的信息
- 首次阅读和理解代码结构

### Stagnation（停滞）

agent 在窗口内未取得有效进展，包括但不限于：
- 重复执行相同或近似的命令
- 反复浏览同一文件的同一区域
- 修改后又撤销/回退到之前状态
- 陷入无关操作（与任务目标无关）
- 反复尝试同一种失败方案
- 原地循环（做了很多操作但没有实际推进）

## 边界案例

| 场景 | 判定 | 理由 |
|------|------|------|
| agent 尝试了多种不同方法但都失败了 | **progress** | 每次尝试是新策略，排除了错误方向 |
| agent 重复同一失败操作（如同一命令反复执行） | **stagnation** | 没有新信息产生 |
| agent 首次阅读代码结构、浏览多个文件 | **progress** | 在建立问题理解 |
| agent 反复浏览同一文件同一区域 | **stagnation** | 未产生新理解 |
| agent 修改代码但引入了新 bug | **progress** | 有行动推进，尝试了解决方案 |
| agent 运行测试但测试失败 | **progress** | 获取了新的诊断信息 |
| agent 反复运行同一测试期待不同结果 | **stagnation** | 重复行为无新信息 |

## 常见易混淆情况

- **忙碌 ≠ 进展**：agent 可能一直在执行命令但原地踏步（如反复 scroll_up/scroll_down 同一文件）
- **失败 ≠ 停滞**：尝试新方法并失败仍然是进展，关键看是否尝试了新东西
- **慢 ≠ 停滞**：仔细阅读分析代码虽然看起来慢，但如果在获取新信息就是进展
- **多步 ≠ 进展**：步数多不代表有进展，要看每步是否带来了新信息或新尝试

## 校准流程

正式标注前，需完成校准步骤以确保标注者间的一致性：

### 第一阶段：独立校准标注

1. 从 650 个标注样本中预先抽取了 30 个校准样本（标记为 `is_calibration=True`，见 `annotation_mapping.csv`）
2. 3 位标注者**独立**标注这 30 个校准样本，不互相讨论
3. 标注方式与正式标注相同：阅读 `agent_actions`，在 `annotator_label` 列填写 `progress` 或 `stagnation`

### 第二阶段：一致性评估

4. 收集 3 位标注者对 30 个校准样本的结果
5. 计算初始 Fleiss' κ（衡量多标注者间一致性的指标）
   - κ ≥ 0.6：一致性可接受，记录分歧案例后进入正式标注
   - κ < 0.6：一致性不足，需要进行第三阶段

### 第三阶段：分歧讨论（如需要）

6. 逐一讨论分歧样本（3 人标注不一致的窗口）
7. 明确分歧原因，统一判断标准（如："连续三次不同的编辑算 progress 还是 stagnation？"）
8. 将讨论结论补充到本指南的边界案例表中
9. 如有必要，重新标注校准样本并重新计算 κ

### 第四阶段：正式标注

10. 确认 κ ≥ 0.6 后，进入正式标注阶段
11. 650 个样本分配给 3 位标注者，每个样本至少 2 人标注
12. 标注过程中如遇边界案例，记录下来待后续讨论

## 标注流程

1. 阅读 `agent_actions` 列中的行为摘要
2. 关注：agent 每一步做了什么（Command）、得到了什么反馈（Output）、是否在推进问题解决
3. 在 `annotator_label` 列填写 `progress` 或 `stagnation`
4. 如果非常不确定，请倾向于你的第一直觉

## 数据文件说明

- **annotation_sample_650.csv** — 标注用文件，650 个窗口样本
  - `id`：样本编号
  - `trajectory_id`：所属轨迹 ID
  - `window_idx`：窗口在轨迹中的位置
  - `confidence`：自动标注系统的置信度（仅供参考，不影响你的判断）
  - `agent_actions`：agent 的行为摘要（**标注依据**）
  - `annotator_label`：你的标注（填写 `progress` 或 `stagnation`）
  - `source`：数据来源标识（无需关注）

## 注意事项

- 只根据窗口内展示的行为判断，不要猜测窗口外发生了什么
- 每个窗口独立判断，不受其他窗口影响
- `confidence` 列仅供参考，不影响你的标注
- 不同来源（source）的 agent 行为格式可能略有差异，但判定标准一致
