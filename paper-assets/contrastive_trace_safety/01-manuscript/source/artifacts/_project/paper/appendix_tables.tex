% To test whether a substantially stronger text encoder closes the hidden-state
% advantage, we encode all traces with E5-Mistral-7B-Instruct
% \citep{wang2024e5mistral}, a 7B-parameter instruction-tuned text encoder
% (4096d, PCA-reduced to 384d), and retrain probes under the same 60/20/20
% protocol. Table~\ref{tab:e5_mistral} shows that HS probes retain higher
% precision across all four models; the advantage reaches Holm--Bonferroni
% significance for R1-8B and OT-7B, while 32B models show consistent but
% non-significant leads. Together with the BGE-large results
% (Table~\ref{tab:encoder_robustness}), these findings trace an encoder-quality
% gradient (Table~\ref{tab:encoder_gradient}): scaling text encoders from 22M to
% 7B parameters monotonically narrows the HS gap without eliminating it.
