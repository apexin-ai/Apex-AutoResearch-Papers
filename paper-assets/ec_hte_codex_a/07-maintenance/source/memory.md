# Memory

## 项目定位
EC-HTE 研究目标是纠正 LLM 生成的分类 effect modifier 中的差异性误分类对 CATE/HTE 估计造成的结构性偏差。首要可证伪机制是：当 subgroup misclassification rate 与真实 subgroup CATE magnitude 正相关时，单一全局 confusion-matrix correction 会系统性 under-correct 高误差/高效应 subgroup，并 over-correct 低误差/低效应 subgroup，因此可能比 uncorrected 更差。

## 领域参考

### HTE/CATE 标准评测协议

- Honest causal forest: Wager & Athey (JASA 2018; arXiv:1510.04342, https://arxiv.org/abs/1510.04342; DOI page https://www.tandfonline.com/doi/abs/10.1080/01621459.2017.1319839) 给出用于 CATE/HTE 的 causal forest 和推断框架；honesty/sample splitting 是其核心推断条件。EC-HTE 的 causal-forest baseline 应固定 honesty 开启，并报告 CI coverage 与 CI width，避免只报点估计误差。
- GRF implementation reference: `grf::causal_forest` 文档说明 causal forest 用于估计 tau(X)，并提示 accurate confidence intervals 通常需要比 prediction 更多 trees；同时把 honesty 定义为 subsample splitting。来源：https://grf-labs.github.io/grf/reference/causal_forest.html。实现时需记录 `num.trees`、`honesty`、`honesty.fraction`、seed、train/test split。
- CATE benchmark caution: Curth, Svensson, Weatherall & van der Schaar, "Really Doing Great at Estimating CATE?" NeurIPS D&B 2021（https://openreview.net/forum?id=FQLzQqGEAH；PDF https://datasets-benchmarks-proceedings.neurips.cc/paper_files/paper/2021/file/2a79ea27c279e471f4d180b08d62b00a-Paper-round2.pdf）指出常见 semi-synthetic CATE benchmark 和单一 metric 可能偏向特定算法，因此 EC-HTE 必须同时报告 pointwise、group-level 和 inference metrics，而不是只报告 PEHE。
- PEHE / root-PEHE: Shalit, Johansson & Sontag, ICML 2017（https://proceedings.mlr.press/v70/shalit17a.html；arXiv:1606.03976）沿用 ITE/CATE 估计误差评测；本项目定义为 `sqrt(mean_i((tau_hat_i - tau_i)^2))`，仅用于 synthetic/semi-synthetic 中 ground-truth tau_i 已知的设置。项目 brief 已列 PEHE 为主指标。
- GATE: Group Average Treatment Effect 是预先定义 subgroup 内的平均处理效应，DoubleML 文档定义为 `E[Y(1)-Y(0)|G=1]`（https://docs.doubleml.org/tutorial/stable/lectures/L3/heterogeneity.html）；Stata 19 CATE 文档也把 GATE/GATES 作为 IATE/CATE 的 group-level summaries（https://www.stata.com/stata19/cate/）。本项目 GATE RMSE 定义为 `sqrt(mean_g((tau_hat_g - tau_g)^2))`，用于 k 个真实 subgroup CATE 已知的 simulation。
- Replication / split reporting: 项目 brief 明确半合成实验使用 `R >= 200` replications、`N in {2000, 5000, 10000}`、expert budget `B in {100, 500, 1000, 2000}`、subgroup count `k in {3, 6}`、treatment assignment `T ~ Bernoulli(0.5)`。这些是首批实验的默认规模来源；任何缩小版只能标为 smoke/MVP，不写成正式结论。

### LLM annotation debiasing 与适用边界

- PPI: Angelopoulos, Bates, Fannjiang, Jordan & Zrnic, Science 2023 / arXiv:2301.09633（https://arxiv.org/abs/2301.09633；Science DOI https://www.science.org/doi/10.1126/science.adi6000）将少量 gold labels 与大量 ML predictions 结合，为 means、quantiles、linear/logistic regression coefficients 等 population parameters 构造有效 CI。本项目可把 PPI 作为 ATE / population regression coefficient correction baseline；不能直接声称它修正 misclassified categorical effect modifier 下的 subgroup CATE，除非把每个 subgroup estimand 单独建模并处理 subgroup membership error。
- DSL: Egami, Hinck, Stewart & Wei, NeurIPS 2023 / arXiv:2306.04746（https://arxiv.org/abs/2306.04746）针对 CSS 中 LLM/surrogate labels 的 downstream statistical analysis，使用 gold-standard labels 与 controlled sampling probability 来获得 asymptotic unbiasedness 和 uncertainty quantification。适合作为 downstream regression/ATE-style estimand 的 debiasing baseline；不自动解决 effect modifier 本身被错分导致的 CATE conditioning error。
- DSL/PPI finite-sample benchmark: Audinet de Pieuchon et al., EMNLP 2025（ACL Anthology https://aclanthology.org/2025.emnlp-main.1000/；arXiv:2506.09627）比较 DSL 与 PPI 在有限 expert labels 下的 LLM-based parameter estimate debiasing；结论范围是 population parameters / regression coefficients / causal effects 的 debiasing，不是 CATE modifier misclassification correction。可引用为为什么首批实验需要固定 expert budget curves。
- StratPPI: Fisch et al., NeurIPS 2024（https://proceedings.neurips.cc/paper_files/paper/2024/hash/c9fcd02e6445c7dfbad6986abee53d0d-Abstract-Conference.html；arXiv:2406.04291）通过 stratified sampling 缩窄 PPI CI，尤其当 autorater performance across conditional distributions varies。EC-HTE 可把 StratPPI 作为 ATE/population mean 的 stratified correction baseline，或作为 expert allocation 思路来源；不能把它当成 categorical modifier confusion-matrix correction，除非 correction estimand 明确改成每个 subgroup 的 gold-label estimand。
- Active Statistical Inference / AM-PPI: Zrnic & Candès, ICML 2024 Active Statistical Inference（https://arxiv.org/abs/2403.03208；ICML page https://icml.cc/virtual/2024/poster/34504）用 model uncertainty 主动选择 gold labels 并构造有效 CI；Brawand et al., AM-PPI arXiv:2605.08429（https://arxiv.org/abs/2605.08429）扩展为多 predictor、per-instance routing、residual uncertainty sampling。可作为 Stage 3 allocation baseline/灵感；其原始目标是 population mean monitoring/valid CI，不直接修 CATE conditioning variable 的 misclassification。
- Mozer difference-estimator view: Mozer, arXiv:2603.19160（https://arxiv.org/abs/2603.19160）指出 PPI mean estimator 等价于 survey sampling difference estimator，并讨论 differential prediction error for subgroup estimands such as ATE。项目中的 "arm-specific rectifier" baseline 应仅实现为 treatment/control arm 内各自估计 LLM-vs-expert residual/confusion correction，然后估计 ATE/GATE；它仍然是 arm-level/population-level rectification，不能代替 subgroup-specific modifier confusion correction。
- Ashwin real-data motivation: Ashwin, Chhabra & Rao, Sociological Methods & Research 2025, DOI 10.1177/00491241251338246（publisher page https://journals.sagepub.com/doi/10.1177/00491241251338246；Maastricht record https://cris.maastrichtuniversity.nl/en/publications/using-large-language-models-for-qualitative-analysis-can-introduc-2/）用 Rohingya/Bengali host interviews 说明 LLM coding errors are not random with respect to respondent characteristics。World Bank summary explicitly names refugee status, gender, education as non-random error correlates（https://documents1.worldbank.org/curated/en/099348304162431121/pdf/IDU1271bc2541c5e8144f51b8cc1be231f985cc6.pdf）。本项目 real-data validation 只用于验证 differential misclassification pattern，不用于声称真实 CATE accuracy。

### Measurement error / categorical misclassification correction baselines

- Global confusion matrix correction: 从 expert validation subset 估计单一 `P(Z_hat | Z)` 或 inverse matrix，把所有 subgroup 共用同一 misclassification mechanism。来源对应 epidemiology 中 matrix / inverse matrix correction for misclassification；见 Lyles et al. extended matrix/inverse matrix method with internal validation data（PMC https://pmc.ncbi.nlm.nih.gov/articles/PMC4382468/）。本项目必须报告当 subgroup-specific error differs 时 global correction 的 under/over-correction。
- Per-subgroup confusion matrix correction: 在每个 true or pilot-estimated subgroup g 内估计 `C_g = P(Z_hat | Z, g)`，再做 correction。该 baseline 是 EC-HTE 的 non-pooled comparator；高方差风险来自每组 expert labels 少。来源是同一 validation-data misclassification framework；partial pooling 是本项目新增稳定化层，不能把 independent per-subgroup correction 写成已有 EC-HTE 结果。
- Arm-specific correction: treatment/control arm 内分别估计 confusion/residual correction，模拟 Mozer/PPI arm-level rectifier 对 ATE 的处理。适用 ATE 或 arm-specific mean outcome/label correction；不能直接修正 "which subgroup is the unit conditioned on" 的 modifier misclassification，除非同时对 subgroup-specific `C_{g,t}` 做建模。
- SIMEX categorical approximation: Kuchenhoff, Mwalili & Lesaffre, Biometrics 2006（PubMed https://pubmed.ncbi.nlm.nih.gov/16542233/）把 SIMEX 扩展到 discrete covariate/response misclassification，通过 transition matrix Pi 增加误分类并外推到无误分类。EC-HTE 可实现为 categorical transition-matrix SIMEX + causal forest baseline；必须标记为近似 baseline，因为项目目标变量是 categorical effect modifier，而 classic SIMEX 更自然地服务 regression parameter correction。
- Calibration/probability modifier baseline: 用 expert validation subset 做 Platt scaling / temperature scaling 或 Dirichlet/multinomial calibration，把 LLM hard label 改成 calibrated class probabilities，再作为 soft modifier features 输入 CATE estimator。该实现只校准 predicted probabilities；如果 downstream CATE 仍按 hard subgroup 分层，它不会消除 subgroup membership error。概率校准作为一般 ML practice 可参考 Niculescu-Mizil & Caruana, ICML 2005（https://dl.acm.org/doi/10.1145/1102351.1102430），但 EC-HTE 需在 artifact 中记录 calibration loss 和 subgroup confusion recovery，而非只报 predictive accuracy。

### Baseline 实现规范

- 所有 correction methods 使用同一 expert label budget B、同一 validation split、同一 random seed list；PPI/DSL/StratPPI/ASI/AM-PPI 类方法只作为 ATE/population-parameter 或 allocation baselines，若用于 CATE 必须明确每个 subgroup estimand 的定义与 membership-error 处理。
- Global/per-subgroup/SIMEX/calibration baselines 都必须输出 estimated confusion matrix 或 transition matrix；没有 matrix recovery 输出的 run 不用于判断 EC-HTE 机制。
- Arm-specific rectifier 只能解释 arm-level residual correction 效果；如果它在 GATE/CATE 上失败，不写成 PPI/Mozer 失效的泛化结论，只写成 "arm-level correction does not address modifier misclassification in this DGP"。
- Real-data Rohingya validation 的结论边界：只验证 LLM coding errors 是否随 respondent characteristics 差异化、以及 partial pooling 是否更好恢复 subgroup-specific error patterns；由于缺少自然 causal ground truth，不报告 PEHE/GATE RMSE 作为真实 causal accuracy。
