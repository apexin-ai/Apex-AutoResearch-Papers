# MAVEN Dataset Description

*(For inclusion in Section 4: Experimental Setup, dataset description subsection)*

**MAVEN** \cite{wang-etal-2020-maven} is a large-scale event detection benchmark constructed from 4,480 English Wikipedia documents. It defines 168 event types organized in a hierarchical taxonomy derived from FrameNet, with 118,732 annotated event mention instances. The type space is substantially larger than prior event detection datasets (e.g., ACE05 with 33 types) and exhibits pronounced sibling-type confusability: Wang et al. report that 14.6--19.8\% of inter-annotator disagreements involve sibling types in the hierarchy (Table 7 of the original paper), confirming that structurally adjacent event types are inherently difficult to distinguish even for human annotators. We select MAVEN for cross-task validation for three reasons: (1) it provides a *different IE task* (event detection vs. NER), testing whether confusability-aware decomposition generalizes beyond entity extraction; (2) its 168-type schema is 2.5$\times$ larger than Few-NERD's 66 fine-grained types, stress-testing SDGD on a more complex schema; and (3) independently documented confusability evidence (sibling confusion rates) enables external validation of our Schema Confusability Score against human judgment.
