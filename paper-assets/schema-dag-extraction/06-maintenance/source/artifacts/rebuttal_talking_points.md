# Rebuttal Talking Points — ARR May 2026
# Prepared: 2026-05-18 | Updated: 2026-05-23 (v24: TP8 format-independence caveat, abstract/intro overclaim fixes per Reviewer)

## 1. Novelty: "SCS not new, findings not surprising"
SCS's formal definition matches LLM-PEE's partitioning criterion — acknowledged in Related Work and Limitations. The novelty is not in the metric but in the empirical findings it enables. Three specific results lacked prior evidence: (a) BCS independently predicts RE batch accuracy (semipartial R²=0.273) but NOT NER — this task asymmetry was unknown; (b) schema decomposition fails due to merge amplification — prior work (LLM-PEE, UniNER) assumed decomposition helps; (c) few-shot demonstrations widen the confusability gap — counterintuitive and previously unreported. Do not defend SCS novelty itself — redirect to "no prior work isolated confusability from count via controlled batch design." "Not surprising in hindsight" ≠ "already known."

## 2. Effect size: "r²=1.3% too small, typical batch only 2.2pp"
Pairwise r²=1.3-1.7% is modest at the pair level, but this is the mechanism-level signal; the primary evidence is batch-level BCS explaining 22% (FewRel, n=100) of cross-batch RE accuracy variance (§4.3). Correlated type pairs within batches compound the pairwise signal (Monte Carlo confirms ~3x amplification as a consistency check, not a causal mechanism). 2.2pp is typical IQR gap; extreme batches (real in production schemas) produce 25pp gap on DocRED (expanded experiment: low_bcs acc=0.672 vs high_bcs acc=0.422 at count=16, Δ=25.04pp [21.90, 28.34]). For 80+ type production schemas, 2.2pp systematic bias accumulates over thousands of extractions. The DocRED expanded experiment (n=55, tripled sample) confirms robust Spearman correlations (r=-0.762 at count=16, r=-0.693 at count=32, both p<0.001).

**Anti-ecological-fallacy defense:** The batch-level BCS signal is not an ecological artifact. Error taxonomy decomposition (§4.4) confirms that BCS variance maps specifically to intra-batch type substitution errors (IntraSub–BCS ρ=0.843–1.0 across all three datasets), not to other difficulty dimensions. The monotonic IntraSub–BCS relationship provides mechanism-level validation independent of the batch-level regression, ruling out spurious batch-level aggregation as the explanation.

## 3. Generalizability: "BCS only works for RE" / "NER null untested"
Task asymmetry is a core finding (C2), not a limitation. RE errors concentrate in type substitution regardless of output format (paired evidence: constrained vs unconstrained yield identical BCS correlations). NER errors scatter across missed entities, boundary misalignment, and type confusion, drowning the batch-level signal. Key evidence: (a) Pairwise SCS significant in NER (r=0.112, p<0.001) — pair-level signal exists, batch-level aggregation fails; (b) IntraSub monotonically correlated with BCS across all three datasets (Few-NERD ρ=1.0, FewRel ρ=0.954, DocRED ρ=0.843, p=8.1e-31), but NER miss rate (43-65%) drowns batch-level signal.

**Direct test (W4 relaxed matching, n=450 batches):** Post-hoc relaxed-matching evaluation (span overlap + correct type) improves absolute F1 by +4.2pp (98.4% of batches benefit), confirming boundary errors are prevalent. However, BCS–F1 Pearson r remains null (exact: 0.014 → relaxed: 0.003, both p>0.7). Boundary errors affect all batches uniformly and do not selectively mask the BCS signal. This rules out evaluation stringency as the explanation and confirms the NER–RE asymmetry is structural: NER error modes (miss, boundary, type) are diversified, preventing any single confusability proxy from dominating batch-level variance.

**Supplementary evidence (per-error-mode quartile analysis, not in paper):** BCS quartile breakdown (Q1-Q4, n=450 batches) shows all three error modes uncorrelated with BCS: miss ρ=+0.017, boundary ρ=-0.043, type_sub ρ=-0.010 (all p>0.37). Miss dominates at 49-56% across all quartiles. Type substitution does NOT increase with BCS in NER (unlike RE where IntraSub ρ=0.954). Caveat: NER batch BCS range is narrow (Q2-Q3 span only 0.014), limiting discriminative power. This data available if reviewer asks "which specific error mode is suppressing the signal?"—answer: none, the null is comprehensive.

## 4. "61% success rate" / many failed experiments
Analysis paper, not method paper — negative results are findings. SDGD failure (C3, now confirmed on both NER and ED via MAVEN experiment), few-shot widening, schema renaming ineffective — all diagnostically valuable. Registry failures include infra issues (Llama env, vLLM version) correctly tagged as engineering failures, not scientific conclusions.

## 5. "Correlational only, no concrete examples"
Appendix V provides qualitative error analysis: top-10 most confused type pairs for both RE and NER with SCS values and confusion rates, plus 3 concrete extraction error instances (all SCS>0.90) illustrating argument reversal (participant/participant of), containment reversal (contains/located in), and part-whole confusion (part of/member of). These ground the statistical findings in observable error patterns.

## 6. "Why not rename labels to reduce confusability?"
We conducted a post-hoc schema label renaming experiment. Results were inconclusive due to label unfamiliarity confounds: renamed labels (e.g., replacing natural relation names with synthetic tokens) introduced a new error source (model unfamiliarity with novel labels) that confounded the confusability reduction. This is noted in Limitations §5. The confound itself is informative: SCS captures not just surface similarity but semantic proximity in the model's embedding space, which renaming alone cannot eliminate. A clean causal intervention would require training-time vocabulary control, which is outside the scope of training-free IE.

**Anti-反噬 defense**: If reviewer argues "renaming inconclusive → SCS has no actionable value," counter: the inconclusiveness *reinforces* our core finding — confusability-induced degradation is representational, not surface-level (links to Q13 defense). SCS/BCS value is diagnostic (pre-hoc risk assessment), not prescriptive (providing a fix). The fact that surface interventions fail is itself a contribution.

## 7. "Additivity only holds on FewRel, not DocRED"
We present converging evidence that the two dimensions operate independently across both datasets:

**Sentence-level RE (FewRel)**: Bounded interaction (±3pp, TOST p=0.003).

**Document-level RE (DocRED, expanded n=55)**: The raw factorial interaction appears nonzero (-9.39pp extreme-batch design; 7.52pp median-split), but BCS range restriction is a confound: larger batches have narrower achievable BCS ranges (spread 0.263 at count=32 vs 0.377 at count=16). A range-matched robustness check—restricting both count levels to the overlapping BCS interval [0.43, 0.70]—reduces the interaction from 7.52pp (95% CI [1.49, 12.83]) to **0.93pp (95% CI [-7.13, 7.44])**, consistent with zero. The BCS-accuracy correlation strengths are also comparable across count levels (r=-0.762 vs r=-0.693, R²=0.653 vs 0.613).

**Conclusion**: After controlling for the achievable BCS range at each count level, the two dimensions operate independently on DocRED as on FewRel. The apparent interaction in the unmatched analysis is attributable to range restriction, not a genuine count-modulated confusability effect. This confirms the bounded-association framework across sentence-level and document-level RE.

**Anti-cherry-picking defense for range matching**: Range matching is not post-hoc data trimming — it controls a known confound (achievable BCS range narrows mechanically with larger batch sizes because more types must be drawn from the same embedding space). The trimming asymmetry (count=16 loses ~47%, count=32 retains ~100%) reflects this mechanical constraint, not selective exclusion. However, we acknowledge the power limitation: the range-matched subsample (n≈84) has MDE≈5.5pp, meaning we can only rule out interactions >5.5pp, not establish a true null. The Introduction now correctly states "directionally consistent on DocRED after controlling for BCS range restriction" rather than "confirmed."

**DocRED semipartial R² vs FewRel**: The 5x gap (0.056 vs 0.273) reflects near-complete BCS–centrality collinearity on DocRED (VIF=50.9, r≈0.99). When two predictors share >99% variance, semipartial R² for either is deflated below its true unique contribution. This is a boundary condition of the dataset (Wikidata relations have correlated frequency and semantic similarity), not inconsistency in the mechanism. The paper treats DocRED quantification as "directional only" (Appendix F) for this reason.

## 8. Format independence
A paired comparison on 25 identical batch type sets shows no detected format dependence in the BCS–accuracy correlation (Pearson r: −0.45 constrained vs −0.44 unconstrained; Fisher z=−0.04, p=0.97). The early n=10 ablation showing null ρ was underpowered and driven by batch-set mismatch (different batch compositions, not different formats). The BCS effect reflects intrinsic type semantic overlap, not decoding-format artifacts. 99.92% of unconstrained outputs stayed within prompt candidates, confirming models comply with schema semantics even without structural enforcement.

**Caveat (internal, do not volunteer):** Spearman ρ is non-significant in both conditions (constrained ρ=-0.16 p=0.45, unconstrained ρ=-0.14 p=0.49). The Pearson r values (-0.44, -0.45) are significant and form the primary evidence. If reviewer attacks Spearman null: Pearson is the pre-registered primary metric; Spearman's non-significance reflects n=25 power limitation, not absence of effect. The paper now uses "no detected format dependence" rather than "format-independent" to avoid overclaim.

## 9. Cross-model generalization
Dimension 2 validated on 4 models spanning 3 architecture families: Qwen3-32B (Δ=-31.2pp), LLaMA-3.1-8B (Δ=-27.1pp), LLaMA-3.1-70B (Δ=-10.9pp), Gemini 2.5 Flash (Δ=-17.6pp). Includes open-weight (8B–70B) and proprietary architectures. The BCS effect is architecture-independent, with mild scale attenuation (8B = 87% of 32B). Core pattern (count→recall decline, BCS→type substitution in RE) replicates on all four models; secondary analyses (error taxonomy, prompt sensitivity, TOST) are conducted on the primary model (Qwen3-32B) to ensure depth.

## 10. Honest statistical disclosure
Gemini count_16 correlation (r=-0.80) is single-point driven (LOO: r→-0.42, p=0.22). We report this transparently in Appendix T. The count_8 result (n=50, gap=17.6pp, CI [15.1, 20.1]) is the primary Gemini Dim2 evidence.

**Framing strategy**: count_16 LOO collapse reflects small-sample instability (n=10), not BCS effect absence. The dose-response narrative rests on count_8 (n=50, robust), not count_16. If reviewer frames LOO as undermining dose-response: count_8 alone shows 17.6pp gap with tight CI — this is the primary cross-model evidence. count_16's LOO instability is why we disclosed it (honest science), not why the effect is questionable. Transparent reporting of fragile results should not be penalized.

## 11. Amplification mechanism (W6): pairwise r²→batch R² gap
Pairwise r²=1.3% amplifies to batch R²=22-58% through two mechanisms: (a) Monte Carlo simulation confirms ~3× geometric amplification from correlated pair aggregation (Appendix N), yielding ~4% baseline — positioned as a *consistency check*, not a causal mechanism; (b) the remaining gap to observed 22-58% reflects that extreme-BCS batches are *compositionally* different—not just higher mean confusability but systematically co-selecting the most semantically overlapping types. The critical bridge from 4% to 22%: unconditional simulation treats all pairs equally, but BCS specifically aggregates *active confusable* pairs (those with high SCS), so the conditional simulation (restricting to SCS>0.5 pairs) yields 21.9%, consistent with observed 27.3%.

**DocRED R²=0.58 vs FewRel R²=0.22**: This is total R² (not semipartial). The 3x gap reflects DocRED's severe BCS–centrality collinearity (VIF=50.9): both predictors share so much variance that total R² inflates while semipartial R² for either deflates. FewRel's semipartial R²=0.273 is the clean estimate; DocRED's semipartial R²=0.056 is deflated by collinearity, not indicative of a weaker mechanism.

**Regression diagnostics**: FewRel max Cook's D < 0.5. If reviewer requests DFBETAS/leverage, these can be computed from existing data and provided in author response.

## 12. No GPT-4 family (W7)

## 14. RE "none" evaluation: "count-curve gains driven by none class prior?"
Gold relation is always in the candidate set by construction — code pre-filters samples so only those whose gold relation is among the K candidates are evaluated (`batch_samples = [s for s in samples if s["relation_type"] in type_set]`, verified across all 5 RE scripts). The prompt allows `none` output as a model escape hatch, but any `none` prediction is always incorrect (gold is never `none`). Therefore in-schema-only accuracy ≡ original accuracy. The count-degradation trend is not driven by none class prior. Supplementary: excluding `none` predictions, accuracy among non-none responses also degrades with count (FewRel: 1.00→0.60; DocRED: 1.00→0.47), confirming degradation reflects genuine type confusion, not model giving up. None prediction rate itself increases with count (DocRED: 12%→25%), consistent with Dim1 recall decline.

## 13. "No solution, only diagnosis" (W8 / significance concern)
This is a diagnostic/analysis paper, and we believe systematic diagnosis is a prerequisite for effective solutions. Prior work (LLM-PEE, CodeKGC, schema decomposition) proposed solutions without isolating the underlying failure modes—our analysis shows why SDGD fails (merge amplification, routing failure) and why naive fixes (renaming, few-shot) backfire. The SCS/BCS framework provides: (a) a pre-hoc complexity audit before deployment; (b) actionable thresholds (SCS>0.85 flagging); (c) clear evidence that future solutions must address the embedding-space geometry, not surface-level schema manipulation. Oracle routing recovers accuracy while decompose-then-merge fails, identifying the merge step as the bottleneck—a diagnostic finding that informs (but does not prescribe) future architectural choices. Several EMNLP/ACL analysis papers have been accepted on diagnostic value alone (e.g., "Are We Modeling the Task or the Annotator?", "On the Dangers of Stochastic Parrots").
