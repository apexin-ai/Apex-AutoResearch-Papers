# Moment Cascade Methodology Audit

**Date**: 2026-05-20
**Decision**: Unified on baseline-comparison method. Within-experiment z-score deprecated.

---

## Two Methods Identified

### 1. Within-Experiment Z-Score (DEPRECATED)

**Method**: Estimates noise from first 3 generations of the *same experiment* (`early_std = np.std(series[:3])`), then flags onset when deviation exceeds 2σ.

**Problem**: On α=0.0 null experiments, token_entropy gen 1 produces z=2.25 → false alarm. The within-experiment noise estimate is too small because 3 data points underestimate natural variance.

**Script locations** (all marked DEPRECATED 2026-05-20):
- Server: `/root/autodl-tmp/distrib_canary_collapse/scripts/moment_cascade_analysis.py` (westd-19828)
- Local: `scripts/moment_cascade_analysis.py`

**Results generated by this method** (do NOT use):
- Server: `results/analysis/moment_cascade_phase1.json`

### 2. Baseline-Comparison (AUTHORITATIVE)

**Method**: Uses α=0.0 experiment's diff std (`np.std(np.diff(norm_base))`) as noise floor. Onset detected when α>0 experiment deviates from baseline by >2σ of baseline noise. Also provides 5% absolute change as secondary threshold.

**Why it's better**: The noise floor comes from the null experiment, so it captures true generational variance. No false alarms on α=0.0 by construction (comparing baseline to itself).

**Script locations** (authoritative):
- Server: `/root/autodl-tmp/distrib_canary_collapse/results/moment_cascade_analysis.py` (westd-19828)
- Local: `artifacts/moment_cascade/moment_cascade_analysis.py`

**Results generated by this method** (use these):
- Local: `artifacts/moment_cascade/moment_cascade_analysis.json`
- Server: `results/moment_cascade/moment_cascade_analysis.json`

## Key Difference Summary

| Aspect | Within-Experiment (deprecated) | Baseline-Comparison (authoritative) |
|--------|-------------------------------|-------------------------------------|
| Noise estimate | `std(series[:3])` from same experiment | `std(diff(α=0.0 normalized))` |
| α=0.0 false alarm | Yes (z=2.25 on token_entropy gen 1) | No (by construction) |
| Threshold | 2σ only | 2σ + 5% absolute (dual) |
| Requires null experiment | No | Yes (α=0.0 as reference) |
