## Cross-α pattern

The direction check reveals that ece→* pairs systematically have negative naive_lag (reverse direction) at both α=0.30 and α=0.40. This is consistent with the C4 audit (D111) findings. The old registry counted any significant xcorr as "forward" without checking lag sign, inflating naive and diff counts.

| α | naive_fwd (old→new) | diff_fwd (old→new) | K≥3 (old→new) | K≥4 (old→new) |

| 0.30 | 8/8 → 5/8 | 4/8 → 3/8 | 6/8 → 3/8 | 3/8 → 3/8 |
| 0.40 | 8/8 → 4/8 | 3/8 → 0/8 | 6/8 → 1/8 | 1/8 → 0/8 |
