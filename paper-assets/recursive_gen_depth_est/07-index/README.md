# Provenance and file indexes

Mappings between original archive members and released files, byte counts, source checksums, exclusions, and manuscript version candidates.

[Back to project guide](../README.md)

- [Asset manifest (CSV)](asset-manifest.csv): original and released paths, sizes, and checksums.
- [Snapshot summary (JSON)](asset-manifest.json): source archive, counts, manuscript title, and scope.
- [Exclusion manifest](excluded-files.csv): dependency installations, caches, account files, and other omitted entries.
- [Version index](version-index.csv): archived PDF candidates and their source paths.


Use [the complete file manifest](../07-index/asset-manifest.csv) to inspect all files and their original archive paths.
