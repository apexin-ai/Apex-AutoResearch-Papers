# exp_arXiv_llama8b_crossscorer: Cross-Scorer Validation Report

## Experiment Overview

This experiment validates the robustness of the arXiv LLaMA-8B saturation boundary (K\*=3) by replacing the original Qwen-1.5B scorer with Pythia-1.4B. The same depth 0-5 texts generated by LLaMA-8B on arXiv data were re-scored using Pythia-1.4B perplexity features (skip_generation mode). If K\* remains at 3 with a different scorer family, we can exclude scorer family bias as a confound for the arXiv result.

## K\* Determination

**K\* = 3** (identical to original experiment).

The AUC threshold (0.60) is crossed between depth 2v3 (AUC=0.6201, above threshold) and depth 3v4 (AUC=0.5230, chance level). This is the same boundary observed with the Qwen scorer.

All AUC deltas between the two scorers are within 0.015, indicating highly consistent scoring behavior across scorer families.

## Conclusion: SUCCESS

Pythia-1.4B cross-scorer reproduces K\*=3 for arXiv LLaMA-8B, with AUC values within 1.5% of the Qwen-1.5B original across all depth pairs. This excludes scorer family bias as a confound for the arXiv domain result.

Key implications:
- The arXiv K\*=3 saturation boundary is robust and scorer-independent
- Unlike the Wikipedia domain (where Qwen scorer showed confound), arXiv results are clean
- The generative depth contamination signal in arXiv is a genuine property of the LLaMA-8B generated text, not an artifact of scorer choice
