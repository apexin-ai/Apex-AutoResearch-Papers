# 来源与文件索引

原始归档条目与发布文件的对应关系、字节数、来源校验和、排除项和论文候选版本。

[返回项目说明](../README.zh-CN.md)

- [文件清单（CSV）](asset-manifest.csv)：原始路径、发布路径、文件大小和校验和。
- [快照摘要（JSON）](asset-manifest.json)：来源归档、数量、论文标题和资料范围。
- [排除项清单](excluded-files.csv)：依赖安装、缓存、账户文件和其他未包含的条目。
- [版本索引](version-index.csv)：归档中的候选 PDF 及其来源路径。

通过[完整文件清单](../07-index/asset-manifest.csv)查看全部文件及其原始归档路径。
