## 矛盾检测信号分析

### Problem II_01: 有矛盾，但未改变答案
- 33个唯一约束中排除5个（15.2%），28个满足
- 12/12 traces 都得到答案73（unanimous）
- SICA加权分=49，仍选73
- **解读**: 矛盾约束来自少数trace的冗余/错误推理步骤，但不影响最终答案共识

### Problem II_02: 完全提取失败
- 0个约束、0个有效投票
- 耗时624s但无产出
- **解读**: 可能是答案格式提取问题（答案236需要特定推理路径），或模型在此题上产生了无法解析的输出

### Problem II_03: 无矛盾，完美一致
- 18个唯一约束全部满足，0排除
- 11/12 traces 得到45
- **解读**: 模型在此题推理高度一致

### Problem II_04: 有矛盾，未改变答案
- 5个唯一约束中排除1个（20%）
- 12/12 traces 都得到答案33（unanimous）
- SICA加权分=13（较低，因为只有4个trace提取到约束）
- **解读**: 约束提取覆盖率低（4/12 traces），但存在的约束中有20%被排除

### 约束质量观察
- 约束提取覆盖率不均: II_01=9/12, II_03=11/12, II_04=4/12
- II_04只有4个trace产出约束，说明约束提取器在某些题型上效果差
- 去重比例: II_01=56→33(41%), II_03=51→18(65%), II_04=20→5(75%)，冗余度差异大

## 与 Smoke Test (MATH-500, 5题) 对比

| 指标 | AIME (4题) | MATH (5题) | 差异 |
|------|-----------|-----------|------|
| 准确率 (SICA) | 75% | 80% | AIME更难，符合预期 |
| 准确率 (SC) | 75% | 80% | 一致 |
| SICA=SC 占比 | 4/4 (100%) | 5/5 (100%) | **两者始终一致** |
| 平均总约束 | 31.8 | 33.8 | 相近 |
| 平均唯一约束(有效题) | 18.7 | 6.8 | **AIME高2.7x** |
| 矛盾检出题比 | 2/4 (50%) | 1/5 (20%) | **AIME更高** |
| 整体排除率 | 6/56=10.7% | 3/34=8.8% | AIME略高 |
| 提取失败题数 | 1/4 | 0/5 | AIME有提取失败 |

### 关键对比发现

1. **约束丰富度**: AIME题产生更多唯一约束（18.7 vs 6.8），因为难题推理步骤更多、中间结论更丰富
2. **矛盾检出率更高**: AIME 50% vs MATH 20%，验证了"难题更易出现跨路径矛盾"的假设
3. **但矛盾未改变答案**: 在所有9题中，SICA和SC答案完全一致。矛盾排除只影响权重分配，未翻转最终选择
4. **SC分布过于集中**: AIME题的SC投票仍高度一致（12/12或11/12），没有出现足够的答案分歧让SICA发挥差异化作用

## 对 v3 全量重跑的预期判断

### 信号强度评估: **弱阳性**

矛盾检测机制本身在工作（AIME 50%题检出矛盾 > MATH 20%），但当前未产生与SC不同的答案。原因分析：

1. **SICA vs SC 差异化需要更多答案分歧**: 当SC投票几乎unanimous时，即使排除了一些约束，加权后仍选同一答案。需要SC分布更分散的题（如6:4:2的分布）才能看到SICA翻转效果。
2. **30题中后面的难题(II_05~II_15)更可能出现分歧**: 前4题是AIME II的最简单部分，QwQ全对3/4。后面的题模型准确率会下降，SC分布更分散，这正是SICA应该发挥作用的场景。
3. **提取失败是隐患**: 1/4题完全提取失败（0约束0票），需要排查是答案格式问题还是模型输出问题。

### 对v3的建议
- v3全量跑30题是必要的——前4题太简单，无法展示SICA真正价值
- 重点关注II_05之后的中高难度题，预期SC分布更分散时SICA有机会翻转答案
- 需要修复II_02类型的提取失败问题，否则会影响整体覆盖率
- 预期30题中可能有3-5题出现SICA≠SC的情况，这些才是核心论证样本
