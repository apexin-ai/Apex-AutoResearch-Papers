## Core Problem

Latent world models for manipulation predict at fixed temporal resolution during imagination, creating a credit assignment bottleneck for long-horizon tasks. In DreamerV3, actor-critic training uses imagination rollouts of H=15 latent steps, each covering one environment timestep — so for a 250-step manipulation episode (e.g., ManiSkill3 StackPyramid), imagination covers only 6% of the episode per rollout. Uneventful intervals (free-space approach, transport) consume the same prediction budget as critical state transitions (contacts, grasps, mode changes), simultaneously wasting imagination compute on uninformative phases and starving late-episode events of credit signal. The problem is most pronounced in contact-rich manipulation with distinct task phases (approach → grasp → lift → transport → place → release), but affects any task where dynamics complexity varies over time. Current solutions are either externally specified (TAWM takes Δt as input), structurally fixed (THICK and HWM use two-level hierarchies), domain-specific (LS-Imagine uses affordance-based jumping for open-world exploration), operate at the execution level rather than imagination (FFDC-WAM), or address prediction quality rather than temporal resolution (DMWM uses logical reasoning, DyMoDreamer uses observation-level dynamic modulation). No existing latent world model learns continuous event-driven temporal resolution to extend imagination horizons for actor-critic policy optimization.

## Opportunity / Why Now

The design point of combining learned event detection with variable-rate latent imagination in a single RSSM-based model for actor-critic training remains open. By learning to skip uneventful timesteps during imagination, the effective horizon extends far beyond H environment steps while keeping latent computation at H steps — directly improving credit assignment for long-horizon tasks. THICK (ICLR 2024) learns temporal abstractions via discrete latent dynamics but uses a fixed two-level hierarchy that cannot express continuous degrees of event significance or variable skip lengths. TAWM (ICML 2025) enables variable-Δt integration but requires Δt to be externally specified and is built on TD-MPC2's short-horizon MPC (H=3–5 with MPPI planning), where temporal skipping during planning is counterproductive. HWM (Zhang et al., April 2026) learns multi-scale latent world models but uses a fixed two-level planner. LS-Imagine (ICLR 2025 Oral) learns jumping flags for long-horizon imagination but targets open-world exploration with action-independent jumps, not actor-critic policy optimization. Adaptive Skip Intervals (Neitz et al., NeurIPS 2018) learns to skip timesteps in recurrent dynamics models by min-pooling over reconstruction losses — selecting intervals that are easiest to predict — but operates on raw observation prediction without MBRL integration and optimizes for prediction ease rather than policy-relevant dynamical significance. DMWM (NeurIPS 2025 spotlight) addresses long-horizon RSSM imagination via logical reasoning (dual-mind architecture with System 1/System 2 feedback) but does not change temporal resolution — it improves prediction quality at fixed rate rather than extending the effective imagination horizon. DyMoDreamer (NeurIPS 2025) uses inter-frame differencing masks to modulate RSSM attention toward dynamic features, improving representation quality at the observation level, but maintains fixed temporal resolution during imagination. ELVIS (May 2026) introduces uncertainty-aware lambda-return gating in RSSM-based MPC, adaptively weighting imagination steps by epistemic uncertainty, but does not change the temporal resolution of imagination itself. Schiewer et al. (2024) document model exploitation at the abstract level as a central failure mode of multi-model hierarchical world models, motivating a single-model approach. A continuous event gate that adapts RSSM imagination rate within DreamerV3's actor-critic framework fills this gap — avoiding multi-model exploitation while offering finer temporal adaptation than two-level hierarchies and extending effective imagination horizons for better credit assignment.

## Landscape (SOTA & Limitations)

Latent world models for MBRL operate in several temporal paradigms. (1) Fixed-rate actor-critic imagination: DreamerV3 (Nature 2025) uses RSSM with H=15 imagination rollouts for actor-critic training; NE-Dreamer (2026) and R2-Dreamer (ICLR 2026) extend this with decoder-free latent prediction. (2) Fixed-rate short-horizon MPC: TD-MPC2 (ICLR 2024) uses implicit latent dynamics with MPPI planning over H=3–5 steps, bootstrapping with a learned terminal value function — no actor-critic imagination. (3) Externally-specified variable-rate: TAWM (ICML 2025) conditions TD-MPC2's dynamics on user-specified Δt via RK4/Euler integration, learning dynamics across time scales but not deciding when to apply which scale. (4) Learned temporal hierarchies: THICK (Gumbsch et al., ICLR 2024) learns a two-level hierarchy via discrete latent dynamics where the lower level forms invariant contexts and the upper level predicts context changes. HWM (Zhang et al., arXiv 2604.03208, April 2026) learns multi-scale latent world models for hierarchical planning with a learned action encoder for temporal compression. (5) Learned skipping for exploration: LS-Imagine (Li et al., ICLR 2025 Oral) learns jumping flags based on affordance-map kurtosis for open-world exploration in MineDojo, with action-independent jumps. (6) Learned temporal skipping for prediction: Adaptive Skip Intervals (Neitz et al., NeurIPS 2018) uses min-pooling over reconstruction losses to select prediction intervals that minimize prediction error — a direct precursor to learned temporal abstraction in dynamics models, but designed for standalone prediction tasks without RL integration. (7) Improving RSSM imagination quality without temporal resolution change: DMWM (Wang et al., NeurIPS 2025 spotlight) uses a dual-mind architecture with RSSM-S1 (intuitive transitions) and LINN-S2 (logical reasoning feedback) to improve long-horizon imagination coherence — addresses error accumulation through logical constraints rather than temporal skipping. DyMoDreamer (NeurIPS 2025) uses inter-frame differencing masks with stochastic categorical dynamic modulation to focus RSSM attention on motion-relevant features, improving representation quality for visual tasks (SOTA on Atari 100k and DMC). (8) Temporal abstractions in autoregressive/offline RL: I-TAP (arXiv 2602.18694, Feb 2026) learns temporal abstractions via discrete residual tokens with a VQ-VAE, performing MCTS planning in token space for offline RL — operates in a fundamentally different paradigm (offline, autoregressive) from online RSSM-based MBRL. Emergent Temporal Abstractions (Kobayashi et al., arXiv 2512.20605, Dec 2025) introduces a metacontroller that discovers variable-length temporally-abstract controllers within autoregressive foundation models via internal RL — demonstrates temporal abstractions can emerge from sequence models but targets language/grid/MuJoCo settings, not latent imagination. (9) Adaptive temporal granularity at execution/planning level: FFDC-WAM (Wang et al., arXiv 2605.06222, May 2026) proposes adaptive action execution in world action models, deciding when to replan based on future-reality consistency — operating at the execution level rather than world model training. ELVIS (Du et al., arXiv 2605.04709, May 2026) uses ensemble-calibrated uncertainty-aware lambda-return gating for long-horizon RSSM-based MPC, adaptively weighting bootstrapping vs. rollout but not changing temporal resolution. (10) Event-aware world models: EA-WM (arXiv 2605.06192, May 2026) introduces event-aware fusion via frame-difference supervision for video world models at pixel level. The decoder-free WM trend (NE-Dreamer, R2-Dreamer, Dreamer-CDP, LeWorldModel — early 2026) shifts representation toward JEPA-style latent prediction. Dreamer 4 (Hafner & Yan, 2025) introduces scalable transformer world models with shortcut forcing. Schiewer et al. (Scientific Reports 2024) identify model exploitation on the abstract level as the central failure mode of hierarchical WMs. The key gap: no method combines learned event detection with variable-rate RSSM imagination for actor-critic training — extending effective imagination horizons while focusing compute on dynamically significant transitions.

## Proposed Approach

Augment DreamerV3's RSSM with a learned event gate for adaptive-horizon actor-critic imagination. The key architectural insight: by learning to skip uneventful timesteps during imagination, a nominal H=15 rollout covers H_eff = Σ Δt_i environment steps (up to 15×K_max), directly extending the credit assignment horizon without additional latent computation.

**Variable-rate RSSM.** Adapt the TAWM principle to DreamerV3's recurrent state-space model. The RSSM sequence model is augmented to accept a temporal gap: h_t = GRU(concat(z_{t-1}, a_{t-1}, embed(Δt)), h_{t-1}), where embed(Δt) is a learned embedding of the integer skip length. During world model training on replay buffer data, trajectories are subsampled at randomly chosen Δt ∈ {1, ..., K} (log-uniform), teaching the RSSM to predict across variable temporal gaps. The reward head is extended to predict cumulative discounted reward r_cum = Σ_{k=0}^{Δt-1} γ^k r_{t+k} over the skip interval, and the continue predictor estimates minimum continuation probability within the interval. K_max is capped at 8 to limit cumulative reward prediction error (accuracy degrades with Δt since intermediate states/actions are unobserved); the gating curriculum further mitigates this by starting with small Δt and gradually increasing.

**Event gate.** At each imagination step, a lightweight MLP gate head takes the current RSSM state (h_t, z_t) and outputs a categorical distribution over {1, 2, ..., K} for Δt via Gumbel-Softmax (temperature annealed τ=5.0→0.5 over training). When the gate selects Δt=1, the model predicts at full resolution; when Δt>1, the RSSM transitions across Δt environment steps in a single latent step. The actor outputs one action per imagination step, held constant for Δt environment timesteps — appropriate for low-significance phases (free-space motion, transport) where actions change slowly.

**Gate supervision (simplified).** The primary gate supervision signal is the L2 norm of consecutive latent-state deltas ||s_t - s_{t-1}||_2 (with stop-gradient on latent states used to compute deltas, preventing circular gradients). This signal is simple, has no training dependencies, and directly measures dynamical significance: states where the latent representation changes rapidly correspond to contacts, grasps, and mode changes. High latent-delta → gate outputs Δt≈1; low latent-delta → gate can output large Δt. The value-gradient magnitude ||∂V(s_t)/∂s_t||_2 is included as a secondary ablation signal (not in the primary method) to test whether policy-relevant significance beyond latent dynamics provides additional benefit. This simplification reduces the core method to a single gate-supervision hyperparameter (the latent-delta threshold), avoiding the complexity of stop-gradient on critic parameters and delayed meaningful signal issues.

**Differentiation from DyMoDreamer.** DyMoDreamer's inter-frame differencing operates at the observation/pixel level to modulate RSSM attention toward motion-relevant features — it improves what the model attends to at each fixed-rate step. Our latent-state delta operates in the learned latent space to control temporal resolution — it determines how many environment steps each latent step spans. DyMoDreamer does not change temporal granularity; our method does not change attention/representation quality.

**Imagination returns.** The λ-return computation is adapted for variable-rate steps: V_λ(s_τ) = r_cum(s_τ, a_τ, Δt_τ) + γ^{Δt_τ} · ((1-λ)V(s_{τ+1}) + λV_λ(s_{τ+1})), where the discount factor γ^{Δt} correctly accounts for temporal gaps. This preserves DreamerV3's actor-critic training while naturally incorporating variable temporal resolution.

**Gate collapse mitigations.** (1) Entropy regularization: auxiliary loss λ_H·H(p_gate) prevents collapse to always-Δt=1 or always-Δt=K, with λ_H annealed 0.1→0.01. (2) Gating curriculum: gate disabled for first 50K environment steps (Δt=1 only), then influence linearly ramped 0→1 over next 100K steps, allowing meaningful latent representations to form before the gate activates. (3) Gumbel-Softmax temperature annealing: high initial temperature produces exploratory near-uniform sampling, gradually sharpening. (4) Minimum-entropy floor: additional penalty if batch gate entropy drops below threshold.

**Differentiation from Adaptive Skip Intervals.** ASI (Neitz et al., 2018) learns to skip timesteps by minimizing reconstruction loss via min-pooling — selecting intervals that are *easiest* to predict. Our gate optimizes for *dynamical significance* via latent-state deltas, focusing on transitions where the world changes meaningfully, not where prediction is easy. ASI operates on raw observation prediction for standalone tasks; our gate operates within RSSM latent imagination for actor-critic MBRL.

**Differentiation from concurrent work.** Unlike DMWM's logical reasoning (which improves prediction quality at fixed temporal resolution), our gate extends the effective temporal horizon of imagination. Unlike ELVIS's uncertainty-aware lambda-return gating (which re-weights existing fixed-rate imagination steps), our gate changes the temporal resolution of imagination itself. Unlike FFDC-WAM (which adapts action execution at deployment), our gate operates during training-time imagination. Unlike THICK's two-level hierarchy, our single-model approach uses continuous Δt values within one RSSM, avoiding the multi-model exploitation problem (Schiewer et al., 2024).

**Evaluation.** 3 ManiSkill3 tasks spanning a wide range of episode lengths and phase complexity: PickCube-v1 (short-horizon, 50 steps — baseline where gate should learn Δt≈1 throughout, confirming no harm on simple tasks), PegInsertionSide-v1 (medium-horizon, 100 steps — contact-rich precision insertion with critical alignment phases), StackPyramid-v1 (long-horizon, 250 steps — sequential multi-object manipulation with pick-place-stack across 3 objects, requiring approach→grasp→lift→transport→place repeated 3 times with increasing precision). StackPyramid-v1 is the primary task for demonstrating credit assignment benefits: at 250 steps, DreamerV3's H=15 covers only 6% of the episode per imagination rollout, creating severe credit assignment bottleneck for late-phase events. Integration note: DreamerV3 is not an official ManiSkill3 baseline; we budget 3-4 days for integration using NM512/dreamerv3-torch (PyTorch, gymnasium-compatible) with ManiSkill3's CPUGymWrapper. Fallback: if integration proves unstable within the first week, fall back to DMC manipulation tasks (Reacher Hard, Manipulator Insert) where DreamerV3 is well-tested, then add ManiSkill3 results for ICLR 2027. Baselines: (1) DreamerV3 (fixed-rate H=15), (2) DreamerV3 + uniform-random Δt (variable-rate RSSM without learned gating — isolates the contribution of learned event detection vs. variable-rate dynamics alone). Key ablations: (a) latent-delta-only (primary) vs. latent-delta + value-gradient gate supervision, (b) with vs. without entropy regularization/curriculum. All main experiments use 3 seeds; ablations use 2 seeds. Metrics: task success rate, effective imagination horizon (mean Σ Δt_i per rollout), wall-clock training time, gate activation statistics (temporal distribution of gating decisions overlaid with ground-truth contact/grasp timestamps).

- 008e_v3（untrained dt_emb + subsample ON）normalized v/e=0.88x → 无崩塌，排除 subsample 数据本身作为根因

- 008a（untrained dt_emb, H=15）: 105K=778（82% baseline），normalized v/e 全程 0.59-0.93x，两次 V-shaped recovery。结构性 value growth suppression，非延迟效应。
