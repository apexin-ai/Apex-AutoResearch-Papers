## 2. 崩塌时序分析

### 核心发现：actor_loss → 0 是首发且核心的崩塌信号

**actor_loss 归零速度与 dt 正相关：**

| 实验 | actor_loss < -0.05 时间 | actor_loss ≈ 0 时间 | 最终 eval_return |
|------|------------------------|---------------------|-----------------|
| dt=4 (exp_007) | ~25K | **35K** | 152 (plateau) |
| dt=2 (exp_006) | ~55K | **65K** | 133 (still falling @72K=29) |
| baseline       | ~95K | ~145K               | 932 (stable) |

### 35K→65K 区间逐步分析 (exp_006)

| 区间 | actor_loss Δ | eval_return Δ | 判断 |
|------|-------------|--------------|------|
| 35K→45K | -0.331 → -0.277 (+16%) | 485→477 (-2%) | **actor_loss 先异常**，return 还未受影响 |
| 45K→55K | -0.277 → -0.130 (+53%) | 477→360 (-25%) | actor_loss 加速归零，return 滞后跟降 |
| 55K→65K | -0.130 → -0.012 (+91%) | 360→133 (-63%) | actor_loss 几乎消失，return 崩塌 |

**结论：actor_loss 归零 LEADS eval_return 下降，滞后约 10K 步。**

### 其他指标在崩塌期间的表现

- **actor_entropy**: 稳定在 -5.1 左右，与 baseline 同期一致（-5.2），**非异常**
- **value_loss**: 从 1.30 降到 0.93 再回升到 1.16，趋势与 baseline 类似，**非异常**
- **reward_loss / dyn_loss / model_loss**: 全部平稳下降，与 baseline 趋势一致，**非异常**
- **grad norms**: 范围正常（actor_grad 0.30-0.37, model_grad 8.0-8.6），**非异常**

**55K→65K 发生了 value-reality 交叉**：critic 从合理低估突变为 2.7 倍高估。这说明：

3. 世界模型在"想象中"仍给出乐观的轨迹预测，critic 基于这些想象训练，所以 value 不会下降

## 5. 与 exp_007 (dt=4) 模式对比

| 特征 | exp_006 (dt=2) | exp_007 (dt=4) |
|------|---------------|---------------|
| actor_loss → 0 时间 | ~65K | ~35K（快 2x） |
| 崩塌速度 | 35K→72K (37K步) | 15K→35K (20K步) |
| value 行为 | 持续高估 (monotonic ↑) | 先升后降 (self-correcting) |
| entropy 行为 | 稳定在 -5.1 | 回弹到 +3.5（actor 放弃确定性策略） |
| 最终状态 | 持续崩塌至 29 | plateau ~150 |

**共同模式**：actor_loss → 0（actor 梯度消失）。这是 fixed dt>1 的系统性问题。

**差异解读**：dt=4 崩塌更快但 plateau（critic 自我修正 + entropy 回弹），dt=2 崩塌更慢但更深（critic 持续高估，actor 仍"自信地"执行错误策略）。

## 6. 根因假设（排序）

### 假设 1（主因）：固定 dt>1 导致 imagination-reality compounding error

固定 dt=2 时，每步 imagination rollout 跨 2 个物理步。H=15 步想象 = 30 步物理时间。世界模型在 2-step 粒度上的小预测误差在 15 步 rollout 中指数放大。actor 优化的是"想象中的最优策略"，与真实环境表现 diverge。

佐证：dt 越大 → 每步误差越大 → compounding 更快 → 崩塌更快（dt=4 在 35K 崩，dt=2 在 65K 崩，dt=1 不崩）。

### 假设 2（加速因素）：advantage 消失 → actor 梯度枯竭

target_mean ≈ value_mean → advantage → 0 → actor 无梯度信号 → 策略固化。这本身也发生在 baseline（145K 时 advantage=0.3），但 baseline 此时 performance 已经很好（932），所以不是问题。在 exp_006，advantage 在策略还很差时就耗尽了。

### 假设 3（反馈回路）：delusional critic 的恶性循环

1. 大 dt 导致想象偏离现实 → actor 退化
2. Actor 退化 → 真实 return 下降 → replay buffer 质量下降
3. 但 world model 在想象中仍给出乐观轨迹 → critic value 不降
4. Value 不降 + actor 退化 → advantage → 0 → actor 完全停止学习
5. 回到第 2 步，形成不可恢复的死循环

## 7. 对 exp_009 设计的建议

1. **禁止使用 fixed dt>1**：这是系统性缺陷，不仅仅是超参数问题。

2. **自适应 dt 需要 actor gradient 保护机制**：
   - 监控 advantage 幅度，当 advantage < threshold 时强制增加 entropy coeff 或降低 dt
   - 在 actor loss 中加入 gradient normalization 防止梯度消失

3. **imagination horizon 应与 dt 反向调整**：dt=2 时用 H=8，保持物理覆盖时间 ≈ baseline（15步）。

4. **早停/干预信号**：当 actor_loss 连续上升（绝对值减小）且 eval_return 开始下降时，自动降低 dt。

5. **混合 dt rollout**：在同一批次 imagination 中混合 dt=1 和 dt=2 的 rollout，让 actor 同时从精确（dt=1）和粗糙（dt=2）的想象中学习，避免完全依赖不精确的大 dt 想象。
