## Core Problem

Vision-Language-Action (VLA) models achieve >90% success on standard LIBERO benchmarks but suffer catastrophic performance drops under perturbation: π₀ falls from >90% nominal to 53.6% average on LIBERO-Plus, with camera perturbations at 13.8% and robot initial-state perturbations at 6.0%. This brittleness stems from VLAs memorizing fixed vision-action mappings rather than developing genuine environmental understanding. Critically, different perturbation types disrupt different processing stages: visual perturbations (camera, lighting) corrupt early visual token representations, spatial perturbations (object rearrangement) invalidate learned action trajectories, and physical perturbations (object mass, friction) break force-compliance assumptions. Current robustness methods either address a single perturbation modality (FTM for visual, AFI for spatial, AnyCamVLA for camera viewpoint) or apply uniform correction across all perturbation types (RobustVLA's adversarial training, VLA-GSE's per-token capacity routing), leaving a fundamental question unanswered: does perturbation-type-aware diagnostic routing outperform one-size-fits-all adaptation?

## Opportunity / Why Now

Four concurrent lines of evidence from 2025-2026 converge to make perturbation-adaptive internal correction newly feasible: (1) SAFE (NeurIPS 2025) demonstrates that VLA intermediate activations encode rich, task-generic signals about execution state — a lightweight MLP on frozen features achieves SOTA failure detection across unseen tasks with <1% overhead, proving that perturbation-relevant information is extractable from VLA internals; (2) Linear probing of OpenVLA (Geier et al., 2502.04558) shows >0.90 accuracy for spatial object states and relations across layers 1-32 of the LLM backbone, establishing that spatial information sufficient for correction is linearly accessible; (3) Feature steering on π₀.₅ and OpenVLA (Buurmeijer et al., 2603.05487) demonstrates that minimal linear interventions on internal representations can reliably steer robot behavior with ~100% constraint satisfaction while preserving closed-loop task performance — proving that the representations are not just readable but controllable; (4) VLA-GSE (2605.06175) achieves 81.2% on LIBERO-Plus with spectral MoE routing using 114M trainable parameters on Qwen3-VL-4B, demonstrating that expert routing on frozen VLA backbones is highly effective — but its per-token capacity routing is perturbation-agnostic, leaving room for perturbation-diagnostic routing as an orthogonal design dimension. Together, these findings establish that VLA internals contain sufficient perturbation-diagnostic information AND that lightweight internal interventions can correct behavior without disrupting the frozen backbone's capabilities.

## Landscape (SOTA & Limitations)

The VLA robustness landscape in early 2026 features complementary but incomplete solutions across seven categories:

**Single-modality correction:** FTM/FLA (Li et al., 2512.02902) achieves 87-91% viewpoint recovery via visual token modulation with only 4K-4.7M parameters — highly efficient for visual perturbations but architecturally limited to recalibrating ViT outputs, with no mechanism for spatial or physical corrections. AFI (Chen et al., 2512.07472) achieves +20.2% on LIBERO-PRO through external 3D Spatial Affordance Fields that detect 'memory traps' via proprioception and propose affordance-driven waypoints — effective for spatial perturbations but requires an external geometric module and does not address visual or physical perturbations. AnyCamVLA (Heo et al., 2603.05868) provides zero-shot camera adaptation via feed-forward novel view synthesis, achieving 94.5% average success under camera perturbations by virtually transforming test-time observations to match training camera configuration — a plug-and-play visual-specific solution requiring no fine-tuning but limited to camera viewpoint changes.

**Multi-modal but uniform correction:** RobustVLA (ICLR 2026, 2510.00037) formulates multi-perturbation robustness as a multi-armed bandit problem, achieving +12.6% on π₀ across 17 perturbation types. However, it applies a single adversarial training strategy uniformly, potentially underperforming on perturbations that require qualitatively different corrections.

**Capacity-based expert routing (perturbation-agnostic):** VLA-GSE (2605.06175) decomposes frozen VLA weights via SVD into generalized (shared) and specialized (routed) experts, achieving 81.2% on LIBERO-Plus with 114M trainable parameters (2.51% of model) on Qwen3-VL-4B. VLA-GSE uses top-2 per-token gating across 7 specialized + 1 generalized expert per block for capacity allocation. This is the current strongest parameter-efficient method on LIBERO-Plus but routes by input-dependent capacity needs, not by perturbation type — the same routing configuration handles camera perturbations (64.4%) and layout perturbations (82.6%) without perturbation-type awareness. Importantly, VLA-GSE's standard LoRA baseline on the same Qwen3-VL-4B backbone achieves 69.2%, providing a controlled reference for the value of routing (+12.0% over LoRA).

**Capacity-based LoRA adaptation:** LoRA-SP (2603.07404) adapts LoRA rank per layer and per input on π₀ and SmolVLA via an SVD-style parameterization with a small router whose nonnegative scores act as singular values over a shared vector bank. The active rank set is selected by an energy threshold on cumulative squared scores, discovering that vision towers require the highest ranks while language layers remain low and stable. On real-robot manipulation tasks, LoRA-SP matches or exceeds full fine-tuning with far fewer trainable parameters and improves multi-task success by up to 31.6% over standard LoRA. LoRA-SP adapts HOW MUCH LoRA capacity to allocate (adaptive rank); Meta-Brain adapts WHAT TYPE of correction to apply (perturbation-specific experts). These are orthogonal dimensions that could be composed — adaptive rank within each perturbation-specific expert — representing a natural extension.

**Task-based LoRA routing (not perturbation-based):** CORAL (2603.09298) freezes the VLA backbone and attaches one LoRA expert per task, with a language-based manager routing instructions to experts. MoIRA (2507.01843) routes LoRA experts on π₀/GR00T-N1 using text-based similarity for task specialization. Both achieve strong multi-task performance but route by task identity/instruction — they cannot distinguish or adapt to different perturbation types within the same task.

**Spatial-aware VLA architectures:** SpatialVLA (2501.15830) injects 3D position encodings into VLA input, achieving 88.2% on LIBERO-Spatial; Spatial Forcing (ICLR 2026, 2510.12276) aligns intermediate VLA representations with 3D foundation model features, achieving 98.5% on standard LIBERO and 3.8× training speedup — both enhance spatial understanding at training time but are complementary to, not competitive with, post-hoc perturbation correction on frozen backbones. CorridorVLA (2604.21241) uses explicit spatial anchor constraints to guide action generation; its GR00T-Corr variant achieves 83.21% on the LIBERO-Plus dataset, though reported by task category (Long/Goal/Object/Spatial) rather than by perturbation type (Camera/Robot/Light/Background/Noise/Layout), making direct per-perturbation comparison with VLA-GSE or Meta-Brain's target metrics not straightforward. CorridorVLA demonstrates that spatial corrections at the action-planning level via explicit geometric constraints are feasible and effective.

**Test-time adaptation:** PDF (2604.18107) achieves +7.4% on LIBERO via test-time perturbation learning with delayed feedback — a lightweight perturbation head adjusts action logits using REINFORCE-style optimization guided by post-action observations, requiring no fine-tuning. PDF and Meta-Brain are complementary: training-time LoRA routing (Meta-Brain) for strong per-perturbation-type correction + test-time adaptation (PDF) for novel perturbation instances.

**VLA internal analysis:** SAFE (NeurIPS 2025, 2506.09937) probes VLA final-layer activations for binary failure detection using a 2-layer MLP (hidden dim 256, 2.3M params), achieving 78.0% ROC-AUC on unseen tasks. Probing work (2502.04558) extracts symbolic spatial states. Feature steering (2603.05487) demonstrates behavioral control through linear interventions on end-effector position and gripper state, achieving ~100% constraint satisfaction. These works establish feasibility but stop at detection/analysis — none close the loop from perturbation diagnosis to targeted correction.

**Gap:** No existing method combines (a) perturbation-type detection from VLA internals with (b) type-specific corrective adaptation. VLA-GSE routes by input capacity (perturbation-agnostic); LoRA-SP adapts rank per layer/input (capacity-agnostic to perturbation type); MoIRA/CORAL route by task instruction; PDF adapts at test-time without perturbation classification. Meta-Brain uniquely routes corrective LoRA experts by diagnosed perturbation type, testing the hypothesis that perturbation-aware specialization achieves comparable robustness gains at dramatically fewer trainable parameters through targeted correction rather than capacity expansion.

## Proposed Approach

**Meta-Brain** is a modular correction framework for frozen VLA backbones (π₀, π₀-FAST) comprising four components. The design departs from the user's original specification of an external frozen LLM (Qwen-2.5-7B) as 'meta-brain' with role-switching and a Unified Representation Interface. Through iterative analysis (Rounds 1-3), we determined that internal LoRA routing on the VLA's own backbone is superior for this problem: it avoids the prohibitive cross-model embedding alignment problem between an external LLM and the VLA's learned representation space, eliminates external LLM inference latency (critical for real-time control at 10-50Hz), and preserves the perturbation-adaptive routing insight from the original specification while simplifying the architecture. The 'meta-brain' concept is retained as the Perturbation-Adaptive Router — a lightweight internal module that fulfills the original spec's goal of diagnosing the perturbation type and orchestrating a type-specific response.

**Phase 0: Early-Kill Validation Gate (Days 1-4).**
Before committing to the full training pipeline, we validate the core assumption: that perturbation types are classifiable from π₀ internal activations. Procedure: (a) Roll out frozen π₀ on a subset of LIBERO-Plus tasks under all 7 perturbation categories (~200 rollouts). Record intermediate activations at layers 4, 8, 12, 16, 20, 24, 28, 32. (b) Train 2-layer MLP classifier (hidden dim 256) on mean-pooled activations for 3-class perturbation-type classification (visual / spatial / physical). (c) Report classification accuracy. GO/NO-GO criterion: if accuracy >70%, proceed to full pipeline. If 50-70%, augment router inputs with proprioception history and visual change detection features, re-evaluate (Days 5-6 reserved as contingency). If <50%, pivot to universal LoRA + Correction Memory (dropping perturbation-type routing). This gate costs ~5 H100-hrs (from buffer) and prevents wasting 185 H100-hrs on a falsified premise. Evidence supporting feasibility: SAFE achieves 78.0% ROC-AUC for binary failure detection from the same activations using the same architecture (2-layer MLP, hidden 256), and 3-class perturbation type classification is a coarser signal than binary failure prediction, so should be easier.

**1. Perturbation-Adaptive Router (PAR).**
Inspired by SAFE's demonstration that VLA internals encode execution-relevant signals, PAR trains lightweight classifiers (2-layer MLP, hidden dim 256, following SAFE's architecture) on intermediate activations from the frozen VLA backbone. Unlike SAFE's binary failure detection, PAR performs multi-class perturbation-type classification (visual / spatial / physical / nominal) with soft routing weights. The router operates on mean-pooled hidden states from layers selected via Phase 0 validation (following SAFE's aggregation protocol, evaluating first-token, last-token, mean, and first+last pooling strategies). PAR outputs a perturbation-type probability distribution p(type | h_l) used to softly weight LoRA expert contributions. PAR is trained with cross-entropy loss; optionally, meta-learning (Reptile across perturbation types) can improve generalization to unseen perturbation instances, at ~10 additional H100-hrs.

**2. Adaptive LoRA Bank (ALB).**
Three perturbation-specific LoRA experts (rank 16) are applied to the attention layers of the frozen LLM backbone:
- **Visual LoRA (LoRA-V):** Corrects visual distribution shifts (camera viewpoint, lighting, background texture). Positioned on early-to-mid LLM layers where visual tokens are first integrated, analogous to FTM's visual recalibration but operating at the cross-modal fusion level rather than ViT output. For camera-only deployments, AnyCamVLA's zero-shot approach is more efficient; LoRA-V's value is unified handling of camera + lighting + background within the routing framework.
- **Spatial LoRA (LoRA-S):** Corrects spatial rearrangement perturbations (object repositioning, initial state changes). LoRA-S targets representational recalibration — biasing attention patterns toward correct spatial features under rearranged configurations — rather than explicit trajectory replanning. The mechanistic justification rests on converging evidence at two levels. At the representational level: Geier et al. (2502.04558) show >0.90 probing accuracy for spatial object relations across LLM layers, confirming spatial state is linearly encoded; Buurmeijer et al. (2603.05487) demonstrate that linear interventions on π₀.₅ achieve ~100% constraint satisfaction for end-effector position and gripper state. At the architectural level: LoRA-S operates on mid-to-late attention layers where spatial-action mappings are computed, modifying the query-key-value projections that determine how spatial token representations are attended to during trajectory planning. This is mechanistically distinct from simply shifting a spatial feature — it alters the attention patterns through which the model routes spatial information into action predictions. However, we acknowledge that for perturbations requiring qualitatively different trajectories (e.g., navigating around a repositioned obstacle rather than merely recalibrating spatial feature attention), representational-level correction may be insufficient — such cases likely require explicit 3D geometric reasoning as demonstrated by AFI's external affordance fields. The Phase 0 validation gate partially tests whether representational-level correction is sufficient: if PAR can classify spatial perturbations from internal activations, this indicates the backbone encodes the perturbation signal, but the adequacy of LoRA-level correction for trajectory-altering spatial changes remains an empirical question resolved in the ablation phase. Hence our pre-planned pivot to hybrid AFI integration if LoRA-S underperforms.
- **Physical LoRA (LoRA-P):** Corrects physical property changes (object mass, friction, deformability). Targets late LLM layers near action decoding.

Expert outputs are combined via PAR's soft routing weights: h_corrected = h_frozen + Σ_k p(type_k) · LoRA_k(h_frozen), enabling smooth interpolation when perturbation types co-occur.

Total trainable parameters: ~6M (3 × rank-16 LoRA experts at ~1.5M each + PAR at ~0.5M). This count excludes Correction Memory, which adds only a single learned scalar (α) and a non-parametric FAISS index. Note that Meta-Brain's fixed-rank experts could be further enhanced by composing with LoRA-SP's adaptive rank allocation within each perturbation-specific expert — a natural extension where LoRA-SP determines how much capacity each expert allocates per layer/input while Meta-Brain determines which expert type to activate.

**3. Correction Memory (CM).**
A retrieval-augmented module that stores embeddings of (perturbation_context, correction_outcome, perturbation_type_label) tuples from successful training rollouts. CM's injection mechanism uses routing-weight modulation rather than cross-attention or prefix tokens: at inference, CM retrieves the k-nearest correction exemplars (k=5) based on cosine similarity between the current PAR activation embedding and stored perturbation context embeddings via a FAISS index. The retrieval results modulate PAR's routing distribution by injecting a correction bias derived from the perturbation-type labels of retrieved exemplars:

  p_refined(type_k) = softmax(logits_PAR + α · Σ_j sim_j · one_hot(type_k^j))

where sim_j is the cosine similarity of the j-th retrieved exemplar, type_k^j is its perturbation-type label, and α is a single learned scaling parameter. This mechanism biases routing toward experts that succeeded on historically similar perturbation instances, providing few-shot adaptation to novel perturbation instances within a known type without requiring additional model parameters. The design is motivated by two considerations: (a) it avoids the architectural mismatch of injecting retrieved embeddings via cross-attention into LoRA's additive weight perturbation framework, and (b) it elegantly connects CM to the routing pathway rather than creating a parallel conditioning channel. The FAISS index is CPU-bound at inference with <1ms lookup latency, adding no GPU overhead.
