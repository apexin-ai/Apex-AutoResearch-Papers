## Core Problem

Reward models for code repair agents operate at granularities that each miss critical information. Trajectory-level scorers (SWE-RM achieves 62–74.6% on SWE-bench Verified via best-of-32) provide a single holistic continuous [0,1] score for the entire multi-turn interaction but cannot localize which reasoning stage—localization, diagnosis, or patch design—caused failure, limiting their value for credit assignment and targeted intervention. Patch-level verifiers (R4P achieves 72.2% verification accuracy via reasoning about final patches) skip the diagnostic process entirely. Rubric-based critics (OpenHands Rubric-Supervised Critic achieves +15.9 best-of-N improvement on the rerankable subset via 25 rubric features) evaluate a mix of behavioral indicators and reasoning adequacy judgments—including features like insufficient_analysis, insufficient_debugging, and misunderstood_intention that assess whether the agent's reasoning was adequate—but these features are independent categorical indicators, not a causally linked decomposition: knowing that 'insufficient_debugging' and 'incomplete_implementation' both fired does not reveal whether the agent failed because it mislocalized the fault (causing downstream diagnosis and patch failure) or correctly localized but misdiagnosed the root cause. Step-level action-utility PRMs (SWE-Shepherd) attempt localized scoring but suffer fundamental credit assignment noise—actions that look locally useful may lead to dead ends, yielding 51% vs. 57% for greedy baselines. Prompt-based behavioral PRMs (SWE-PRM achieves 40→50.6% via course-correction) detect process inefficiencies like looping and drift but do not evaluate the logical soundness of diagnostic reasoning. Empirical evidence from RACE-bench (arXiv:2603.26337) confirms that reasoning quality in code agents degrades systematically across stages—from 9.25/10 at issue understanding to 0.445 recall at step decomposition—exhibiting 'waterfall-style degradation' that validates the premise of stage-dependent reasoning quality variation and motivates stage-level evaluation. Critically, none of these systems can guide *targeted resampling*—diagnosing which cognitive stage first failed and regenerating only from that stage onward while preserving validated reasoning prefixes. This targeted intervention capability has been validated as superior to full resampling in adjacent domains (Doctor-RAG in RAG, TraceElephant's counterfactual re-execution in multi-agent systems) but remains unexploited for code repair search guidance. Can we build a step-level PRM that scores reasoning quality along the causal diagnostic chain—localize → diagnose → patch—and use stage-level causal failure localization to enable targeted resampling that outperforms full-trajectory resampling at equal compute budget?

## Opportunity / Why Now

Code repair follows a diagnostic reasoning structure (localize → diagnose → patch) where intermediate diagnostic claims make verifiable predictions checkable against test execution outcomes—a domain-specific advantage absent from code generation or general agent tasks. This creates a unique opportunity that no existing system exploits: *targeted resampling from the diagnosed failing stage*. The three stages form a causal chain where localization quality constrains diagnosis quality, which constrains patch quality. When DiagPRM identifies that a trajectory has sound localization but flawed diagnosis, the system can preserve the validated localization prefix and regenerate only the diagnosis and patch stages—producing a better trajectory at ~40-66% the token cost of full-trajectory resampling while avoiding the risk of introducing new early-stage failures. This capability is fundamentally impossible with trajectory-level scorers (SWE-RM cannot identify which stage failed), independent categorical features (OpenHands Critic cannot determine causal ordering of failures), action-level PRMs (SWE-Shepherd scores utility of individual actions, not cognitive stages), and prompt-based PRMs (SWE-PRM detects behavioral patterns, not reasoning quality). The principle of causal failure localization followed by targeted intervention from the failure point has been validated in adjacent domains: Doctor-RAG (arXiv:2604.00865) demonstrates that diagnosing the earliest failure point in agentic RAG trajectories and performing tool-conditioned local repair—intervening only at the diagnosed failure while maximally reusing validated reasoning prefixes—significantly outperforms full-trajectory resampling strategies. TraceElephant (arXiv:2604.22708) validates counterfactual re-execution from diagnosed failure points in multi-agent systems, showing that full traces improve attribution accuracy by up to 76%. DiagPRM brings this principle to code repair as a trained reward model producing per-stage scores that guide both reranking and targeted resampling. Three additional advantages support the approach: (1) Reasoning quality at each stage is a property of the reasoning chain itself, not of future actions, making it a lower-variance scoring target than action utility—formally, Var(Q_reasoning|prefix) = 0 as Q depends only on observables, while Var(U_action|prefix) > 0 as U depends on stochastic future decisions; (2) Test execution outcomes serve as automatic validators for reasoning quality annotations during training—not as runtime input—enabling training label quality verification that general-purpose reasoning evaluators lack; (3) RACE-bench (arXiv:2603.26337) provides direct empirical evidence that stage-level reasoning quality varies systematically (9.25/10 at goal understanding to 0.445 recall at step decomposition), confirming that agents fail at specific stages rather than uniformly—meaning targeted resampling from the failing stage is both feasible and informative. The credit assignment survey (arXiv:2604.09459) categorizes 47 methods across five granularity levels (token, segment, step, turn, multi-agent)—DiagPRM's 'cognitive stage' granularity is distinct from all: coarser than individual steps but finer than full trajectory, structured around the causal diagnostic reasoning process rather than mechanical workflow phases or arbitrary step boundaries. This positions DiagPRM as a novel granularity in the credit assignment taxonomy that is uniquely suited to domains with structured diagnostic reasoning. Beyond code repair, the causal stage decomposition principle generalizes to any domain where agent reasoning follows a structured diagnostic process—medical diagnosis (symptom interpretation → differential diagnosis → treatment plan), legal reasoning (fact finding → rule application → conclusion), and scientific hypothesis testing (observation → hypothesis → experimental design)—suggesting broader applicability.

## Landscape (SOTA & Limitations)

SWE-PRM / When Agents Go Astray (arXiv:2509.02360, Sept 2025, IBM Research) is the first PRM applied to SWE agents: a prompt-based system using a taxonomy of behavioral inefficiencies (looping, drift, redundancy, specification violations) to course-correct agents at runtime, achieving 40.0→50.6% on SWE-bench Verified with closed-source PRMs. It evaluates behavioral process patterns—not diagnostic reasoning quality—and is not a trained model. SWE-RM (arXiv:2512.21919, Dec 2025, Qwen team) is the current strongest trained reward model for SWE agents: a 30B MoE model (3B active) trained on ~100K trajectories, producing continuous [0,1] scores via softmax of YES/NO token log-probabilities on whole trajectories, achieving 51.6→62.0% (Flash) and 67.0→74.6% (Max) on SWE-bench Verified via best-of-32 (RM@32), plus RL gains. It scores complete trajectories holistically but provides no step-level diagnostic feedback and fundamentally cannot guide targeted resampling from a failing stage. R4P/Patch Reasoner (arXiv:2510.22775, Oct 2025) frames patch verification as reasoning via group-wise RL, achieving 72.2% accuracy surpassing o3 and 50× faster than testing, but evaluates final patches, not the diagnostic process leading to them. OpenHands Rubric-Supervised Critic (arXiv:2603.03800, March 2026, UIUC/CMU) trains a lightweight 4B critic model using semi-supervised learning on real-world user-agent interactions, achieving Best@8 +15.9 over Random@8 on the rerankable subset of SWE-bench Verified. It uses 25 rubric features including reasoning-adequacy judgments (insufficient_analysis, insufficient_debugging, misunderstood_intention). The critical distinction from DiagPRM is structural: independent categorical indicators cannot provide causal decomposition—knowing multiple features fired does not reveal where the reasoning chain broke or what to regenerate. Agentic Rubrics (arXiv:2601.04171, Jan 2026, Scale AI) creates repository-grounded rubric checklists for execution-free patch verification, achieving 54.2% on SWE-bench Verified with Qwen3-Coder-30B at Best@16—evaluates the output artifact against external criteria rather than the reasoning process. RGFL (arXiv:2601.18044, Jan 2026) generates structured per-candidate reasoning explanations for fault localization achieving 85% Hit@1 but covers only the localization stage. Agent-RRM (arXiv:2601.22154, Jan 2026) produces decomposed trajectory judgments for general agent tasks but lacks code repair's verifiable intermediate claims. ORPS (ICML 2025, arXiv:2412.15118) demonstrates execution-grounded process rewards without trained PRMs but requires execution at every search tree node. SWE-Shepherd (arXiv:2604.10493, April 2026) introduces step-level action-utility PRMs for SWE agents but achieves only 51% vs. 57% greedy baseline, confirming that action utility suffers credit assignment noise. SWE-TRACE (arXiv:2604.14820, April 2026) uses rubric-based PRMs with heuristic test-time scaling but relies on hand-designed rubric criteria. RTMC (arXiv:2604.11037, April 2026) organizes group rollouts into a shared rollout tree for step-level credit assignment, achieving +3.2pp on SWE-bench Verified over GRPO, but operates at the action level without diagnostic stage structure. CodeTracer (arXiv:2604.11641, April 2026) constructs hierarchical trace trees and performs failure onset localization across five mechanical workflow stages—a post-hoc diagnostic tool, not a reward model for search guidance. Doctor-RAG (arXiv:2604.00865, April 2026) validates the principle of causal failure localization + targeted repair from the failure point in RAG trajectories, demonstrating that intervening only at the diagnosed failure while reusing validated prefixes outperforms full-trajectory resampling. TraceElephant (arXiv:2604.22708, April 2026) introduces counterfactual re-execution from diagnosed failure points for failure attribution in multi-agent systems, showing full-trace attribution improves accuracy by up to 76%. Tree Training (arXiv:2511.00413, Nov 2025/Feb 2026) demonstrates computationally efficient shared prefix reuse in agent trajectory trees via Gradient Restoration, achieving 6.2× training speedup—validating that branching from shared prefixes is technically tractable at scale. RACE-bench (arXiv:2603.26337, March 2026) documents systematic waterfall-style degradation across reasoning stages in code agents. From Reasoning to Agentic (arXiv:2604.09459, April 2026) surveys 47 credit assignment methods across five granularity levels (token, segment, step, turn, multi-agent)—DiagPRM's cognitive-stage granularity (causal diagnostic reasoning stages) is distinct from all surveyed categories, representing a novel point in the credit assignment design space. The gap—a trained step-level PRM that evaluates reasoning quality along the causal diagnostic chain, uses stage-level causal failure localization to guide *targeted resampling* from the diagnosed failing stage (not just reranking), execution-free at inference—remains open. No existing system combines: (a) stage-level causal decomposition enabling root-cause identification, (b) targeted resampling guided by per-stage reward scores, (c) validated prefix reuse to improve trajectories at reduced compute cost.

## Proposed Approach

We define a 3-stage diagnostic reasoning taxonomy for code repair—localize (connect symptoms to fault location), diagnose (identify root cause), patch (design fix from diagnosis)—and extract stage boundaries from natural language repair trajectories using an LLM parser. We train DiagPRM as a LoRA-tuned Qwen3-8B classifier on ~15K annotated step-outcome pairs from the 66K SWE-smith trajectory corpus. Annotation uses an LLM-judge (Claude/GPT-4o) evaluating: (1) whether localization reasoning correctly connects error evidence to candidate locations, (2) whether the root cause hypothesis logically explains the observed failure, (3) whether the fix rationale follows from the diagnosis. To address LLM-judge circularity, we explicitly mine disagreement cases (sound reasoning + failed patch; poor reasoning + passing patch) as the most distinctive training signal. We validate annotation quality through a 100-trajectory pilot (300 reasoning steps) comparing inter-model agreement on reasoning quality vs. action utility labels, with an explicit fallback: if reasoning quality kappa falls below 0.4, we pivot to a hybrid approach combining high-agreement independent features with targeted causal stage criteria.

**Primary Evaluation: Targeted Resampling Experiment.** This is DiagPRM's unique contribution and the experiment that demonstrates capabilities impossible with trajectory-level scorers or independent feature indicators. Protocol: (a) For each of 100 SWE-bench Verified instances, generate N=8 initial trajectories via API-based agent. (b) DiagPRM scores each trajectory at each cognitive stage (localize score, diagnose score, patch score). (c) Identify 'partially-good' trajectories: those where early stages score high but a later stage fails (e.g., good localization + bad diagnosis, or good localization + good diagnosis + bad patch). (d) For the top-3 partially-good trajectories per instance, perform *targeted resampling*: preserve the validated reasoning prefix up to the diagnosed failing stage and regenerate only from that stage onward (e.g., keep localization reasoning, regenerate diagnosis + patch). (e) Measure whether targeted-resampled trajectories resolve the issue at higher rates than: (i) full-trajectory resampling—generating 3 additional complete trajectories from scratch (same total token budget, since targeted resampling reuses ~34-60% of tokens from the prefix); (ii) random selection among the original N=8; (iii) DiagPRM best-of-N reranking among the original N=8 (no additional generation). Key metric: *resolution rate improvement per additional token generated* (compute-normalized). The targeted resampling experiment directly demonstrates that causal stage decomposition has practical value beyond reranking: by preserving good early reasoning and only fixing what's broken, it should achieve higher resolution rates than full resampling at the same compute budget. Expected effect size: 8-15pp improvement over full resampling (vs. 3-8pp for reranking alone), because targeted resampling creates *new, better* trajectories that leverage validated prefixes rather than merely selecting among existing candidates. This larger effect size also improves statistical power on the 100-instance evaluation set.

**Secondary Evaluation: Best-of-N Reranking.** We additionally evaluate DiagPRM for best-of-N selection (N∈{5,8,16}) and stage-level reranking on 100 SWE-bench Verified instances with bootstrap confidence intervals and paired bootstrap significance tests. We compare against: (1) SWE-RM (trajectory-level, noting its headline results use N=32); (2) DiagPRM+SWE-RM combination (testing complementarity of stage-level causal and trajectory-level holistic signals); (3) OpenHands Rubric-Supervised Critic; (4) SWE-PRM; (5) SWE-Shepherd; (6) SWE-TRACE; (7) outcome-only; (8) random. For the targeted resampling experiment specifically, the baselines are: (a) full-trajectory resampling at same token budget, (b) DiagPRM-guided best-of-N without resampling, (c) random resampling from a random stage (ablation showing that diagnosing the *correct* failing stage matters), (d) always-resample-from-localization (ablation showing that stage-specific diagnosis matters vs. always starting over from the earliest stage).

**Targeted Resampling Implementation.** The technical implementation leverages the prefix-preserving property of autoregressive generation: we feed the validated reasoning prefix (up to the stage boundary identified by DiagPRM as the last good stage) as context to the agent, then allow it to continue generation from that point. This is analogous to Doctor-RAG's tool-conditioned local repair with prefix reuse, but applied to code repair trajectories with learned reward scores determining the branching point. Tree Training (arXiv:2511.00413) demonstrates that shared prefix reuse in agent trajectories is computationally efficient—our targeted resampling is a simpler case (branching from one identified point per trajectory rather than constructing full tree structures). The stage boundary extraction is performed by the same LLM parser used for annotation, identifying where the agent transitions from one cognitive phase to the next in its natural language reasoning.

**Ablation studies** for the targeted resampling experiment: (1) Oracle stage selection (resample from the *actual* failing stage determined post-hoc by test execution) vs. DiagPRM-predicted stage—measuring how well DiagPRM's stage diagnosis aligns with ground truth; (2) Resample from N-1 vs. N-2 stages back (e.g., if diagnosis is diagnosed as failing, compare resampling from diagnosis vs. from localization)—testing whether preserving more prefix helps; (3) Number of targeted resamples per trajectory (1, 3, 5)—testing compute scaling; (4) Stage score threshold for 'partially-good' trajectory selection—sensitivity analysis.

We acknowledge SWE-bench Verified's documented concerns (contamination, flawed tests) but retain it because all reward model baselines report on Verified—switching benchmarks prevents meaningful comparison. DebugBench (1,000 instances, N=3) provides complementary validation on a cleaner benchmark. If timeline permits, we evaluate on a 50-instance SWE-bench Pro subset.

We provide a formal stability argument: reasoning quality Q(r_t) depends only on the trajectory prefix, so Var(Q|prefix) reflects only annotator noise, while action utility Var(U|prefix) additionally includes irreducible variance from unknown future decisions—explaining SWE-Shepherd's credit assignment failures and motivating reasoning-quality scoring over action-utility scoring.

The contribution is framed as: (a) DiagPRM-guided targeted resampling achieves higher resolution rates than full-trajectory resampling at equal compute budget—demonstrating that causal stage decomposition has direct practical value for improving code repair success; (b) competitive or superior best-of-N reranking despite the 8B vs. 30B model size gap; (c) a novel 'cognitive stage' granularity in the credit assignment design space (distinct from all five levels in the arXiv:2604.09459 survey) that is uniquely suited to domains with structured diagnostic reasoning.

【主要风险】:

1. **实验结果风险：targeted resampling 的 Pareto 优势可能不显著**。如果 agent self-retry 已经足够强，或者 stage segmentation 准确率不足以产生可靠的介入点，Pareto 曲线可能仅显示 marginal improvement。此时论文需要依赖 disagreement mining 和 failure-stage analysis 作为 fallback 贡献。审稿人可能判定"方法有趣但效果不充分"。

2. **SWE-TRACE 正面碰撞**。SWE-TRACE（2026年4月）已实现 rubric-based step-level PRM + test-time scaling。虽然优化后的 proposal 已做了清晰的差异化定位（post-hoc diagnosis vs. during-rollout pruning），但如果审稿人认为 step-level pruning 在实际效果上已经 subsume 了 stage-level diagnosis 的价值，novelty 仍可能被质疑。Pareto 分析中未包含 SWE-TRACE TTS 的直接定量对比是一个残留弱点（定性比较在 Discussion 中，但 primary evaluation 未包含）。

【实施评估】:
- **计算资源**: Qwen3-8B LoRA 训练约 1-2× A100 (80GB), 训练时长 8-16 小时。Base agent trajectory generation（500 instances × N=8 trajectories）是主要计算开销，约 500-1500 GPU-hours（取决于 base agent 规模）。Targeted resampling 实验（含多轮重采样 + 全部 ablation）另需约 300-800 GPU-hours。DiagPRM 推理开销轻量（8B 模型，per-trajectory ~seconds）。总计约 **1000-2500 GPU-hours**，约需 4-8 张 A100 运行 2-4 周。
- **数据需求**: SWE-smith（公开，NeurIPS 2025 D&B Spotlight）、SWE-bench Verified（公开，500 instances）、DebugBench（公开，1000 instances）。均可直接获取。SWE-smith 需要从其框架中生成轨迹数据。
