# 项目资料

[首页](../README.zh-CN.md) · [精选论文](../highlight/README.zh-CN.md) · [按研究方向浏览](../categories/README.zh-CN.md) · [完整目录](../CONTENTS.zh-CN.md)

本目录存放 36 个研究项目的完整资料。先通过精选论文、研究方向或完整目录找到论文，再打开项目的中文说明查看资料入口。`vla-ssd` 等目录名是项目标识，完整论文标题见对应项目说明。

导航及项目说明分别提供英文版（`README.md`）和简体中文版（`README.zh-CN.md`），可在每页顶部切换。归档源码中的文档和研究对话记录保留原始正文及语言。

## 按需查找

| 所需资料 | 项目内目录 |
|---|---|
| 论文 PDF、LaTeX 源码、参考文献、图表和论文版本 | `01-manuscript/` |
| 研究代码、脚本、配置和依赖记录 | `02-code/` |
| 实验设置、数据、结果、表格和分析输出 | `03-experiments/` |
| 可读对话和结构化生成记录 | `04-generation-trace/` |
| 内部评审、审计和检查记录 | `05-validation/` |
| 项目说明、来源、修订和维护记录 | `06-maintenance/` |
| 文件清单、来源路径、校验和及可用性记录 | `07-index/` |

快速阅读可直接打开论文 PDF；查看实验时，从项目说明进入代码和实验目录；了解研究生成过程时，打开生成记录指南。文件索引用于核对归档资料及其来源路径。
