Each agent team uses AG2 v0.6.1's \texttt{ConversableAgent} (served via vLLM v0.6.6) with task-specific system prompts (solver: step-by-step solutions; checker: verify and flag errors). Under selector topology, a third agent routes via \texttt{GroupChat} with automatic speaker selection. Conversations are limited to 10 rounds. Function type labels are assigned by two independent LLM annotators (Qwen2.5-7B as Model~A, Llama-3.1-8B as Model~B) with structured JSON output. The oracle ablation and cross-model annotation use GPT-4o (\texttt{gpt-4o-2024-08-06}). Solution correctness is evaluated by exact match: numerical answers for GSM8K, letter match for ARC-Challenge, and yes/no match for StrategyQA. All experiments were conducted on 4$\times$ GPUs (96\,GB each). Code and data will be released upon acceptance.
