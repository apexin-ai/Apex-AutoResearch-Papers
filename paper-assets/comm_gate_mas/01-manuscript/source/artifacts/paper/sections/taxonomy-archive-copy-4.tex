We define five exhaustive, mutually exclusive communication function types (Table~\ref{tab:taxonomy}). Ambiguity is resolved by hierarchical priority: \textit{coordination} $\succ$ \textit{verification} $\succ$ \textit{reasoning\_guidance} $\succ$ \textit{information\_provision} $\succ$ \textit{acknowledgment}, reflecting the principle that structurally higher-level functions take precedence.

Our categories map onto established dialogue act frameworks (DAMSL~\cite{core_damsl_1997}, ISO 24617-2~\cite{bunt_iso_2012}, FIPA ACL~\cite{fipa_acl_2002}; detailed mapping in Appendix~\ref{app:damsl-mapping}), collapsing 56+ fine-grained types into five categories operationalized via measurable perturbation sensitivity rather than speaker intent. The taxonomy was developed for two-agent solver-checker dialogue; applicability to other configurations remains untested.

\label{sec:annotation_protocol}
Each message is annotated by an LLM annotator using a structured prompt with taxonomy definitions and hierarchical decision rules (temperature~0, constrained JSON; Appendix~\ref{app:annotation-prompt}). Cross-model validation uses two independent annotator models per message ($\kappa \geq 0.4$ threshold; Section~\ref{sec:cross_domain}).
