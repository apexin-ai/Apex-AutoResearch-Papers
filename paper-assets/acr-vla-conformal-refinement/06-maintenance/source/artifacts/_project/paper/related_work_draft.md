# Related Work

## Conformal Prediction in Robotics

Conformal prediction (CP) provides distribution-free coverage guarantees for prediction sets without assumptions on the underlying data distribution \cite{shafer2008tutorial, angelopoulos2023gentle}. Extensions to non-exchangeable and multivariate settings \cite{barber2023conformal, braun2025cgs, gibbs2021aci} have enabled applications in high-dimensional robotic action spaces. In robotics, CP has been applied to trajectory optimization with feedback-based coverage \cite{wang2025cploop}, assistive teleoperation with adaptive uncertainty detection \cite{zhao2024conformalized}, and safe planning with control barrier functions \cite{zhou2025acp_cbf}. These works primarily use CP for uncertainty quantification or safety filtering: they construct prediction sets to answer "how uncertain is this action?" or "is this plan safe?" Our work departs from this paradigm. ACR-VLA uses conformal nonconformity scores not for uncertainty quantification but for multi-sample selection, where the argmin over Mahalanobis-based scores identifies the most conforming action candidate as a pre-correction anchor. This selection stage feeds into a learned correction module rather than serving as an end-to-end decision boundary.

## Inference-Time VLA Refinement

Several concurrent methods address the problem of improving frozen Vision-Language-Action (VLA) model outputs at inference time without retraining. A2C2 \cite{a2c2_2025} trains a lightweight correction head that asynchronously adjusts action chunks to incorporate recent observations; this directly addresses the temporal reactivity limitation of chunked VLA policies. ReconVLA \cite{chen2026reconvla} applies conformal quantile regression to VLA outputs for calibrated uncertainty estimation and out-of-distribution detection; it answers "when should the policy not be trusted" rather than "how to improve it." SC-VLA \cite{sc_vla_2026} uses auxiliary predictive heads for sparse future state prediction combined with residual reinforcement learning (RL) for per-task online refinement. VLA-Pilot \cite{vla_pilot_2025} steers frozen VLA outputs through iterative MLLM self-critique with evolutionary diffusion optimization, but incurs substantial latency per step. SAFE \cite{gu2025safe} uses internal VLA features with CP for failure detection timing, and UPS \cite{yuan2026ups} calibrates policy composition via conformal prediction for strategy selection. These methods occupy distinct points in the design space: detection/gating (ReconVLA, SAFE, UPS), online RL refinement (SC-VLA), iterative re-ranking (VLA-Pilot), and per-step correction (A2C2). ACR-VLA combines two stages that prior work treats separately: conformal selection followed by bounded learned correction. Unlike A2C2, our method incorporates multi-sample selection before correction and systematically studies how conditioning features interact with correction magnitude. Unlike ReconVLA, we perform active correction rather than passive detection. Unlike SC-VLA, our correction is trained offline and requires no environment interaction at deployment.

## Residual Policies and Action Correction

Residual policy learning \cite{silver2018residual} established the framework of adding bounded corrections to a base controller, with subsequent work applying this to robot manipulation with stability guarantees \cite{johannink2019residual}. Recent methods extend this paradigm to VLA backbones: PLD \cite{xiao2026pld} introduces scheduled magnitude bounds for residual RL corrections on VLAs, TRANSIC \cite{jiang2024transic} learns binary gates for sim-to-real residual corrections, and DRC \cite{pan2025drc} applies temporal decay to correction magnitude over episode progression. Training-time approaches such as RobustVLA \cite{robustvla2025}, DiG-Flow \cite{digflow2025}, and SRPO \cite{srpo2025} improve VLA robustness through RL post-training or geometric regularization, but require modifying the base model weights. Test-time RL adaptation \cite{liu2026ttvla} provides online adaptation but needs environment reward signals. ACR-VLA differs from the RL residual tradition in three ways: (1) selection precedes correction via conformal scoring rather than applying corrections to a single policy sample, (2) the correction module (CRM) is trained with offline MSE supervision on demonstration data rather than RL reward, and (3) correction magnitude is explicitly bounded by norm clipping with the bound treated as a first-class hyperparameter whose interaction with conditioning features we systematically study.

## Correction Magnitude Sensitivity

Despite extensive work on residual corrections, the interaction between correction magnitude and conditioning signal quality has received limited attention. PLD \cite{xiao2026pld} schedules a magnitude cap but does not compare conditioning alternatives under varying bounds. TRANSIC \cite{jiang2024transic} demonstrates that ungated corrections lead to model collapse and motivates bounded correction, but uses a binary gate rather than continuous magnitude control. Our work identifies a previously unrecognized failure mode: per-DOF conformal features cause progressive performance collapse as correction magnitude increases, while observation-conditioned corrections remain stable across the full magnitude range. This conditioning-magnitude interaction constitutes a key empirical finding for safe inference-time VLA correction.
