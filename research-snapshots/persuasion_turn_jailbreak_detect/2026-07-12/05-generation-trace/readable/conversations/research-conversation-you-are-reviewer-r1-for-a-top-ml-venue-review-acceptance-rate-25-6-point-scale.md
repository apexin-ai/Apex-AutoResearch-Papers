## Paper Summary

**Title**: DisPeD: Persuasion-Aware Fine-Tuning for Robust Cross-Attack Multi-Turn Jailbreak Detection

**Core idea**: Fine-tune DeBERTa-v3-base on an 8-class persuasion strategy classification task (multi-task with binary jailbreak intent), then aggregate per-turn [CLS] embeddings via mean pooling for conversation-level jailbreak detection. Trained only on Crescendo-style attacks, evaluated zero-shot on Deceptive Delight (DD) and Foot-in-the-Door (FITD).

**Key claims**:
1. Cross-attack generalization: DisPeD F1=1.0 on DD vs vanilla DeBERTa F1=0.284 (+72pp)
2. Interpretable strategy trajectories via 8-class taxonomy
3. Perturbation robustness at K=1: DisPeD loses 2.6pp vs TF-IDF 9.6pp vs baseline 14.6pp

**Method (Section 3)**:
- Stage 1: Multi-task fine-tuning of DeBERTa. Persuasion head: 9-class softmax (8 strategies + none). Intent head: binary sigmoid. Loss: L = L_pers + λ·L_intent. λ=0.5 default but ablation shows insensitivity (all λ∈{0,0.3,0.5,2.0} yield F1=1.0).
- Stage 2: Extract [CLS] embeddings per turn, aggregate via mean pooling (GRU variant equivalent), linear classifier for jailbreak/benign.

**Experimental Setup (Section 4)**:
- Training: 240 topic-anchored conversation pairs (Crescendo jailbreak + matched benign), generated by Qwen3-8B
- OOD: 80 FITD + 80 DD synthetic conversations (Qwen3-8B)
- WildChat hard negatives: 420 high-drift benign conversations after filtering 16% jailbreak contamination
- Baselines: Vanilla DeBERTa+GRU, TF-IDF+LR, DeepContext proxy (BERT+GRU), LLM-as-judge (GPT-5.5, Qwen3-8B)
- Evaluation: F1 (macro), 3 seeds, bootstrap 95% CIs, K∈{1,2,3,5,all}

**Key Results**:
- Table 1: TF-IDF achieves F1=1.0 IID and FITD, 0.944 DD
- Table 2: IID all methods saturate (DisPeD 1.0, Baseline 0.968-1.0, TF-IDF 1.0). Max gap 3.2pp at K=1
- Table 3: DD cross-attack — DisPeD 1.0 vs Baseline 0.284 (full), but TF-IDF 0.944. FITD saturates for all methods
- Table 4: Scrambled labels drop persuasion acc 79.6%→64.4% but detection drops only 1.3pp IID, 6.5pp OOD. Binary (none-collapse) matches 9-class within 1pp
- Table 5: Perturbation — DisPeD 0pp drop (full), -2.6pp (K=1). Baseline -11.8pp/-14.6pp. TF-IDF -1.3pp/-9.6pp
- Table 6: Strategy trajectories — Crescendo escalation slope 0.68, benign 0.12
- Table 7: WildChat FPR — DisPeD 9.5%, Baseline 14.3%, TF-IDF 4.8%
- Table 8: DeepContext proxy BERT+GRU F1=0.256 DD (vs DeBERTa baseline 0.284)
- Table 9: GPT-5.5 F1=0.19-0.45, 30-47% unparseable; charitable correction reaches 0.7-0.8

**Ablations**:
- Lambda insensitivity: all λ values → F1=1.0
- Mean pooling = GRU (0pp gap)
- Checkpoint sensitivity: epoch 2-final all F1=1.0 IID, DD variance 0.011pp

## Review Context (imagined experiment expectations)
The review context file identifies these key tensions:
1. IID saturation: all methods converge, task is trivially separable IID
2. Scrambled labels: the most contentious result — scrambled labels barely hurt, raising annotation artifact concerns (Gururangan et al. 2018). Without a random-task control (NLI fine-tuning on same data), cannot distinguish persuasion-specific from general domain adaptation
3. TF-IDF achieves 0.944 on DD — practical gap to DisPeD is only 5.6pp, not 72pp
4. Mean pooling = GRU → method reduces to "fine-tune DeBERTa on persuasion text, average embeddings, classify"
5. Lambda insensitivity → multi-task framing is misleading, intent head contributes nothing
6. FITD saturates → cross-attack advantage is attack-type-dependent
7. All OOD data is synthetic (Qwen3-8B) — diversity/subtlety concerns
8. No human evaluation of interpretability claim
9. WildChat FPR 9.5% > TF-IDF 4.8%

118	% 3. METHOD
119	% ============================================================
120	\section{Method}
121	
122	\subsection{Problem Formulation}
123	Given a multi-turn conversation $C = (u_1, u_2, \ldots, u_T)$ consisting of $T$ turns, the goal is to classify $C$ as jailbreak or benign at the conversation level.
124	We additionally define a per-turn persuasion strategy label $s_t \in \{0, 1, \ldots, 7\}$ from an 8-class taxonomy and a binary jailbreak-intent label $y_t \in \{0, 1\}$.
125	
126	\subsection{Stage 1: Persuasion-Aware Encoder Fine-Tuning}
127	We fine-tune DeBERTa-v3-base \citep{he2021deberta} on two auxiliary tasks jointly.
128	Each turn $u_t$ is encoded independently to produce a [CLS] representation $\mathbf{h}_t \in \mathbb{R}^d$.
129	Two classification heads operate on $\mathbf{h}_t$:
130	
131	\begin{align}
132	    \hat{s}_t &= \text{softmax}(\mathbf{W}_s \mathbf{h}_t + \mathbf{b}_s) \label{eq:persuasion} \\
133	    \hat{y}_t &= \sigma(\mathbf{w}_y^\top \mathbf{h}_t + b_y) \label{eq:intent}
134	\end{align}
135	
136	The combined loss is:
137	\begin{equation}
138	    \mathcal{L}_{\text{stage1}} = \mathcal{L}_{\text{CE}}(\hat{s}_t, s_t) + \lambda \cdot \mathcal{L}_{\text{BCE}}(\hat{y}_t, y_t)
139	\end{equation}
140	where $\lambda$ controls the relative weight of the intent classification objective.
141	Ablation experiments (Section~\ref{sec:ablation}) show detection performance is insensitive to $\lambda \in \{0, 0.3, 0.5, 2.0\}$.
142	
143	\subsection{Stage 2: Conversation-Level Aggregation}
144	Given the fine-tuned encoder, we extract turn embeddings $\mathbf{H} = (\mathbf{h}_1, \ldots, \mathbf{h}_K)$ for the first $K$ turns of a conversation.
145	These are aggregated and classified:
146	\begin{equation}
147	    \hat{c} = \sigma(\mathbf{w}_c^\top f(\mathbf{H}) + b_c)
148	\end{equation}
149	where $f$ is either a GRU that produces the final hidden state, or mean pooling across turns.
150	We report GRU as the default but note that mean pooling produces equivalent results (Section~\ref{sec:ablation}), confirming that temporal ordering is not the detection mechanism.
151	
152	\subsection{Early Detection}
153	For deployment, the system can operate on partial conversations.
154	Given the first $K$ turns, detection is performed on $\mathbf{H}_K = (\mathbf{h}_1, \ldots, \mathbf{h}_K)$.
155	We evaluate at $K \in \{1, 2, 3, 5, \text{full}\}$ to characterize early detection capability.
156	
157	\subsection{Persuasion Strategy Taxonomy}
158	\label{sec:taxonomy}
159	Following \citet{zeng2024pap} and \citet{hagendorff2026}, we define 8 persuasion strategy classes spanning the spectrum from rapport building to explicit coercion.
160	Strategy index increases with escalation intensity: class 0 (rapport/trust building) through class 7 (explicit pressure/coercion).
161	This ordering enables trajectory analysis (Section~\ref{sec:interpretability}) where the temporal pattern of strategy indices characterizes different attack types.

293	\subsection{Ablation Studies}
294	\label{sec:ablation}
295	
296	Table~\ref{tab:ablation} presents systematic ablation across four dimensions: label quality, label granularity, loss weighting, and aggregation architecture.
297	The results converge on a single conclusion: the persuasion fine-tuning objective is the sole critical ingredient for cross-attack generalization.
298	
299	\paragraph{Label quality (scrambled vs. proper).}
300	Randomly permuting strategy labels before fine-tuning reduces DD \fone{} by only 1.0pp at full length (0.990 vs. 1.000) and 6.5pp at $K$=1 (0.935 vs. 1.000).
301	Both scrambled and proper labels massively outperform the vanilla baseline (+70.6pp and +71.6pp on DD, respectively).
302	This reveals that the fine-tuning process on persuasion-related text, not the specific class boundaries, drives generalization.
303	Scrambled fine-tuning still achieves 64.4\% persuasion strategy accuracy (vs. 79.6\% with proper labels), confirming that even degraded class signal provides useful representation structure.
304	
305	\paragraph{Label granularity (binary vs. 8-class).}

495	% 7. DISCUSSION
496	% ============================================================
497	\section{Discussion}
498	
499	\paragraph{The supervision signal, not the architecture.}
500	The comprehensive ablation picture (Section~\ref{sec:ablation}) reveals a clean mechanistic story. Four independent ablation axes (label quality, label granularity, loss weighting, temporal modeling) all point to the same conclusion: the persuasion fine-tuning objective is the sole critical ingredient for cross-attack generalization. Scrambled labels retain \fone{}=0.94--0.99 on DD, binary labels match 8-class within 1pp, mean pooling matches GRU, and all $\lambda$ values produce \fone{}=1.0. The method requires no careful hyperparameter tuning, no expert label annotation, and no specific architecture. This positions persuasion-domain fine-tuning as an accessible and robust supervision signal rather than an overengineered system.
501	
502	\paragraph{Honest positioning against TF-IDF.}
503	TF-IDF + LR achieves \fone{}=0.944 on DD and 1.0 on Crescendo and FITD, reflecting inherent lexical separability between jailbreak and benign conversations. \ours{} does not claim superiority over TF-IDF on raw detection. Instead, the treatment provides three complementary advantages: (1) it bridges the vanilla temporal modeling gap (+72pp on DD vs. the baseline's 0.28), establishing that persuasion-aware representations solve a problem that lexical features happen to also address through a different mechanism; (2) it is more robust under adversarial perturbation at early detection ($K$=1: treatment $-$2.6pp vs. TF-IDF $-$9.6pp); (3) it provides interpretable strategy trajectories that TF-IDF cannot offer.
504	
505	\paragraph{Content analysis vs. process detection.}
506	The LLM-as-judge results (Section~\ref{sec:llm_judge}) establish a fundamental distinction. GPT-5.5 achieves perfect precision but recall below 30\%, confirming that even frontier LLMs analyzing conversation content cannot detect distributed persuasion when each turn appears individually benign. \ours{} operates at the process level, detecting the accumulation of persuasion dynamics rather than evaluating content for harmfulness. These are complementary capabilities: content analysis catches explicit harm, process detection catches distributed manipulation.
507	
508	\paragraph{Limitations.}
509	The evaluation uses synthetic OOD data (80 FITD + 80 DD conversations). While sufficient for proof-of-concept, ecological validity requires evaluation on real-world multi-turn attacks when such data becomes available. The 8\% FPR on WildChat hard negatives indicates that deployment requires threshold calibration. The method targets persuasion-mediated attacks and does not address pure information accumulation, token smuggling, or single-frame roleplay jailbreaks. The training set ($n$=480) is small; scaling to larger and more diverse persuasion-annotated corpora may further improve robustness.
510

514	% ============================================================
515	\section{Conclusion}
516	
517	We presented \ours{}, a method that uses persuasion strategy classification as a multi-task fine-tuning objective to enable cross-attack multi-turn jailbreak detection.
518	Our central finding is that vanilla semantic temporal modeling catastrophically fails on unseen attack types (\fone{}=0.28 on Deceptive Delight), while persuasion-aware fine-tuning bridges this gap entirely (\fone{}=1.0, +72pp).
519	Systematic ablation demonstrates that the persuasion fine-tuning objective functions as an accessible supervision signal: detection survives label scrambling, binary collapse, architecture changes, and loss reweighting.
520	The 8-class taxonomy provides complementary interpretability through characteristic strategy trajectories.
521	These results establish persuasion-domain fine-tuning as a practical and robust approach to detecting distributed multi-turn manipulation, complementing existing per-turn safety classifiers and content-level LLM judges.

It explicitly acknowledges inherent lexical separability and positions DisPeD's value along three complementary axes (bridging vanilla temporal failure, perturbation robustness, interpretability). 48	## 3. Weaknesses (Consensus)
49	
50	### Critical
51	
52	**W1. Entirely synthetic OOD evaluation data undermines the headline claim (R1, R2).** All OOD test data (80 FITD, 80 DD) was generated by the authors using a "controlled generation pipeline." The training data (480 conversations) is also synthetic. The headline claim of F1=1.0 on "unseen attack types" is F1=1.0 on *synthetic approximations* generated by the same team. The generation process likely embeds systematic stylistic signatures (from the generation LLM, playbook templates, or annotation pipeline) that make transfer artificially easy. Without evaluation on real-world multi-turn attacks (e.g., from JailbreakBench, red-teaming logs, or published attack datasets), the ecological validity of the cross-attack generalization claim remains unestablished. The Limitations section acknowledges this, but the framing throughout the paper does not reflect the caveat with appropriate prominence.
53	
54	**W2. The core "method" is standard domain-adaptive fine-tuning, not a novel architecture (R2).** The technical contribution reduces to: fine-tune an encoder on a domain-relevant auxiliary task, then use the encoder for downstream classification. This is a well-established paradigm (Caruana 1997, STILTs/Phang et al. 2018, MT-DNN/Liu et al. 2019, "Don't Stop Pretraining"/Gururangan et al. 2020). The paper does not cite or position against this body of work at all. The ablation reveals that the "method" effectively reduces to "expose the encoder to persuasion-domain text during fine-tuning," since scrambled labels, binary labels, any lambda, and mean pooling all produce equivalent detection. The contribution is an empirical finding (persuasion-domain fine-tuning rescues OOD failure), not a methodological advance, but the paper is framed as the latter. Reframing as an empirical findings paper would be more honest and potentially stronger.
55	
56	**W3. Scrambled labels achieving F1=0.99 raises fundamental questions about the claimed mechanism (R1, R2).** If random labels work almost as well as correct labels, the encoder is not learning persuasion strategies; it is learning distributional properties of the fine-tuning corpus. The "persuasion-aware" framing is potentially misleading. The method may more accurately be described as "domain-adaptive fine-tuning on jailbreak-adjacent text." The critical missing control: would fine-tuning on *any* conversational persuasion corpus (without the specific taxonomy), or even continued pretraining (MLM) on the same text, produce the same result?

58	### Major
59	
60	**W4. Perfect F1=1.0 results and small test sets create ceiling effects (R1, R2).** Treatment achieves F1=1.0 with zero variance across 3 seeds on n=72 IID and n=80 OOD per type. A single misclassification on 40 positive DD samples would drop F1 to ~0.97. By the rule of three, the 95% CI upper bound for the error rate is 7.2%, meaning true F1 could be as low as ~0.93. The pervasive 1.0 results prevent meaningful comparison between configurations (treatment, binary, scrambled all within 1pp at F1=0.99-1.0). The evaluation does not discriminate between "the method works perfectly" and "the synthetic test set is too easy."
61	
62	**W5. TF-IDF at F1=0.944 on DD makes incremental value questionable (R1, R2).** The treatment's advantage over TF-IDF reduces to: (a) 5.6pp on DD raw detection (within the confidence interval given n=80), (b) 7.0pp advantage at K=1 under perturbation, and (c) interpretability via strategy trajectories. A TF-IDF model is orders of magnitude cheaper, faster, and transparent. The paper needs stronger evidence that the neural approach provides value beyond what TF-IDF offers.
63	
64	**W6. 8-class interpretability claim (Claim 2) is weakly supported (R2).** Strategy trajectory analysis (Table 7) provides descriptive statistics but no demonstration that trajectories are actionable or useful to human analysts. Given that binary labels suffice for detection, the taxonomy must justify itself through interpretability, but that justification is only sketched (transition entropy, mean index) with many missing entries in Table 7.
65	
66	**W7. Related work is thin and misses key literatures (R2).** 25 references is below top-venue norms. Critical missing areas:
67	- Multi-task learning / auxiliary task selection (Caruana 1997, Phang et al. 2018 STILTs, Liu et al. 2019 MT-DNN)
68	- Domain-adaptive pretraining (Gururangan et al. ACL 2020 "Don't Stop Pretraining")
69	- Real-world multi-turn attack datasets (Li et al. 2024 "LLM Defenses Are Not Robust to Multi-Turn Human Jailbreaks Yet")
70	- FITD original paper (the attack type is evaluated but not cited)
71	- ActorAttack (Ren et al. 2024)
72	- Several bibliography entries are incomplete (BIID, G-Guard, SafeDream lack author names)
73	- Orphan references appear in bibliography but not in text (Austin 1962, Searle 1969)
74	
75	### Minor
76	
77	**W8. 8% FPR on hard negatives has underexplored deployment implications (R1).** At 1% attack base rate and 8% FPR, the positive predictive value would be ~11%. No precision-recall curve is provided.
78	
79	**W9. DeepContext proxy is not a fair comparison (R1).** BERT-base (not BERT-large or actual DeepContext model) trained on the authors' dataset rather than original DeepContext data. This adds little beyond what the vanilla DeBERTa baseline already shows.
80	
81	**W10. Tables have incomplete reporting (R1, R2).** Table 2 baseline std shown as "---" for K=2,3,5 without explanation. Table 3 FITD results for K=2,3,5 are "---". Table 7 has many "---" and "(see pattern)" entries.
82	
83	**W11. The 8-class taxonomy is never enumerated (R2).** For a paper claiming the taxonomy as a contribution, the classes should be listed with descriptions in the main text.
84	
85	**W12. No figures in the paper (R2).** For a 10+ page submission, at least an architecture diagram and a cross-attack comparison visualization would improve accessibility.
86	
87	**W13. Missing reproducibility/ethics statements (R2).** Increasingly expected at top venues.

## Reviewer R1: Methods and Experiments

### 1. Summary

DisPeD fine-tunes DeBERTa-v3-base on an 8-class persuasion strategy classification task (with optional binary intent head) and aggregates turn-level [CLS] embeddings via mean pooling for conversation-level jailbreak detection. Trained only on 240 synthetic Crescendo attack/benign pairs, the system achieves F1=1.0 on unseen Deceptive Delight (DD) conversations where a vanilla DeBERTa+GRU baseline collapses to F1=0.284, a +72pp gap. Comprehensive ablation across four axes (label quality, granularity, loss weighting, aggregation) converges on a single conclusion: persuasion-domain fine-tuning is the sole critical ingredient, while all architectural and annotation choices are interchangeable. The paper honestly positions itself against a strong TF-IDF baseline (F1=0.944 on DD) and zero-shot LLM judges (GPT-5.5 F1=0.19-0.45).

### 2. Strengths

- **S1. Large, unambiguous headline delta.** The +72pp gap between treatment and vanilla baseline on DD is striking and not easily dismissed. The baseline's monotonic degradation with conversation length (K=1: 0.575 to full: 0.284) is a genuinely novel observation: the generic encoder actively accumulates misleading signal as DD's interleaving structure unfolds. This pattern is independently interesting.

- **S2. Unusually thorough and self-aware ablation.** Four independent ablation axes all converge on the same mechanistic conclusion. The scrambled-label result (F1=0.935-0.990 on DD) is the kind of finding many authors would suppress. Foregrounding it and drawing the correct inference (the domain exposure, not the label taxonomy, drives generalization) demonstrates scientific maturity and builds reviewer trust.

- **S3. Honest positioning against TF-IDF.** The paper explicitly reports that TF-IDF achieves F1=0.944 on DD and 1.0 on IID/FITD, then positions DisPeD's incremental value along three specific axes rather than hiding this inconvenient result. This candor is rare in the area.

- **S6. Reproducibility-friendly simplicity.** The ablation picture reveals the method reduces to "fine-tune DeBERTa on persuasion-related text, average embeddings, classify." ### 3. Weaknesses

- **W1. All evaluation data is synthetic, generated by the same team, likely sharing systematic artifacts (Critical).** Training data (480 conversations), IID test data (72), and OOD test data (80 FITD + 80 DD) are all synthetically generated using Qwen3-8B through the authors' pipeline. The headline claim of F1=1.0 on "unseen attack types" is actually F1=1.0 on synthetic approximations of those attack types, produced by the same LLM, presumably following the same annotation schema, and likely sharing generation-pipeline stylistic fingerprints. The Crescendo training conversations and the DD/FITD test conversations may share systematic distributional properties (sentence structure, vocabulary register, conversational formality) from Qwen3-8B that make "cross-attack transfer" artificially easy. Without evaluation on real-world multi-turn jailbreak data (e.g., JailbreakBench, MHJ dataset, red-teaming logs from Anthropic/Meta/Microsoft), the ecological validity of the generalization claim is fundamentally unestablished. The Limitations section acknowledges this in one sentence, but the paper's framing throughout (title, abstract, introduction, headline numbers) does not reflect this critical caveat.

- **W2. The scrambled-label result raises a domain-adaptation confound that lacks the right control (Critical).** Scrambled labels achieving F1=0.935-0.990 on DD means the encoder is learning from the distributional properties of the fine-tuning corpus, not from the persuasion class structure. The paper correctly identifies this but does not run the critical control: continued pretraining (MLM objective, no labels at all) on the same text. If MLM-only continued pretraining on the persuasion corpus also bridges the OOD gap, then the entire multi-task framing is misleading since the contribution reduces to "domain-adaptive pretraining on jailbreak-adjacent text." A second missing control: fine-tuning on a non-persuasion auxiliary task (sentiment, topic classification, NLI) using the same text would isolate whether the task matters or just the domain exposure. This relates to a well-known body of work on domain-adaptive pretraining (Gururangan et al., ACL 2020, "Don't Stop Pretraining") that the paper does not cite or engage with.

By the rule of three, the 95% upper bound on error rate is 7.2%, meaning the true F1 could be as low as 0.93. The pervasive ceiling at 1.0 prevents meaningful comparison between treatment, binary-collapse, scrambled-label, and different-lambda variants (all within 1pp of each other at 0.99-1.0). The paper cannot distinguish "the method works perfectly" from "the synthetic test set is insufficiently challenging." TF-IDF at F1=0.944 on DD substantially narrows the practical contribution (Major).** The paper's positioning of a +72pp advantage is computed against the vanilla DeBERTa baseline, not against the practical alternative. Against TF-IDF, the treatment's advantage is 5.6pp on DD raw detection. Given n=80 and the confidence interval analysis above, a 5.6pp gap is not statistically distinguishable from zero. The treatment's two genuine advantages over TF-IDF are: (a) 7pp at K=1 under perturbation, and (b) interpretability via strategy trajectories. But (a) is demonstrated only on IID perturbation (not OOD perturbation), and (b) lacks any human evaluation or user study. A reviewer must ask: is a fine-tuned DeBERTa model with higher FPR (8% vs 5%) and comparable detection justified over a TF-IDF+LR model that is orders of magnitude cheaper, faster, and intrinsically interpretable through its feature weights?

Scrambled labels achieve F1=0.99. The paper's Section 3 describes a two-stage architecture with multi-task learning, persuasion heads, intent heads, loss weighting, and GRU aggregation. The actual method is: fine-tune DeBERTa on any classification task using persuasion-related text, then average embeddings and apply a linear classifier. The gap between the described architecture and the actual mechanism is large enough to be misleading. The paper should either lead with the minimal effective method (fine-tune + average + classify) or provide a principled argument for why the full architecture is preferable despite equivalent performance.

- **W6. FITD saturation eliminates half the cross-attack evaluation (Minor-Major).** On FITD, baseline achieves F1=0.99-1.0, treatment achieves 1.0, and TF-IDF achieves 1.0. The cross-attack advantage is entirely attack-type-dependent: it manifests on DD (which uses interleaving deception) but not on FITD (which uses compliance escalation similar to Crescendo). With only two OOD attack families, one of which saturates, the generalization claim rests on a single attack type. The paper needs evaluation on additional structurally distinct attack families (ActorAttack, PAIR iterative, multi-turn social engineering) to establish that the finding is not DD-specific.

1. **The critical missing control:** Would continued pretraining (MLM objective, no classification head) on the same persuasion-annotated text corpus bridge the OOD gap? 2. **Synthetic data generation details:** Were the 80 DD and 80 FITD test conversations generated by the same Qwen3-8B model used for training data generation? 5. **Why are per-turn safety classifiers (Llama Guard, WildGuard) not evaluated as baselines?** The paper cites them as production standards that "do not model cross-turn dependencies" but does not verify this claim experimentally. Running Llama Guard on the concatenation of first K turns would be a straightforward and informative addition.

### 5. Missing Experiments or Controls

1. **Domain-adaptive pretraining control (Critical).** Continued pretraining (MLM) on the persuasion text corpus without any labels. This is the most important missing experiment because it would determine whether supervision matters at all.

2. **Alternative auxiliary task control (Major).** Fine-tune DeBERTa on sentiment classification or NLI using the same persuasion-related text. This isolates whether the persuasion task specifically, or any supervised signal on domain-relevant text, drives generalization.

3. **Real-world multi-turn attack evaluation (Critical).** Evaluation on at least one source of real (not synthetic) multi-turn jailbreak conversations. Even 30-50 real examples would substantially strengthen ecological validity.

4. **Precision-recall curves on WildChat hard negatives.** The 8% FPR is a single operating point. A full PR curve across thresholds would characterize the precision-recall tradeoff for deployment.

5. **Additional OOD attack types.** FITD saturates, leaving DD as the sole discriminating attack. Evaluation on at least one additional structurally distinct attack family is needed.

6. **Exact counts and confidence intervals.** TP/FP/FN/TN for every cell in Tables 2-5, plus exact binomial CIs, would allow reviewers to assess statistical significance of small gaps.
