## 实现

写 Python 脚本 `code/analysis_mbr_selection.py`：

### MBR Score 计算
对每个 instance 的 N 个 sample (s1, ..., sN)：
```
MBR_score(si) = mean_{j≠i} entity_overlap(si, sj)
```

entity_overlap(si, sj) = 2 * |entities(si) ∩ entities(sj)| / (|entities(si)| + |entities(sj)|)

实体匹配用 span-based: (start, end, type)。如果两个 sample 都没有 entity（空集），overlap = 1.0。

### Selection
选 MBR score 最高的 sample。Tie-breaking: 选第一个。

### 评估
对每个数据集计算：
- MBR Selection F1（macro：每个 instance 的 selected sample 的 entity F1 vs gold，取均值）
- 对比 Greedy F1 和 LP Selection F1
- Delta: MBR - Greedy

entity F1 计算用 span-based (start, end, type)。
