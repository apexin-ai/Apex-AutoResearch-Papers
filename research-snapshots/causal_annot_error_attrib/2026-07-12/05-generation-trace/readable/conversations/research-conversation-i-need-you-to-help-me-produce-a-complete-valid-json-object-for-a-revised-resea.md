### 4. V(s) vs A(s,a) theoretical argument
Key theoretical insight to articulate:
- V(s) = MC pass rate = expected success probability from state s. Confounds step quality with problem difficulty: V values are high for easy problems, low for hard ones.
- A(s,a) = V(s') - V(s) = marginal progress. Centered around 0 regardless of problem difficulty. Isolates step quality from problem difficulty.
- For calibration: V(s) regression forces the model to learn both "how hard is this problem" and "how good is this step" simultaneously, coupling these signals. A(s,a) isolates the step-quality signal.
- Scale invariance: A(s,a) ranges around 0 regardless of whether V(s) is 0.05 (hard) or 0.9 (easy). This means advantage-calibrated scores generalize better across problem difficulties.
- Cross-generator argument: Different generators have different V(s) distributions, but A(s,a) for a step of given quality is more stable across generators.
