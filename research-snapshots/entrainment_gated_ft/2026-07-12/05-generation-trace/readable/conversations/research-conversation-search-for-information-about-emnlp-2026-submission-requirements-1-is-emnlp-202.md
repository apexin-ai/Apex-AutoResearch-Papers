## Overview

RadixAttention is a technique for automatic and efficient KV cache reuse across multiple LLM generation calls. SGLang is a high-performance serving framework for large language models and multimodal models.

## How RadixAttention Works

RadixAttention maintains an LRU cache of the KV cache for all requests within a radix tree, which manages the KV cache as a traditional cache and uses a radix tree for efficient matching, insertion, and eviction. RadixAttention stores KV cache entries in a radix tree where each node represents a sequence of tokens. When a new request arrives, the runtime walks the tree from the root, matching the request's prompt tokens against existing nodes.

## Key Benefits

RadixAttention reduces total memory usage by sharing the KV cache, allowing for a larger batch size to improve maximum throughput, and also reduces the computation of prefill, thus decreasing the first token latency.

KV cache reuse means different prompts with the same prefix can share the intermediate KV cache and avoid redundant memory and computation.

## Performance Impact

SGLang achieves up to 5 times higher throughput compared to existing systems, namely Guidance and vLLM. The SGLang paper reports up to 6.4x higher throughput across various workloads when RadixAttention can exploit shared prefixes.

## Use Cases

In a complex program that involves multiple LLM calls, there can be various KV cache reuse patterns, with four such patterns being common in LLM workloads. These include few-shot learning, multi-choice questions, agent systems, and tree-of-thought reasoning.
